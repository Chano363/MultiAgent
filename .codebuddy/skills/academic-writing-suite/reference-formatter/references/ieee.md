# IEEE Citation Style — Detailed Rules

Used in engineering, computer science, and electronics publications.

## General Rules
- Entries numbered in order of citation in text: [1], [2], [3]...
- No alphabetical sorting — citation order only
- Author names: initials before surname (F. M. Last)
- No italics for journal/conference names in plain text; use italics in formatted output
- Abbreviate journal and conference names (IEEE standard abbreviations)

## Journal Article
```
[#] F. M. Last and F. M. Last, "Title of article," *Abbrev. Journal Name*, vol. #, no. #, pp. #–#, Mon. Year, doi: 10.xxxx/xxxxx.
```

**Rules:**
- Authors: initials + surname, comma-separated, "and" before last author
- Title: sentence case (only first word and proper nouns capitalized), in double quotes
- Journal name: italicized, abbreviated (e.g., *IEEE Trans. Neural Netw.*, *Proc. IEEE*)
- Include month of publication if available
- DOI format: `doi: 10.xxxx/xxxxx` (not a URL — no `https://doi.org/`)

**Example:**
[1] J. A. Smith and B. C. Lee, "Effects of climate change on biodiversity," *Nature Rev.*, vol. 15, no. 3, pp. 120–135, Mar. 2020, doi: 10.1038/xxx.

## Conference Paper
```
[#] F. M. Last, "Title of paper," in *Proc. Conference Name (ABBREV)*, City, Country, Year, pp. #–#, doi: 10.xxxx/xxxxx.
```

**Example:**
[2] A. B. Chen, "Deep learning for image recognition," in *Proc. IEEE Int. Conf. Comput. Vis. (ICCV)*, Seoul, Korea, 2021, pp. 1234–1242, doi: 10.1109/xxx.

## Book
```
[#] F. M. Last, *Title of Book*, #th ed. City, Country: Publisher, Year, pp. #–#.
```

**Example:**
[3] D. E. Knuth, *The Art of Computer Programming*, 3rd ed. Reading, MA, USA: Addison-Wesley, 1998, pp. 45–67.

## Book Chapter
```
[#] F. M. Last, "Title of chapter," in *Title of Book*, F. M. Editor, Ed., #th ed. City: Publisher, Year, pp. #–#.
```

## Thesis / Dissertation
```
[#] F. M. Last, "Title of thesis," Ph.D. dissertation [or M.S. thesis], Dept. Name, Univ. Name, City, Year.
```

**Example:**
[4] J. Wang, "Neural architecture search," Ph.D. dissertation, Dept. Comput. Sci., MIT, Cambridge, MA, USA, 2022.

## Technical Report
```
[#] F. M. Last, "Title of report," Org. Name, City, Rep. Rep-Number, Year.
```

## Standard
```
[#] *Title of Standard*, Standard Number, Year.
```

**Example:**
[5] *IEEE Standard for Floating-Point Arithmetic*, IEEE Std 754-2019, 2019.

## Webpage / Online Resource
```
[#] F. M. Last, "Title of page," Website Name. Accessed: Mon. DD, Year. [Online]. Available: URL
```

**Example:**
[6] A. Smith, "Introduction to transformers," Towards Data Science. Accessed: Jan. 15, 2023. [Online]. Available: https://towardsdatascience.com/xxx

## Author Rules
- ≤ 6 authors: list all
- > 6 authors: list first author + *et al.*
- Corporate/org author: use org name directly

## Common Errors
- ❌ Using `https://doi.org/` instead of `doi:` prefix
- ❌ Full journal name instead of IEEE abbreviation
- ❌ Title case for article titles (should be sentence case)
- ❌ Surname before initials (IEEE uses initials-first)
- ❌ Alphabetical ordering (IEEE is citation-order only)
