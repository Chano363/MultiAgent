# GB/T 7714-2015 — Detailed Rules

Chinese national standard for academic citations. Most common format in Chinese academic publications.

## Document Type Identifiers

| Type | Code | Type | Code |
|------|------|------|------|
| Journal article | [J] | Thesis/Dissertation | [D] |
| Book/Monograph | [M] | Report | [R] |
| Edited volume | [C] | Standard | [S] |
| Conference paper | [A] | Patent | [P] |
| Webpage/Electronic | [EB/OL] | Newspaper | [N] |

## Author Rules
- Surname first, then given name (Chinese: write as-is; Western: full surname + initials)
- Multiple authors: comma-separated, no "and" / "和"
- ≤ 3 authors: list all; > 3: list first 3 + "等" (Chinese) or "et al." (English)

## Journal Article [J]
```
Author. Title[J]. Journal Name, Year, Volume(Issue): Pages. DOI.
```

**Chinese example:**
张三, 李四, 王五. 气候变化对生物多样性的影响[J]. 生态学报, 2020, 40(3): 120-135. https://doi.org/10.5846/xxx

**English example:**
Smith J A, Lee B C. Effects of climate change on biodiversity[J]. Nature, 2020, 15(3): 120-135.

## Book/Monograph [M]
```
Author. Title[M]. Edition (omit if 1st). Place: Publisher, Year: Pages.
```

**Example:**
李明. 现代生态学[M]. 2版. 北京: 科学出版社, 2019: 45-60.

## Thesis / Dissertation [D]
```
Author. Title[D]. Place: Institution, Year.
```

**Example:**
王芳. 城市热岛效应研究[D]. 北京: 北京大学, 2021.

## Conference Paper [A] in Edited Volume [C]
```
Author. Title[A]//Editor. Volume Title[C]. Place: Publisher, Year: Pages.
```

## Webpage / Electronic Resource [EB/OL]
```
Author. Title[EB/OL]. (Publication date)[Access date]. URL.
```

**Example:**
中国政府网. 关于碳达峰碳中和工作意见[EB/OL]. (2021-10-24)[2023-05-01]. http://www.gov.cn/xxx.

## Punctuation Rules
- Fields separated by `.` (period + space)
- Volume/issue: `40(3)` — volume number, issue in parentheses
- Page range: use `-` (hyphen), not `–` (en dash)
- End each entry with a period

## Ordering
- Sequential (citation-order): [1][2][3]... — most common in Chinese journals
- Alphabetical (author-date): by surname stroke count or pinyin

## Common Errors
- ❌ Missing document type identifier [J][M] etc.
- ❌ Not truncating author list beyond 3 with "等"
- ❌ Missing access date for electronic resources
- ❌ Using en dash (–) instead of hyphen (-) for page ranges
- ❌ Listing edition number for first editions
