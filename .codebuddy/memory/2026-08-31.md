### 踩坑记录（重要）
1. **3000 步阶段训练奖励系统性崩塌**：后列全程贴前列，势场惩罚（−200/步）累积，单回合可达约 −75 万。处理：best-checkpoint 协议评估；学习曲线截断至 −30000（仅可视化，原始值仍在 JSON 中如实保留）。
2. **5 seed 并行 CPU 竞争**：5 进程互相抢 CPU，总墙钟显著长于串行单 seed ×5。已按 handoff 用 `&`+`wait` 在常驻 WSL 终端跑。
3. **WSL 后台进程被杀**：`wsl.exe` 每次调用是独立会话，nohup 分离进程会随会话结束被杀 → 必须在不关闭的终端里用 `&`+`wait`。
4. **出图 CJK 乱码/缺字**：需 `setup_cjk_font` 加载 Windows 字体（Microsoft YaHei）。
5. **主对比图追尾标注重叠**：正值柱 "追尾69步" 与数值标签重叠 → 改置于数值标签上方（bar 高度 +10 偏移）；负值柱置于零线上方。
6. **学习曲线 "300 步" 标注被图例遮挡** → 图例移图外底部（ncol=5），三阶段起始线 1/67/133 全部可见。
7. **5 列图追尾标注被高柱遮挡、增益标签被 twinx 轴裁剪** → 追尾标注置于两柱最高值上方、twinx 显式 set_ylim。
