### P1 第16条：万吨级训练发散诊断（四层 bug 链）+ 性能向量化优化

**发散诊断（V5.1 → V5.2）**：
- V5.1 修复 ValueNorm 后仍发散（Ep10 viol 1315 → Ep20 爆 112368）→ 三层 bug 链：
  1. log_prob 未归一化（×101，已修）
  2. value 目标尺度爆炸（ValueNorm 修复）
  3. SafetyLayer 修正动作后 log_prob 失配（用 `executed_actions` 重算）
- **关键回归**：小编组对照实验发现 V5.1 的"log_prob ÷num_drones 归一化"**本身是错的**——正确 MAPPO 是 per-agent ratio，归一化 → ratio≈exp(Δ/101)≈1 → policy_loss≈0 → 策略不学习。修复=per-agent log_prob/ratio
- **viol 指标 bug**：`ep_viol += info[...]` 重复累加 reset 起累计值 → 三角放大。修复=直接覆盖
- 修复后：Ep10 viol=8.0（真实值），per-agent KL 0.0153 正常

**性能向量化优化（V5.3，本次核心）**：
- 三个逐车 Python 循环（101 车）是瓶颈：select_actions/get_log_prob 逐车 batch=1 前向 + update 逐车循环 + _coupler_forces/_resistance_forces 标量循环
- 修复：
  1. 策略前向整批向量化：flatten 状态 reshape `[N, obs_dim]` 一次前向
  2. update 用 `[batch*N, obs]` 一次前向 + view 还原 per-agent log_prob
  3. 安全层未修正时复用 select 的 log_prob（`actions_modified` 标记），跳过 get_log_prob 二次前向
  4. 车钩力用相邻差分数组 + np.where 死区；Davis 阻力内联向量化
- **结果：~130-180s/ep → 16.8s/ep，提速 8-10 倍**，500ep 从 18h → ~2.3h，71 测试无回归
- 注意：向量化时 log_prob 需 `.detach()`（带梯度 tensor 不能 `.numpy()`）

### V5.8 场景特性认知：长大下坡本质是协同制动策略问题（用户确认方向）

**关键领域认知（经诊断验证，务必记住）**：
- **长大下坡列车无法牵引超速，只能制动降速**：目标20→末速20.6（被限速锁死），目标25满牵引→仍20.6（超速被安全层锁死），目标15→能降到15.6。控制核心=制动，非牵引
- **列间 RL 的价值 = 协同制动策略**（多列如何协同制动：避免追尾 + 车钩力 + 安全间距），**不是牵引能耗优化**（下坡不用牵引，能耗本来就低，能耗奖励信号弱）
- 因此：奖励设计应聚焦"制动决策 + 避免追尾 + 车钩力 + 安全"，去掉/弱化牵引能耗项
- 之前"学无可学"根因补充：速度被限速锁死 + 能耗低 + 间距被底层控制器保持 → 目标速度动作几乎无效
- **让协同制动必要的场景**：引入前车减速/限速区间等突发工况，跟随车需协同制动（不是独立跟随）才体现 MARL 意义

**奖励重设计方向**：
- 去掉牵引能耗优化（下坡不适用），改为：制动平滑度/制动策略项 + 避免追尾（势场/最小间距硬惩罚）+ 车钩力约束 + 速度不超限
- 引入扰动：前车突发减速（测试协同制动响应）

**诊断工具（临时）**：tmp_diag_speed.py 验证速度极限、tmp_diag_energy.py 验证能耗
