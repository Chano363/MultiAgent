## 第六轮（✅ 缓解波bug修复完成 + 诚实验证）

### 缓解波传播bug根因（确认）
- `_reset_air_brake_command` 缓解时对每节设 `delay_remaining = 距离/波速`（尾部=6秒=60步）
- `_advance_air_brake_propagation` 缓解波循环**依赖 releasing[i-1]**（逐节串行），每节等满自己的 delay
- 结果：第 k 节需 ~60k 步才释放（串行累积），缓解传播严重延迟 → 尾部残留满制动 → 拖停列车
- **数学证明**：串行6000步 vs 连续波前60步，差100倍

### 修复（✅ 83测试全过无回归）
- `_reset_air_brake_command`：对每个设置缓解delay的节标记 `releasing[j]=True`（缓解波传播中）
- `_advance_air_brake_propagation`：缓解波循环改为 `for i in range(n): if releasing[i] and active[i]` **并行独立倒计时**（去掉 releasing[i-1] 依赖）
- **验证**：缓解波传播 61步=6.1秒（vs 理论6.1秒，1.0x），提速100倍 ✅

### 修复后重评（固定初态65，诚实结果）

|:--|:--|:--|:--|
| reward | +27950 | **+36446** | **-31151** |
| 车钩力 | 651 | 804 | 734 |
| 追尾 | 0 | **0** | **202** |

**协同增量从 +110434 缩水到 +67597**（修复前M3追尾392→修复后202）。M1不追尾仍成立。

**⚠️ 重大诚实发现**：
