### 步骤① 扰动鲁棒性评估（✅ 诚实负结果）
- `train_fleet_env.py` 分层分支加扰动脉冲（`enable_disturbance` + 窗口 `disturbance_step~+duration`，默认 False 不影响训练/评估）；`evaluate_m1_m3_long.py` 加 `--disturbance`/`--disturbance_duration`
- 扰动机制正确（诊断：领航车 -0.3 时 62→51.9km/h）
- **诚实负结果**：当前 M1 扰动鲁棒性不足。扰动太弱（-0.25）M3 独立也能应对；太强（-0.3）M1 也追尾；中间窗口 M1(+11318) 不优于 M3(+13246)。根因：M1 训练无扰动，阈值偏移未针对扰动优化
- 记录为论文"限制/未来工作"（需训练加扰动场景），不污染无扰动主结论

### 步骤② 多种子统计评估（✅ 协同增量稳健）
- `evaluate_m1_m3_long.py` 加 `--randomize_init`（初态 58-66 km/h，避开高初态触发缓解波 bug）+ `--n_seed`，summarize 输出 mean±std
- 10 seed 结果：**M1 reward +34763±1141（std小）vs M3 -10641±43683（std巨大）**；M1 追尾0 vs M3 158.6；M1 间距min182m vs M3 -202m。**协同增量稳健**
- **发现**：随机化初态部分 seed 车钩力爆炸（~22900kN）是**已知缓解波满制动失效 bug**（诊断证实 M3 init=66 也爆炸，非协同引入）。主评估固定初态65 车钩力守住（M1 864/M3 997）

### 步骤③ 循环制动场景（✅ 现有场景已体现协同价值）
- M3（独立）循环制动 2 次 → 掉速（低40 7.4%）→ 追尾392；M1（协同）循环制动 0 次 → 不掉速、不追尾、车钩力守住
- 价值链条："循环制动产生掉速/追尾压力 → 协同(M1)避免"已体现，无需改场景（改场景触发缓解波 bug + 触及用户决策点X/Y/Z）

### 步骤④ 车钩力消融 M1 vs M2（✅ 结构性结论）
