## 项目核心事实

**两阶段递进式 RL 研究**（根目录 d:\Code\MultiAgent）：
- 阶段一：无人机编队控制（gym-pybullet-drones，已完成，历史成果）
- 阶段二（当前主战场）：**重载列车群组协同控制**

**阶段二论文题目（2026-08-12 确认）**：面向长大下坡场景基于多智能体强化学习的重载列车群组自动控制方法
**研究对象**：一万吨级 1+0 重载列车群组（单机牵引万吨列车，1机+~100节货车，群组由多列组成，每列内部有车钩力）

**阶段二核心创新点**：车钩力 + 多列群组 + 长大下坡 **分层（Hierarchical）MARL**
- 现有长大下坡 RL 工作（Zhang2024 DQN、Liu2021 DDQN、Wang2025 DQN）**均忽略车钩力**
- 本项目在长大下坡循环制动场景下**显式建模车钩力**，并扩展到多列群组协同
- 自动控制 = MARL 训练出的控制器本身（无额外底层控制器）

**【关键架构澄清 2026-08-14，用户纠正，务必遵守】**
- **"0+1" 编组 = 1 台动力机车 + ~100 节拖挂车厢**（不是前后两台动力）
- **"多智能体" 只在列间（多列万吨列车编队）**，每列 = 1 个智能体；列内（1 机车 + 100 拖挂）**不是多智能体**，是单列控制
- **列内控制** = 单列多体动力学最优控制（车钩力作为该列约束/状态/奖励），用单智能体 RL 或规则/最优控制
- **分层框架**：层级一 = 多列编队 MARL（列间协同，每列 obs 含自身车钩力统计）；层级二 = 单列控制（1机车+100拖挂）
- **当前代码 `train_train.py` 的实现是错误的**（`num_drones=101` 把每车厢当智能体），需重构为列间 MARL + 列内单列控制
- 当前卡点"车厢级 101 智能体学不会平稳制动"是**错误实现导致**，非真实定位难点

## 论文新方案（2026-08-20 调研，后经用户纠正，⚠️ 生搬硬套部分已删除）

> **用户纠正（2026-08-20）**：Zhang2021/Guo2025 的 **APF/势场控制器"解耦"是从地铁/汽车平直场景生搬硬套**，与我们重载列车长大下坡 + 车钩力场景物理不符，属错误内容，不得作为重构依据。

**为什么 APF 势场对本场景是错的**：
- Zhang2021 = 地铁**平直**线路、**单质点、忽略车钩力、无坡度**——与我们朔黄线长大下坡 + 多体车钩力 + 循环制动物理完全不同
- APF `tanh(间距误差)+tanh(速度差)` 假设车辆可自由±加减速；而我们长大下坡**无法牵引超速，只能制动降速**（向下可制动、向上无牵引），±对称的 APF 修正与循环制动的离散档位节奏天然冲突
- Guo2025 = 汽车编队（CACC），同样无车钩力/坡度/循环制动概念
- 结论：**"RL 出宏观意图 → 确定性 APF 势场转 throttle" 这条解耦路径不可采用**

**正确贴合本场景的分层（仅魏咪车钩力分层框架可借鉴）**：
- **魏咪（考虑车钩力约束的分层框架，重载列车场景贴合）**：顶层生成宏观控制序列（暂不考虑车钩力），底层用车钩力约束**迭代修正**，修正不经过 RL 反向传播
- 即：**列间 RL 只负责宏观协同决策（配合前列制动/缓解的时机），列内用已验证的规则循环制动 + 车钩力安全层执行**（不引入 APF 势场控制器）
- 这正是工作方针"分层框架"的正确落地：**不新增 Zhang2021 的 APF 势场控制器**

**当前真正的待解问题**：E16/E18/E25C 的"RL 直接叠加 throttle（δ）破坏第1层循环制动控速"。正确方向应是**让 RL 输出"何时配合前列制动/缓解"的宏观时序意图（离散档位或时机），而不是连续 δ 叠加 throttle**——具体设计需回归朔黄线长大下坡 + 循环制动物理，勿再照搬地铁/汽车方法。

**核心定位（用户多次强调）**：循环制动 + 多列群组协同 + 车钩力约束（分层 MARL），绝不允许改动。

**正确场景（用户最后纠正，此前多次失败根源）**：
- ❌ 不是"更紧间距/系统强制制动制造车钩力压力"——这导致"群组协同对车钩力贡献=0"（工作记忆 L55-58 已确认）

- 各列循环制动**相位天然错开**，跟随车为保持间距**配合前列制动/缓解节奏** → 协同价值由场景**天然驱动**

**核心逻辑链（2026-08-20 用户再次纠正，务必记住，勿再搞混）**：
- ① 车钩力**在列内处理**（每列内部车厢间机械钩缓，制动-缓解产生）——不冲突
- ② 编队的价值 = 维持各列之间**距离**，维持距离需**循环制动**
- ③ 编队→循环制动→**列内**车钩力变化（一列为配合编队距离而制动/缓解 → 该列内部车钩力变化）
- ④ **核心创新 = 多列编队协同（为保持间距的循环制动节奏配合）影响/约束每列内部车钩力**
- **"错开"相关**：各列循环制动相位不同，某列因配合间距急制动→列内车钩力放大；**协同价值 = 保持间距同时控制/最小化每列车钩力**
- **正确对比**：M1（协同协调制动节奏保持间距+控车钩力） vs M3（每列独立按速度循环制动，不管间距→追尾急制动→车钩力大/牺牲速度）

**下一阶段核心任务**：验证 **M1（多列群组协同 + 车钩力约束）** vs **M3（单列独立，只循环制动不协同）** 的增量（间距保持 + 安全，车钩力贯穿约束）。

**公平 DQN baseline（M-DQN-fair，2026-08-23 已验证）**：
