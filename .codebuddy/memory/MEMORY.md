## 项目核心事实

- **两阶段递进式 RL 研究**：阶段一无人机（已完成）；阶段二（当前主战场）= **重载列车群组协同控制**。
- **论文题目（导师给定，2026-08-12）**：面向长大下坡场景基于多智能体强化学习的重载列车群组自动控制方法。
- **研究对象**：一万吨级 1+0 重载列车群组（单机牵引万吨列车，1机+~100节货车，群组由多列组成）。
- **核心创新点**：车钩力 + 多列群组 + 长大下坡 **分层（Hierarchical）MARL**。现有长大下坡 RL 工作（Zhang2024 DQN、Liu2021 DDQN、Wang2025 DQN）均忽略车钩力。

**【关键架构澄清 2026-08-14，用户纠正，务必遵守】**
- "0+1" 编组 = 1 台动力机车 + ~100 节拖挂车厢（不是前后两台动力）。
- **"多智能体"只在列间**（多列万吨列车编队），每列=1智能体；列内是单列控制，非多智能体。
- 分层框架：层级一=多列编队 MARL（列间协同）；层级二=单列控制（1机车+100拖挂，车钩力为约束/状态/奖励）。
- 早期 `train_train.py` 把每车厢当智能体（101 智能体）是**错误实现**，已废弃。

## 第1层/第2层定位（2026-08-19 最终确认）

- **第1层（单列）= 规则循环制动**（`get_action_cyclic_braking`）。多次尝试 RL 循环制动均不如规则。
- **第2层（多列）= RL 阈值协同**（MAPPO，输出 v_max_adj/v_min_adj 阈值偏移 ±5km/h，不直接动 throttle）。
- **车钩力约束（创新点1）靠规则循环制动 + 车钩力安全层贯穿两层强制执行**（≤1000kN，紧急 2250kN）。
- 领域标准：重载列车 RL 全用离散档位动作，评估指标=制动距离/平均速度/车钩力/纵向冲动。

## 已试过且失败的多列协同架构（勿重复！）（2026-08-20）

1. **E16**：硬规则循环制动 + RL δ 叠加 throttle → 训练不稳定（探索破坏规则档位）。
2. **E17**：RL 调循环制动阈值参数 → 仍不稳定。
3. **E18**：RL 第1层策略控速（warm start）+ δ 协同 → 普通场景稳定，但坡段错开方案下不稳定。
4. **核心困境（E25）**：RL 直接叠加 throttle（无论 δ 还是调阈值）都会破坏底层循环制动控速。

**✅ 方案A已回退（2026-08-20）**：人为坡段错开（start_offset_m/spacing_m）偏离正确场景，已从代码移除。**APF 势场解耦方案废弃**——Zhang2021(地铁)/Guo2025(汽车)的 APF 是平直场景生搬硬套，与重载长大下坡+车钩力物理不符。正确分层仅借鉴魏咪车钩力分层框架：顶层宏观决策、底层车钩力约束迭代修正（不经过 RL 反向传播）。

## 下一步工作方针（2026-08-20 最终确认，★★★★★ 不可偏离）

- **核心定位**：循环制动 + 多列群组协同 + 车钩力约束（分层 MARL），绝不允许改动。
- **正确场景**：朔黄线真实剖面（shuozhou_23800）+ 多列保持间距（虚拟耦合）。各列循环制动相位天然错开，跟随车配合前列制动/缓解节奏 → 协同价值由场景天然驱动。**不引入人为扰动**。
- **核心逻辑链**：① 车钩力在列内处理；② 编队价值=维持列间距离（需循环制动）；③ 循环制动→列内车钩力变化；④ **核心创新 = 多列协同（保持间距的循环制动节奏配合）影响/约束每列内部车钩力**。
- **正确对比**：M1（协同协调制动节奏保持间距+控车钩力） vs M3（每列独立循环制动，不管间距→追尾急制动→车钩力大）。
- **工作方针检查表**：①朔黄线真实剖面+多列保持间距+循环制动天然驱动？②无人为扰动？③锚定 M1 vs M3？④车钩力贯穿约束？

## 论文冲刺收尾关键结论（2026-08-23 后）

- **车钩力创新点叙事（勿再写错）**：车钩力约束由第1层规则循环制动+安全层在物理控制层强制执行，不是第2层 RL 学到的。M1 vs M2（忽略车钩力）消融结构性无差异是**证据**（约束下沉到安全层更稳），不是矛盾。M-DQN 的 2111kN 超限归因到"缺安全层+缺协同"。
- **公平 DQN baseline（M-DQN-fair）**：同架构只换 MAPPO→每列独立 DQN，追尾229、reward -38432，**远不如 M1（0追尾、+36446）** → MAPPO 协同价值是真实算法优势。代码：`coor_dqn_agent.py`/`train_fleet_dqn.py`/`evaluate_m1_m3_long.py mdqn_fair`。
- **泛化失败率**：3 seed 训练 2/3 泛化成功、1/3 失败 → `train_fleet.py` 加 `--curriculum 300-1000-3000` 缓解。
- **Yang2025 对标**：简化 MPC 探索实验（`mpc_controller.py`）追尾296、车钩力1246超限，仅作参考线不写入主表。
- **环境限制**：`wsl.exe` 每次调用独立会话，tmux/setsid 后台不持久；但前台训练可行（200ep ~10min 可在 idle timeout 内完成）。跨 WSL 传多行 python -c 会被吃引号 → 用临时脚本文件。
- **P3 第二剖面普适性**：协同价值与下坡长度强相关；普适性证据 = 主评估压力消融（gap 100→40m 单调 +67597→+89588）+ 5列扩展（+67595）。`long_downhill_20km` 第1层规则循环制动掉速到0 → 协同无法弥补（诚实记录）。

## 仿真器物理模型基线（2026-08-30 对齐，★★★★★ 权威口径）

- **四篇基准文献全文** dump 至 `outputs/diagnostics/`（yang_min_thesis / li_wei_2023 / yu_zongze_2025 / zhang_ertian_2021 .txt），改物理模型前必读。
- **文献同工况基准值（唯一对照口径）**：
  - B 基准（杨敏，实测验证）：万吨 HXD2×2+105 C80，-6‰，60km/h，常用全制动至停 → **634 kN**
  - A 基准（张二田 2021 表1/2）：朔黄线 2万吨循环，货车最大钩力峰值区间 **[836, 2142] kN**；初制动时差 3s/缓解时差 10s
  - 李蔚表3：2万吨**紧急**制动仅 ~1100 kN
- **模型结构（已对齐，勿回退到线性弹簧）**：
  - 缓冲器 = MT-2 迟滞模型：F0=200kN 预压 + k=1.89e7 + 库仑摩擦 500kN + 10mm 间隙 + 83mm 行程刚性限位。**限位力必须在饱和封顶外叠加**（否则位移漂移 16m+）
  - 制动力 = 实算法：C80 常用全制动 64 kN/车、紧急 160 kN/车；升压时间分档（常用 18s、紧急 10s）
  - 制动波 = **并行倒数**（delay=累计距离/波速 + pending 档位）；缓解波同步处理
  - 多机同步制动：中置机车双向发波（sync_loco_brake）
  - 动力学子步进 ≤0.01s（内部自动拆分，RL dt=0.1 透明）
  - Newmark-β（β=1/4,γ=1/2）隐式积分 + Picard 迭代，替代半隐式 Euler（2026-08-30 新增）
- **验证结论**：B 651/671 vs 634（+3%/+6%）✅；A 1989 ∈ [836,2142] ✅。验证脚本 `src/evaluation/verify_dual_baseline.py`（dt=0.01）。**改任何动力学参数前先跑它**。

## 关键技术坑速查

1. 制动传播延迟按**车辆累计长度/波速**算，不要用车钩 free_length。
2. mcp 必须 1.9.3（2.0 移除 @app.list_tools）。
3. 开放获取论文程序化下载被 403 → 浏览器手动下载。
4. YAML 用十进制（`0.0003` 非 `3e-4`）。
5. 安全层修正动作 → 训练必须用实际执行动作重算 log_prob（否则重要性采样失效发散）。
6. value_loss 爆炸 → 用 ValueNorm（PopArt），不要硬编码 `total_loss>1000` 阈值。
7. 网络下载用 Windows PowerShell。
