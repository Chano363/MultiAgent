## 4. 基线对齐重建：双基准首次全部通过（B +3%/+6%，A 落实测区间）

**背景**：车钩力虚高 10 倍（B 6634 vs 杨敏 634 kN）。用户指示"全面读论文对齐基线，不盲目调参"。四篇论文全文已 dump 至 outputs/diagnostics/（yang_min_thesis / li_wei_2023 / yu_zongze_2025 / zhang_ertian_2021 .txt）供精读。

**比对结论**：制动力/阻力/编组/限值均与文献一致，问题在结构：① 缓冲器无摩擦迟滞（MT-2=弹簧摩擦式，迟滞环为主耗能机制，线性阻尼低速时消失）② 制动力非实算法 ③ 制动波传播 O(i²) bug ④ 力封顶削掉刚性限位。铁证：李蔚表3 2万吨**紧急**制动仅 ~1100 kN → 我们纯空气循环 5059 物理不可能。

**修复四项**（src/train_dynamics/）：
1. `params.py`+`train.py`：MT-2 迟滞缓冲器（于宗泽式(1)：F0=200kN 预压 + k=1.89e7 + 库仑摩擦 500kN 恒反对相对速度，10mm 间隙，4mm 接触渐入，行程 83mm+刚性限位）。**关键：刚性限位力必须在饱和封顶之外叠加**（否则位移漂移 16m）
2. `train.py` 制动波传播：串行等待+累计距离延迟 = O(i²)（第43节55s，应6.1s）→ 改并行倒数（pending 档位数组），缓解时撤销 pending
3. `braking.py`：实算法制动力（李蔚式13-15+周占松缸压：C80 常用全制动64kN/车、紧急160kN）
4. `train.py`：分档升压时间（常用18-20s 发散式，紧急10s）；动力学内部子步进 ≤0.01s（RL dt=0.1 透明，否则 NaN）
5. `train_env.py`：多机同步制动 sync_loco_brake（中置机车双向发波，张二田初制动时差3s）——A 从 4588→1989 kN

**最终结果**：A 朔黄线2万吨循环 1989 kN ∈ 实测[836,2142]（拉钩主导@缓解段，与实测一致）；B 万吨全制动 651/671 vs 634（+3%/+6%）。verify_dual_baseline.py 判定已更新。诊断脚本在 outputs/diagnostics/diag_*.py。
