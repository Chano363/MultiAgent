## 专攻完成：缓解波 releasing 清除根因修复（✅ 关键修复）

**根因**：缓解波传播（train.py L440-457）中，`_air_brake_releasing` 一旦设为 True 就**永不清除**（除 sync 缓解或 _apply 打断）。长运行后整列 releasing 残留（100/101）→ 缓解命令被 `not releasing[brake_origin]` 阻塞无法再触发缓解波 → 满制动在缓解状态下失效 → 制动力0 → 陡坡超速117 + 车钩力1847kN爆炸。

**修复**（train.py）：
1. 缓解波传播到后车 i 时，**清除前车 i-1 的 releasing**（缓解波扫过后无残留）
2. 缓解完成后（全部 active=False）**清除整列 releasing**

**验证**：
- **6000步长运行**：超速117→**0**，车钩力1847→**894kN**，循环制动0→**1**，速度[38,64]km/h
- 83测试通过

**影响**：修复改变了缓解波物理（传播更真实，缓解后速度能跌到40触发循环制动），但**现有 checkpoint（第1层缓解波+第2层M1）是修复前训练的不匹配** → 重评估出现追尾（M1 146步、间距-40m、reward -49744）。

**决策**：**保留 releasing 清除修复**（真正根因，物理正确，解决超速+车钩力爆炸），**需重训**让策略适应新物理。重训链：第1层缓解波（50-120min）→ 第2层M1（20-40min）→ 评估。

## 论文调研结论（2026-08-22）：缓解中途重新制动的物理依据与模型方向

**查论文库（樊运新/李蔚/刘博阳/张二田/王宏宇）+ scholar 检索**：

**2. 但论文提供了物理依据和模型方向（关键）**：
- **樊运新（循环制动专家，2024）**：空气制动用**气体流动理论的一维管道模型**（等温 N-S 方程）——制动/缓解是**列车管压力的连续渐变**（减压=制动、充风=缓解），制动力由制动缸压力 pz 决定。**缓解是充风、pz 渐进下降**。**缓解中途可继续施加电制动**（"从控机车为保证列车管再充风时间，继续施加电制动力"）。缓解延时 5.63-13.66s（3万吨）。缓解不同步是纵向冲动主因。
- **李蔚（联合制动，2023）**：制动波/缓解波通过列车管压力波传播（有限波速），制动不同步是纵向冲动主因。解决"多源制动时序协调"（本务+重联机车空气制动与再生制动适时异步匹配），非"缓解中途制动"。

**3. 对我们问题的启示（解决方向）**：
- 我们的 bug 根因是**分离状态机**（`_air_brake_active` + `_air_brake_releasing` + `_air_brake_release_frac` 三个标志互相阻塞）→ "缓解中途制动被 `not active` 跳过"。
- **论文用单一列车管压力渐变**（樊运新气体流动模型）——缓解和制动是**同一压力的连续升降**，天然不存在"阻塞"问题。缓解中途制动 = 压力从下降转上升（自然打断）。
- **因此正确的解决方向不是打补丁，而是重构为"单一缓解-制动压力状态"**：缓解 = 制动力渐变衰减，制动 = 渐变上升，缓解中途制动 = 自然打断衰减重新上升。物理正确且无阻塞。

**结论**：论文未给现成补丁，但指明了**模型重构方向**（从分离状态机 → 单一压力渐变，对齐樊运新气体流动模型）。当前 3000 步基线正常可先固化；重构作为后续课题。

## 论文调研：为什么 RL 发散 + 其他论文怎么做（2026-08-22）

**为什么 RL 发散（缓解波 + 连续 throttle）**：
1. **连续 throttle 动作空间 + 缓解波长时延（6s）**：制动力延迟 6s 才传尾部 → PPO/GAE 信用分配失效 → 策略梯度失真 → 发散
2. **无物理约束引导**：RL 自由探索连续空间，探索中制动-缓解切换 → 车钩力爆炸（viol上千、车钩力2000kN）
3. **车钩力多体强非线性耦合**：速度+车钩力双目标，车钩力对动作极敏感 → 双重困难

**其他论文（领域标准，从 Zhang2024/Tang2020 论文库）**：
- **Zhang2024（DQN 循环制动）**：动作 = 空气制动**二元（施加/缓解 ha=1/0）** + 电制动连续；缓解有**物理约束**（最小缓解速度40km/h + 最小充风时间）；**忽略车钩力**（单质点）→ 绕开缓解波车钩力冲击的 RL 难题
- **Tang2020（DSQ 多机车）**：**离散档位**（机车手柄 notch）+ 变化率约束；coupler force 优化
- **领域标准**：重载列车 RL 全用离散档位动作

**关键洞察**：
- Zhang2024 用**二元空气制动动作 + 缓解物理约束引导**（不让 RL 自由探索缓解），且**忽略车钩力**（单质点）
- 我们建模车钩力（创新点），比 Zhang2024 难，不能照搬忽略车钩力
- **但可借鉴**：①动作空间改离散档位（4-6档）；②缓解时机物理约束引导
- **MEMORY.md 已记录"多次 RL 循环制动都不如规则"**：规则循环制动本就是领域最优，我们建模车钩力后，**规则循环制动 + 车钩力安全层（方案 A）是正确方向**，而非让 RL 学循环制动
