## 低40掉速优化（步骤①-③，进行中）

**背景**：步骤③评估 M1/M3 低40占 26%，整体 reward 为负。核心创新（M1 vs M3 增量+25%）已验证，低40是"锦上添花"（让 reward 转正）。

**诊断（见 PROJECT_PIPELINE 4.2.6 + VALIDATION_BASELINE）**：
1. **规则循环制动方案扫描**：方案B（缓解加牵引 release=0.3）有效（低40 14.3%→7.3%，牵引0.5→5.8%，车钩力722kN不变）；方案A（提前缓解 v_min=48）无效（缓解后下坡惯性仍穿越40）
2. **第1层 RL 策略单列低40=11.2%**：策略"50就强制动、跌穿40才牵引"→ 缓解时机太晚是单列掉速主因
3. **评估 M1/M3 低40=26% 高于单列 11.2%** → 多列间距协同贡献额外~15%

**奖励塑形（E16.1，train_cyclic_braking.py cyclic_reward）**：
- 增强循环制动引导：<48 未缓解+牵引 → 惩罚-3；48-52 未缓解 → 惩罚-1；<52 缓解+牵引 → 奖励+1
- 目的：引导策略"提前缓解+缓解加牵引"，避免跌穿40

**30ep 短训验证（✅ 有效）**：
- 低40：**11.2%→2.9%**（大幅下降）
- 策略行为改变：45-50 提前缓解+牵引(+0.54)，60 以上才制动，不再"50强制动"
- 超80=0%，车钩力852kN 守住

**进行中**：第1层完整重训（300ep 带奖励塑形，~1.8h，日志 l1_relief_300ep_seed0.log）。完成后 → 重训第2层 M1 → 重评估验证低40下降且协同增量保持/提升。
