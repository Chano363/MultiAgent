# 重载列车群组协同控制 · 多智能体强化学习

面向重载列车长大下坡场景的多智能体强化学习研究。以万吨列车编队为对象，在朔黄线 49.6km 坡段上实现速度同步、间距保持与车钩冲动抑制的多目标优化，兼顾安全约束与能耗。本项目为大学生创新创业训练计划成果。

## 技术栈

- **算法**：MAPPO（多智能体近端策略优化），CTDE（集中式训练、分布式执行）
- **框架**：Python、PyTorch、Gym 多智能体环境
- **物理建模**：列车纵向动力学（车钩力、牵引/制动特性、坡度阻力）
- **安全层**：规则式 ATP 安全约束，车钩力 ≤ 1000kN 硬约束
- **工程**：配置驱动的训练—评估流水线、元数据内嵌的结果 JSON、评估诊断脚本

## 系统方案

每列万吨列车建模为一个智能体，动作空间为每列的目标加速度，观测包含本车速度、间距与车钩力状态。策略网络采用共享参数 + 集中式 Critic 的 CTDE 结构：训练时 Critic 可访问全局状态，执行时每个智能体仅依赖本地观测，兼顾协同优化与工程可部署性。

仿真环境实现了车钩力、牵引/制动特性与坡度阻力的纵向动力学模型，并在 reward 中引入加速度绝对值约束与车钩力惩罚。规则式 ATP 安全层作为最后一道防线，在策略输出越界时强制约束，保证训练与评估过程中的物理安全。

## 我负责的部分

从零搭建列车纵向动力学与编队仿真环境，封装为多智能体 Gym 环境；实现 MAPPO 训练算法与共享策略 + 集中式 Critic 结构；设计规则式 ATP 安全层与车钩力/间距硬约束；构建配置驱动的训练—评估流水线与诊断脚本，并参与实验结果分析与论文撰写。

## 关键结论

在保持车钩力 ≤ 1000kN 安全约束的前提下，相比基线方法，MAPPO 策略实现间距误差下降约 23%、能耗下降约 19%。研究过程同时记录了若干反例与证伪结论（如协同机制在特定参数区间无 reward 增益），相关诊断与根因分析已归档在 `docs/` 中，便于复现与复核。
