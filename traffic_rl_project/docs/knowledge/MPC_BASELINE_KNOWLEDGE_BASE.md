## §1 业务背景与核心概念

论文对比实验的唯一 MPC 基线代码 = **NMPCController**（ADR-022；旧 `FairMPCController`/简化 MPC 已删除，历史 MPC 数值作废）。对比口径（ADR-037，废止 ADR-016 Regime A 协议）：不按坡道换 MPC 模型；同一仿真器、同一环境与坡度数据、同档调参力度——坡度是 MPC 预测模型的**固有输入**（图纸天然先于运营存在），**不设"逐线重喂 `grade_at`/在线标定 b0"协议，也不作"免重辨识成本"叙事**；D-RL 跨线严格零微调。立论 = **相对传统基线的编队指标收益**（ADR-042，2026-10-19；旧"编队上下文协同增益"随独立消融废除）。**⚠️ 主表角色已由 ADR-034（2026-10-13）修订：NMPC 退出主表**（related work 文本，"方法与场景不匹配，忠实复现不成立"）；**主表 MPC 行 = Tube MPC**（following Song2026 虚拟编组管式预测控制架构，车钩力口径见 `RESEARCH_POSITIONING.md` §1.2；主对比场景物理关闭车钩力，同仿真器 + 同档调参力度；**只主张编队指标胜出，绝不主张车钩指标胜出**；ADR-042）。

技术构成：casadi + IPOPT；列内**集中质量（lumped）多体**（ADR-022 术语）；MT-2 车钩；坡度经 `grade_at` 接口读入（固有输入，非重喂）。

## §2 核心流程（求解与桥接）

`compute_actions_from_env()`（nmpc_controller.py）：
1. 首次调用按编组构建 casadi 优化问题；
2. 从 env 快照状态、读入 `grade_at` 坡度（固有输入）、设初值；
3. IPOPT 求解，记录 `solve_times` / `solve_statuses`；
4. 输出每列目标加速度，经桥接逻辑反解为规则基线的加性调制 `(ed_mod, ab_mod)`，保证与 D-RL 动作权限一致（与 `inner_rule_cyclic` 公平对比）。

## §6 核心规则与隐藏约束

- **AI pitfall**【状态残留】`--n_seed` 多回合复用同一 env 时，每回合开始必须 `_mpc.reset()`（历史 bug，有回归测试）。
- **AI pitfall**【solve_statuses】读取求解状态用 `getattr` 兜底（缺失不崩溃）；`NMPCController` 负责记录并清空 `solve_statuses`。
- 【唯一基线】只认 `NMPCController` + `--mpc_type nmpc`；任何"简化 MPC/旧 Fair"数值已作废（ADR-022）。
- 【对比口径】同一仿真器/环境/坡度数据/调参力度；坡度为固有输入，**不设逐线重喂与标定协议**（ADR-037）；D-RL 跨线零微调——改对比口径须走 ADR。
- 【权限对齐】MPC 输出经桥接为 `(ed_mod, ab_mod)` 调制，不得直接给原始加速度当动作。
- 【术语】"多体" = 集中质量（lumped）多体（ADR-022）。

### L2 状态构造的三个决定

1. **参考轨迹直接用 `ref_speed_table`**（75 口径表，与 D-RL 同源）——这同时满足"公平标定"（两方法跟同一条参考线）。
2. **车 1 = 领航列，车 2/3 = 跟随列**（x0 的 s_e2/v_e2 是前车实际状态 − 期望间距，Song2026 式 20）。三列 = 3 个 TubeMPC 实例（idx 0/1/2），与 3 智能体 MARL 对称。
3. **起点/编组/工况与 D-RL 完全一致**（4300 m 固定起点、10 kt 1+108、朔黄 49.6 km、主对比关车钩物理——ADR-042）。

### 陷阱清单（NMPC 时代教训，硬红线）

1. **【权限对齐】** Tube MPC 是**独立基线**：û 直接物理执行（thr/ed/notch），**不走 `(ed_mod, ab_mod)` 调制**——NMPC 的 clip 带宽陷阱（MPC 期望 ED [0,0.75] vs 规则基线 [0,1]，455 步越权，ADR-022/044）在调制架构下才存在。
2. **【不比车钩】** 写作红线（ADR-033）：Formation-MPC 显式关车钩约束，**只主张编队指标（列距/速度带）胜出**。
3. **【metadata】** 评估落权威 metadata（AGENTS 红线 5），`--mpc_type tube` + 配置 + 求解器参数全记录。
4. **【ED 下限】** û<0 时 ED 深度映射不得被 `ed_zero_point=0.77` 类钳制——那是 notch 动作空间的参数，MPC 走自己的执行通道。
