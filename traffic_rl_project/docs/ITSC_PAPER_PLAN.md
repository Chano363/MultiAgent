## 〇、研究问题（RQ）—— 单一聚焦

**主 RQ**：在**长大下坡**场景下，多列**虚拟编组**的重载列车群组，能否通过**分层 MARL** 实现协同控制，使得**列间安全间距、速度一致性和列内车钩力约束**同时得到满足——相比"忽略车钩力的群组控制"和"单列独立控制"，在**不牺牲安全的前提下**显著降低车钩力峰值/超限风险？

**为什么是这个问题**：
- 现有长大下坡 RL（Zhang2024 DQN / Liu2021 DDQN / Wang2025 DQN）**单列 + 忽略车钩力**
- 现有虚拟编组 MARL（Zhang2021 / Song2026 / Guo2025）**多列 + 忽略车钩力**
- **交叉空白**：多列虚拟编组 + 长大下坡循环制动 + 显式车钩力 —— 无人做过

**副 RQ（支撑主 RQ）**：
- RQ1：车钩力约束在"多列群组协同"下是否比"单列独立"更重要？（缺口3的因果链）
- RQ2：协同带来的增量价值是否显著优于"每列独立控制"？（缺口2）
- RQ3：如果群组控制忽略车钩力，是否会给出"速度同步但车钩力超限"的危险解？（对比公平性）

### 0.1 最直接对标：Yang2025（ITSC 2025）【文献调研 08-16 补充】

**Yang2025《Automatic Train Operation of Heavy-Haul Trains Based on Model Predictive Control》**
- DOI：`10.1109/ITSC60802.2025.11423746`（ITSC 2025，已投稿会议同届）
- **同会议、同场景、同目标，算法不同** → 最强对标
- 多质点 20000吨 + **朔黄线真实数据 + 循环空气制动** + **MPC 速度跟踪**
- 目标：**降低车钩力冲动 + 能耗 + 速度跟踪精度**
- **差异**：Yang2025 用 MPC（单列），我们用 **MARL（多列虚拟编组）**

**定位强化**：
- Yang2025 = **单列 MPC + 朔黄线 + 车钩力冲动** → 我们可比（单列场景：MPC vs 我们的列内执行/第1层）
- 我们 = **多列虚拟编组 + MARL + 车钩力** → 多列协同是 Yang2025 没有的扩展

## 一、核心贡献（单一创新点）

> ITSC 是短会议论文（6页双栏）。**只讲一个核心贡献**，其他作为支撑。

**核心贡献**：提出一种**规则循环制动 + 阈值协同分层框架**，用于**长大下坡下多列虚拟编组重载列车的协同控制**，在保证**列内车钩力安全约束**的前提下实现**多列协同保持间距**（避免独立控制的追尾碰撞）。

具体支撑（3 点，不是并列创新，而是同一个贡献的三层证明）：
1. **C1（方法）**：分层框架——第2层 MAPPO（每列=1智能体，输出协同阈值偏移 v_max_adj/v_min_adj）+ 第1层规则循环制动（领域最优，Zhang2024 直接规则化）+ 车钩力安全层强制执行（≤1000kN）。对齐领域标准（重载 RL = 规则循环制动 + 离散动作），避免 RL 学单列循环制动（结构性失败：缓解波长时延→信用分配失效→探索即爆炸）
2. **C2（物理）**：在朔黄线真实剖面循环制动下，各列独立循环制动（掉速+速度差）→ 后列追上前列 → **追尾碰撞**（M3 追尾392步）；多列协同（阈值偏移）使后列配合前列制动/缓解 → **保持间距不追尾**（M1 追尾0、间距182m）。协同价值由场景天然驱动（真实编队总长~4km，各列进入坡段时机天然不同）
3. **C3（验证）**：同架构对比证明**协同增量**（M1 vs M3：+110042，M1 不追尾 vs M3 追尾392），且车钩力约束由第1层安全层强制执行（M1/M3 都守住 864/997kN <1000kN，创新点呈现为"规则循环制动 + 安全层强制执行"）——严格归因到"协同"而非"算法优势"

## 二、方法架构（对齐论文范式）

### 2.1 分层框架

```
┌──────────────────────────────────────────────────┐
│ 第2层（列间，Platoon Level）—— MAPPO，每列=1智能体   │
│   状态   = 该列 速度/间距误差/前方坡度/前列状态/车钩力  │
│   动作   = 协同阈值偏移 coor_adj ∈ [-1,1]           │
│            → v_max_adj/v_min_adj（限±5km/h）        │
│   奖励   = 限速区间[40,80] + 间距保持 + 速度一致性     │
│            + 避免追尾势场                          │
│           ↓ 生成每列"循环制动阈值偏移"               │
│ 第1层（列内，Coupler Level）—— 规则循环制动（非RL）   │
│   执行   = get_action_cyclic_braking               │
│            （速度>v_max 制动 / <v_min 缓解）         │
│   约束   = 车钩力安全层 ≤1000kN（强制执行）          │
│           ↓ 反馈实际车钩力给第2层作 obs/reward     │
└──────────────────────────────────────────────────┘
```

> **【2026-08-22 最终架构重构】**：放弃"RL 学单列循环制动"（结构性失败：缓解波长时延6s→PPO信用分配失效+车钩力多体耦合→探索即爆炸）。领域标准（Zhang2024 用 DQN 学循环制动但忽略车钩力单质点；Tang2020 离散档位）= **重载列车 RL 用规则循环制动 + 离散动作**。因此：
> - **第1层（列内）= 规则循环制动**（`get_action_cyclic_braking`，领域最优，Zhang2024 直接规则化，含车钩力安全层强制执行 ≤1000kN）
> - **第2层（列间）= RL 只做阈值协同**（v_max_adj/v_min_adj 偏移，限 ±5km/h，不直接动 throttle，避免破坏规则循环制动）
> - **车钩力贯穿约束下沉到第1层安全层强制执行**（M1/M3 都守住 864/997kN），第2层 RL 消融（考虑 vs 忽略车钩力）结构性无差异

### 2.2 关键设计决策（论文导向，2026-08-22 更新为最终架构）

| 决策 | 选择 | 理由 |
|:--|:--|:--|
| 列间动作 | **协同阈值偏移 coor_adj ∈ [-1,1] → v_max_adj/v_min_adj（限±5km/h）** | 最终架构：RL 只做宏观协同（调循环制动阈值），不直接动 throttle，避免探索破坏规则循环制动（E16/E18 教训） |
| 列内执行 | **规则循环制动**（`get_action_cyclic_braking`，速度>v_max 制动 / <v_min 缓解）+ 车钩力安全层强制执行 | 领域最优（Zhang2024 也是学这个，我们直接规则化）；RL 学单列循环制动结构性失败（缓解波长时延6s→信用分配失效→探索即爆炸） |
| 虚拟耦合 | **无线协同，无物理车钩** | 车钩力只在列内（用户确认，勿当列间机械耦合） |
| 限速区间 | **[40,80] km/h**（缓解40/线路限速80，V5.24 修正） | 依据 Zhang2024（朔黄线23.8km长大下坡）：上限80=朔黄线实际线路限速，下限40=重载最小缓解速度；行业《重载铁路设计规范》设计速度≤100/80级。弃用[45,65]（樊运新3万吨参数，与1万吨对象不符+物理不可行） |
| 场景 | **朔黄线真实剖面 shuozhou_23800** | 坡度交替→循环制动→相位错开（真实编队总长~4km，各列进入坡段时机天然不同） |
| 扰动 | **主评估不引入人为扰动** | 真实线路本身驱动协同（用户确认）；扰动作为鲁棒性补充实验（训练加扰动场景增强） |
| 循环制动 | **规则循环制动**（领域最优，非 RL 学） | 对齐 Zhang2024 直接规则化；RL 只做协同阈值偏移（最终架构） |

## 三、对比矩阵（补齐缺口1：公平性，2026-08-22 更新为最终架构）

**核心原则**：方法（考虑车钩力的群组 MAPPO）与各 baseline 之间，**只变一个变量**，才能严格归因。

| # | 方法 | 控制器结构 | 信息可用性 | 车钩力约束 | 对比什么 |
|:--|:--|:--|:--|:--|:--|
| **M1** | **提出方法**：群组 MAPPO + 协同阈值偏移 + 规则循环制动 + 车钩力安全层 | 列间MAPPO(阈值协同) + 列内规则循环制动 | 每列obs含前列状态/车钩力 | ✅（安全层强制执行） | **基线（本文方法）** |
| M2 | 群组 MAPPO **无车钩力**（obs/reward 去掉车钩力 + 安全层关闭） | 同 M1（同架构） | obs 不含车钩力 | ❌ | 消融验证（结构性结论，见下） |
| **M3** | **单列独立（δ=0）**：每列规则循环制动，无列间协同 | 列间δ=0 + 列内规则循环制动 | 仅本列，无列间信息 | ✅（安全层强制执行） | **协同增量（H1）**：证明"协同价值" |
| M4 | 惰行（throttle=0 baseline） | 无控制 | 无 | ❌ | 对照：无控制下坡超速 |
| M5 | **Yang2025 MPC 参考**（单列朔黄线循环制动，ITSC 2025 对标）——**性能参考线，非必复现** | MPC 速度跟踪 | 单列 | ✅ | **论文对标**：引用其报告数据作参考线 |
| M6 | **Wang2025 DQN**（单列循环制动，ICIRT） | DQN | 单列 | ✅ | **论文对标**：DQN vs 我们的列内，报告最大拉力-9.64%/压力-28.77% |

**M3 定义（最终架构）**：M3 = 每列 δ=0（无列间协同），只用第1层规则循环制动各自控速。与 M1 **完全同架构**（列内规则循环制动 + 车钩力安全层），只差"第2层协同阈值偏移"。差异严格归因到协同。

**M2 消融（结构性结论，已实测）**：重训 M2（`--no_coupler_constraint`，忽略车钩力）后评估，**最终架构下 M1 与 M2 结果完全相同**（reward +33490、车钩力864kN、追尾0）——因为车钩力约束已内置列内规则循环制动安全层（`enforce_coupler=True`）强制执行，第2层 RL 是否考虑车钩力不影响列内执行。**车钩力创新点呈现为"规则循环制动 + 车钩力安全层强制执行"**（M1/M3 都守住 864/997kN <1000kN），而非第2层 RL 消融。

**公平性保证**：
- M1 vs M3：**完全同架构**（列内规则循环制动 + 车钩力安全层），只差第2层协同（δ=0 vs 学习阈值偏移）→ 差异归因到协同
- M1 vs M2：同架构，只变"是否考虑车钩力"→ 实测结构性无差异（车钩力内置安全层）
- 所有方法：**相同随机种子、相同评估协议**（确定性 eval_mode）

## 四、实验协议（补齐缺口2/3 + 严谨性）

### 4.1 训练协议（可复现）

- **多种子**：5 个独立训练种子（seed 0-4），报告 mean±std（避免单 seed 假象，V5.13 教训）
- **训练步数**：足够收敛（先做收敛曲线，找到拐点，再定总步数；不盲目长训）
- **固定配置**：lr、entropy、batch_size、GAE 等超参在对比方法间**完全一致**
- **checkpoint 策略**：保存 best 模型（训练 reward 最优），评估报告 best 非末 ep（V5.14 教训）

### 4.2 评估协议（严谨）

- **评估种子**：独立于训练种子的 N 个评估种子（随机化初始状态/扰动工况）
- **确定性评估**：策略 eval 模式（无探索噪声）
- **关键指标**（每列逐一记录，不只记均值——论文对比需要分组明细）：
  - 车钩力峰值（kN）/ 超限次数
  - 速度一致性（各列速度 std）/ 速度范围是否在 [40,80]（V5.24）
  - 间距误差（m）/ 最小间距（安全）
  - 能耗（kWh）（可选，因下坡能耗低）
  - 奖励曲线（训练收敛性）

### 4.3 假设检验（2026-08-22 已实测验证）

**H1（协同增量价值）**：M1 vs M3（最终架构，已验证 ✅）
- **实测**：M1(协同) +33494 vs M3(δ=0 独立) -76548，**协同增量 +110042**；M1 追尾0 vs M3 追尾392；M1 间距min 182m 守住 vs M3 -689m
- **多种子统计**（10 seed 随机化初态）：M1 reward +34763±1141（std小，稳健）vs M3 -10641±43683（std巨大）；M1 追尾0 vs M3 158.6 → **协同增量稳健**
- **机制**：M3 各列独立规则循环制动（掉速+速度差）→ 后列追上前列 → 追尾碰撞；M1 第2层 RL 学阈值偏移，后列配合前列制动/缓解 → 保持间距不追尾
- 图表：`outputs/figures/m1m3_gap_trajectory.png`（M1 蓝线保间距 vs M3 红线追尾 -689m）

**H2（车钩力约束价值）**：结构性结论（已验证 ✅）
- **最终架构下 M1 vs M2（忽略车钩力）结果相同**（reward +33490、车钩力864kN、追尾0）——车钩力约束已内置列内规则循环制动安全层（`enforce_coupler=True`）强制执行
- **车钩力贯穿约束**：M1/M3 都守住 864/997kN <1000kN（安全层强制）；惰行 661kN（无制动车钩力小）
- **呈现方式**：车钩力创新点 = "规则循环制动 + 车钩力安全层强制执行"，确保群组协同在保证安全间距的同时不牺牲列内车钩力约束
- **机制背景**（读论文）：多篇论文指出"缓解不同步"比"制动不同步"更危险——张二田(朔黄线实测"缓解后车钩力最大")、刘博阳(缓解同步性↑→拉钩力降44.5%)、王宏宇("最大车钩力在缓解后")、李蔚("制动不同步→前堵后涌")。最终架构下该机制由规则循环制动 + 安全层承接

## 五、仿真器验证（补齐缺口 + 论文可信度）

**原则**：我们的多体模型（完整多体 + 车钩力）与 Zhang2024（简化单质点、忽略车厢间力）**模型架构不同，不强制对齐数值**。只对齐"场景 + 物理行为"。论文用**物理规律自证**我们的模型真实性。

**已对标论文（物理规律层）**：

| 验证项 | 对标论文 | 关键数据/规律 |

**对齐策略**：不强行对齐单质点数值，但**用这些论文的"物理规律 + 相对指标"验证我们的模型**：
- 制动距离趋势（Yu2026：制动距离与下坡坡度/条件关系）
- 车钩力降幅量级（He2025：21-23.9%；Zhao2026：>8%；Wang2025：9.64%/28.77%）
- 车钩力误差分布（He2025：64.6kN 68% 置信）——用于验证我们的仿真器车钩力输出合理性

**我们多体模型的物理自洽验证目标（E2 核心）**：
1. **惰行下坡会加速**（-10.5‰ 平衡速度 ~152km/h）→ 需循环制动，这是长大下坡真实特征
2. **循环制动能把速度控制在 [40,80] km/h** → 证明控制有效（V5.24 对齐 Zhang2024 朔黄线[40,80]：上限80=线路限速，下限40=最小缓解速度；行业/物理三重依据）
3. **制动相位错开会放大车钩力** → 证明"车钩力是协同瓶颈"机制
4. **车钩力有物理合理量级**（峰值 <1000kN 正常工作）→ 证明多体动力学正确

**不强制对齐**：不调 Davis 阻力去复现 Zhang2024 的 65 km/h 平衡速度（模型不同，参数天然不同）。
