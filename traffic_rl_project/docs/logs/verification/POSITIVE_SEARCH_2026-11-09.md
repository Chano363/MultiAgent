## 对锚定链的含义（截至本日志，推断均标注）

1. **用户阶梯逻辑获实车支持**（推断）：朔黄 1wt 实车全程极值 666/512（A6）远低于 1000 → 真实 1wt 在朔黄正常操纵下可显著低于 1000 kN；本项目仿真基线 1313 相对实车下限偏高约 2×（需排除 A6 轻载/混编/试运保守等混淆项）。
2. **策略优化增益先例带**：−10% ~ −39%（B1–B3）→ 规则层最好 1148.4 经 GA 搜索的合理落点 ~860–1030 kN（推断）；1000 kN 在策略空间内的可达性获得先例支持。
3. **ECP −17%（A4）= "时序协调"效应量的实车量化**（推断）：制动时序同步化改变峰值 ~17% 量级，与本项目"RL 时间维度分配"机理一致；但我们不能上 ECP，纯空气波传播约束下的可协调增益需自证。
4. **1wt 真实力值范围很宽**（512–2502 kN，跨工况/统计口径）：印证"峰值 = 工况×编组×装备×操纵多重嵌入"，比较必须条件匹配（2026-11-09 LEARNINGS 待登记）。

## A4 提取结果（2026-11-09，PDF 全文 + 表5）

> PDF 已存 `docs/papers/01_coupler_physics/王蒙2024_朔黄万吨ECP制动试验.pdf`（2.6 MB / 7 页，DOI 与文章编号核对无误）。数值不在图版而在**表5（PDF 第 5 页 / 期刊页 247）**：各测点车钩力最大值精确值（kN），图11 曲线仅作印证。

| 工况（重车） | 第2辆 | 第28辆 | 第56辆 | 第74辆 |
|---|---|---|---|---|
| 纯空气（ECP OFF，减压 50 kPa，60→40 km/h） | 726 | **945** | 575 | 559 |
| ECP ON（减压 50 kPa，60→44 km/h） | 594 | **656** | 412 | 420 |

- 全列峰值均在**第 28 辆**：945 → 656 kN，**降 30.6%**；四测点降幅 18.2%–30.6%（最小 18.2% > 17%，与"减小 17% 以上"结论吻合）。
- 工况细节：编组 = 1 台交流机车 + 108 辆 C80（与本项目 preset 完全一致）；测点 = 第 2/28/56/74 辆；图11(a)(b) 时间轴 0–200 s，纵轴 0–700 / 0–1000 kN。
- **不确定处**：该文未区分拉/压峰值（表5 每测点仅一个最大值；重车子图纵轴从 0 起无负值）；空车 70→0 停车制动峰值约 208/171 kN 与本项目场景不同，仅作参考。
- **对锚定链的更新**（替代上文"含义 1"中 1313≈2× 的粗口径）：同配置 + 同工况（常用制动 50 kPa）+ 同装备代差（纯空气）下，实车峰值 **945 kN < 1000 kN**——用户阶梯逻辑（常规 < 1000）获得**最强直接锚**；本项目仿真基线 1313 kN 相对同条件实车 945 高 **+39%**（此前 vs A6 非煤 666 的 +97% 口径作废；A6 保留作轻载/混编下限参照）。ECP−17% 量级不变（实测 −18.2%~−30.6%）。
