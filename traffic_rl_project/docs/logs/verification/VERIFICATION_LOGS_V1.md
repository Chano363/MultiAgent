### V1-2 杨敏数据提取 + 验证（2026-08-12）

**从论文提取的关键数据（杨敏, 王开云, 纪天成. 交通运输工程与信息学报, 2018）**：
- 60 km/h 时，车钩间隙 0.01m 与 0.018m 最大车钩力相差 **52.14 kN**
- 大间隙车钩数量 10 → 799.14 kN；数量 100 → 938.18 kN（高 **17.4%**）
- 规律：车钩间隙越大 → 最大车钩力越大（**近似线性增加**）；凸型分布最小

**验证记录（含失败 → 修复，2026-08-12）**：
- ❌ **失败记录**：验证"车钩间隙 0.01 vs 0.018m 车钩力差 52.14kN"（论文规律）时**失败**——原 `coupler.py` 是线性弹簧 `F=k*e-c*(v_front-v_back)`，`free_length` 只是偏移量，0.01m 与 0.018m 在相同相对位移下力完全相同。**期望**：间隙越大→力越大；**实际**：力相同。**原因**：缺车钩间隙死区（非线性）建模
- ✅ **修复（方案 A）**：`coupler.py` 增加死区函数 `_dead_zone(e,gap)`——`|e|<=gap` 弹簧力为0（只留阻尼），超死区按 `k*(e∓gap)` 线性恢复；`CouplerParams.coupler_gap_m` 新增（默认 0.01m，0=无死区向后兼容）
- ✅ **修复后验证（成功）**：`tests/test_coupler_gap.py`（8 测试）复现杨敏规律——制动冲击下间隙 `[0,0.01,0.02,0.03]m` → 峰值车钩力单调不减。全部 48 测试通过（40+8），无回归
- 📌 **教训**：线性弹簧无法表达车钩间隙效应，验证基准（论文数据）能暴露模型简化缺陷；引用：杨敏 2018（交通运输工程与信息学报）


### V1-3 樊运新数据提取（2026-08-12）

**来源**：樊运新 等. *编组方式对3万吨重载列车循环制动工况纵向冲动的影响.* 电力机车与城轨车辆, 2024.

**关键数据（3 种编组，循环制动）**：
- 编组对**空气制动波传递（缓解延时）**影响显著：
  - 编组1 尾部缓解延时最小 **5.63s**；编组3 最大 **13.66s**；编组1 相比编组3 减少约 **58.8%**
  - 编组2 两台机车相隔货车是其他编组 1.5 倍，制动波传递最慢，整体延时 **8.34s**
- 编组3 在长大下坡（10.2‰）最大拉钩力 **952.6 kN**（出现在 2 号从控机车）
- **规律**：列车编组/长度影响制动波传递时间 → **制动不同步性 + 坡道差共同产生纵向冲动**；尾部（分布式）动力可显著提升制动同步、降低冲动

**可验证点（对项目）**：
- 你的 `train.py` 空气制动波速传播：**已验证**"多源（分布式动力）制动 → 全列更快达到制动状态"（同步性提升，对应编组1 缓解延时减少）
- ⚠️ **失败验证记录（2026-08-12，重要留痕）**：原预期"双源制动比单源制动峰值车钩力更低"**验证失败**：
  - ❌ 实测：单源 355.0 kN（最大在队尾第 11 车）、双源 360.1 kN（最大在中部第 5 车）
  - **原因（物理机制）**：单源从队首向后传播→队尾最后制动→**前部先停后部冲→尾部压钩力**；双源两端同时紧急制动→**中间车厢被两端拉伸→中部拉钩力增大**
  - **结论**：**双源紧急制动在物理上不降低峰值**（两端同时全力制动会拉伸中部）。樊运新的"尾部动力降冲动"本质靠**分布式动力参与牵引/张紧 + 缓解同步**，而非"两端同时紧急制动"
  - **修复的动作**：发现并修复 `_apply_air_brake_command` 只支持单向（向后）传播的 bug，现支持双向（`bidirectional=True`）；新增 `step_vehicles_ed_ab` 多源制动参数 `ab_sources`
  - **留下的测试**：`tests/test_braking_propagation.py` 保留"同步性提升"（双源更快全列激活）等可复现验证，删除不成立的"双源峰值更低"断言
  - 📌 **教训**：验证"分布式动力降冲动"需建模牵引/张紧作用，不能简单用"双源紧急制动"替代；此项作为**后续 P1/P3 待办**（尾部机车参与牵引保持车列张紧）


### V1-4 Tang2020 提取（2026-08-12）

**来源**：Tang, Wang, Liu. *Double-Switch-Q-network for multiple electric locomotives.* Knowledge-Based Systems, 2020.

**核心 RL 设计（可复现/借鉴）**：
- **状态**：只用**领航车速度 + 位置**（非所有车），降低维度提高收敛 → **对层级一有直接借鉴**
- **动作**：所有机车档位（HXD3B 25 档：-12~-1 再生制动 / 0 惰行 / 1~12 牵引）+ 档位变化率约束
- **奖励**：评价指标 = 速度 + 能耗 + **车钩力**，带权重 `µe, µc, µh, µl`；含限速惩罚
- **DSQ-network**：状态特征 + 动作特征作两个 switch 层，增强相邻档位参数共享，提升收敛（因相邻机车档位对车辆影响相似）
- **关键规律**：速度↑ → 能耗↑、车钩力↑（多目标权衡，不可同时最优）

**可借鉴点**：
- 你的 `train_env.py` 奖励（-0.5速度/-0.3间距/-0.15冲动）与 Tang 的 µ 权重对照，做权重消融（P2）
- 层级一状态可用领航车（或每列代表）降维
- 你的电制动/空气制动档位可参考 Tang 的离散档位映射


### V1-5 Fu2019 提取（2026-08-12）

**来源**：付雅婷, 原俊荣, 李中奇, 杨辉. *基于钩缓约束的重载列车驾驶过程优化.* 自动化学报, 2019, 45(12): 2355-2365.

**车钩力安全上限（铁道科学研究院建议值，极重要）**：
- **正常运行工况：最大车钩力 ≤ 1000 kN**
- **紧急制动工况：最大车钩力 ≤ 2250 kN**

**验证结果**：
- ✅ **你的 `safety_layer.py` 和 `train_env.py` 用的 1000 kN 车钩力上限 = 论文正常运行工况建议值**（正确）
- ✅ **已实现双上限区分**（2026-08-12）：`SafetyLayer` 新增 `coupler_force_limit_emergency_n`（默认 2.25×1000kN=2250kN），`_state_snapshot()` 检测紧急制动状态（`emergency` 标志），紧急制动时放宽到 2250kN、正常运行仍 1000kN。新增 3 个测试（`test_safety_layer.py`）：紧急制动下 1500kN 不拦截、正常运行 1500kN 拦截、紧急制动超 2250kN 仍拦截。全部 54 测试通过

**方法**：钩缓特性曲线 + 翟方法构造钩缓模型 + 整车纵向动力学；多目标自适应遗传算法（安全/正点/节能）；改进广义预测控制器跟踪速度曲线；大秦线 HXD1 实车数据


### V1-6 Heineken2023 提取（2026-08-12）

**来源**：Heineken, Richter, Birth-Reichert. *Energy-Efficient Train Driving Based on Optimal Control Theory.* Energies, 2023, 16(18): 6712.

**关键数据**：
- **节能效果：37%**（PMP 优化策略节省平均能耗 37%；辅助驾驶综述均值 15-30%）
- **方法**：Pontryagin 极大值原理（PMP），Khmelnitsky 理论推导，再生制动
- **5 种驾驶工况**（最优解总是其一）：全牵引 / 部分牵引恒速 / **惰行** / 部分制动恒速 / 全制动
- 含再生制动时最优速度曲线不同

**可借鉴点（P2 能耗优化）**：
- **PMP 最优解 = RL 能耗上界对照**：你的 MAPPO 能耗结果应接近或低于 PMP 最优
- 惰行（coasting）是关键节能工况，可作为节能奖励设计参考
