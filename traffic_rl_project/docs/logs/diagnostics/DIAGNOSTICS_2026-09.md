- M1 vs M3（均规则循环制动）：

  | 项                        |         M1 |                M3 |
  | :----------------------- | ---------: | ----------------: |
  | speed\_band（速度带内 +5/−20） |    +98,100 | +97,850（**几乎相同**） |
  | **brake（−0.5/制动列·步）**    | **−8,760** |                 0 |
  | **gap（间距）**              | **−2,101** |              +176 |
  | total                    |    +86,406 |           +97,228 |

- **定位结论**：M1 的 reward 劣势**不在速度控制**（speed\_band 与 M3 几乎相同），而在**①协同导致制动频繁（brake 成本 −8,760）+ ②间距惩罚（−2,101）**。即 M1 的 coor\_adj 协同让列车 `target_accels<0` 步数大增（制动多）→ brake 成本高；且间距控制差（gap 惩罚）。**M1 协同机制（调循环制动阈值）的本质问题 = 让制动更频繁、效率更低**，而非速度控不住。

- **与 MPC 差距来源**：MPC 直接加速度控制（循环制动 11 次）vs M1 调阈值协同（循环制动 29 次 + brake 成本高）——控制信号粒度差异（连续在线优化 vs 阈值偏移）是核心。

- **与成熟论文差距**：Zhang2024 完整线路 5 次循环制动 vs 本项目 29 次（口径不同 + 行为差异：本项目 v\_high/v\_low 带 \[40,80] 触发频繁）——需对齐口径/循环制动行为后才能与文献数字对比。

- **机制启示（B 设计依据）**：新协同机制应**减少无效制动/提升效率**（如"目标速度协同"让列车在高效速度带运行，或直接加速度控制），而非继续调阈值偏移。

### 诊断-2026-09-04-代码审计：MARL 协同为何迭代不出增量结果（控制权+奖励+一致性根因）

- **目的**：回答"为什么 M1（分层 MARL 协同）在修复后物理下无 reward 增量、甚至 < M3（独立）"——从控制器/动作/奖励机制逐层定位，区分"训练没学好"与"机制本身无增量"两类根因。

- **方法**：纯代码审计 + 已有数值证据（上节鲁棒性表 + B 机制 reward 分解 + `outputs/diagnostics/coor_policy_report.md`），不重跑训练。

#### 根因1：协同动作控制权过小 = 微观"学无可学"（新定位，最致命）

- 链路：[`hierarchical_controller.py`](file:///D:/Code/MultiAgent/traffic_rl_project/src/controllers/hierarchical_controller.py#L37-L39) [L37-39/78](file:///D:/Code/MultiAgent/traffic_rl_project/src/controllers/hierarchical_controller.py#L37-L39)：`adj = clip(coor_adj)·adj_coef·COOP_LIMIT`，`COOP_LIMIT=5km/h`。M1 训练用 `--adj_coef 0.1` → **coor\_adj=±1 仅把 v\_max/v\_min 阈值偏移 ±0.5 km/h**。

- 阈值带宽 = v\_max−v\_min = **40 km/h**（80−40）→ 协同偏移仅占带宽 **1.25%**；规则循环制动触发点只挪 0.5km/h。

- 后果：`_calculate_reward` 里**所有对 coor\_adj 敏感的量**（speed\_band ±5/−20、间距趋势、跟丢惩罚）对 ±0.5km/h 阈值偏移几乎无响应 → reward 对动作的梯度 ≈ 0 → RL 学不到"更好的协同"，最优可达状态 ≈ 不协同（M1 best +154,849 ≈ M3 +158,638）。

- 对比铁证：**M4（规则 PID 协同）用** **`--adj_coef 0.3`（控制权 3×，转换 ±1.5km/h）** 而 **M1（RL）只用 0.1**。RL 想赢过规则基线，自己却只有规则 1/3 的协同杠杆——结构上就被按在地上。这与 ADR-003（目标速度被物理锁死→学无可学）是**同一病在协同层复发**。

#### 根因2：奖励被低层控速主导，协同项淹没

- `speed_band_reward`（+5/列带内，−20/列带外）占奖励绝对主体，完全由规则循环制动（固定阈值）决定，**与 coor\_adj 无关**；M1≈M3 在该项几乎相同（B 机制分解已验证 speed\_band +222k 两方法一致）。

- 仅 `gap_reward`/跟丢项对协同敏感，且是**分桶**（±1 区间 / >200m 惩罚）。微小阈值偏移很难稳定地把间距误差搬过桶边界 → 协同信号既弱又有噪声。

- 结果：RL 的最优解就是"什么也不做"维持 M3 的默认阈值——因为任何主动协同都只是引入额外方差，多数被跟丢桶惩罚。

#### 根因3：多智能体一致性难收敛（上节已证，机制层面首个）

- B 机制 reward 分解：灾难全来自 `gap_reward −82.5万`，三列独立输出 `v_coop` 不一致 → 速度不同 → 间距拉开 → 跟丢。**一致性的负耦合惩罚在量级上远超协同正向收益**。

- M3（δ=0）三列天然一致 → 无此问题；M1（RL 学联合阈值）在长时程/多体耦合+安全约束下难以找到"三列一致的阈值组合"，探索即破坏一致性。文献（Zhang2024/Liu2021/Wang2025）都是**单列单智能体控速，无列间一致性维度**，故易学；多列群组 MARL 好结果的（Guo2025/车队）多为**质点简化、忽略车钩力**模型。

#### 根因4：阈值偏移方向/结构不合理（机制设计层）

- `adj` 同时加在 `v_max_adj` 和 `v_min_adj` 上 → **只是整带平移、带宽不变**（40km/h 恒定）。它只能挪动"整条速度带"的相位，无法压缩/拉伸循环周期、也无法直接定向一个目标间距。

- 各列跑同一阈值带+同一坡面 → 制动/缓解相位天然被共同坡面锁死（同频），可利用的相位自由度极少。协同概念在此场景"几乎无物可协"（间距健康时无增量必要，间距危险时该类弱动作又够不着）。

- 佐证：[`coor_policy_report.md`](file:///D:/Code/MultiAgent/traffic_rl_project/outputs/diagnostics/coor_policy_report.md) 显示已学 coor\_adj 大量贴 clip 界（±0.9，std 0.7-0.8），corr(gap)=−0.642 / corr(dv)=+0.427——**RL 学到的是"间距/速度差→阈值偏移"的粗粒 bang-bang 版启发式，正是 M4 规则 PID 已实现的映射，且权威还只有其 1/3**。即 RL 没有学到规则之外的非平凡协同。

#### 结论（期望 vs 实际）与启示

- **期望**：训练调参/加机制后 M1 应逼近或超越 M3。**实际**：根因1（控制权 1.25%）+ 根因2（奖励主导项与协同正交）+ 根因3（一致性负耦合）共同导致"MARL 协同既学不出增量，最优也仅是复刻默认阈值"。根因1/4 是**机制性**（非训练资源问题），加训练时长/算力无法解决；根因2/3 是**任务难度**（一致性+弱信号）。

- **启示（供决策选向参考）**：①在"A 机制阈值二维 + 0.1 权重"框架内继续迭代 MARL **结构性没戏**——要么把协同杠杆放大到与 M4 同级（adj\_coef≥0.3 且让 RL 学非均匀偏移/带宽容积），要么换"真能影响物理"的动作（如多机车电空分工 ADR-009，动作直接作用牵引/制动源）；②"实时性/部署优势"（方向①）不受以上任何根因影响，是独立成立的卖点。

- **留痕来源**：本审计代码行 + 上节鲁棒性表 + B 机制 reward 分解 + coor\_policy\_report。

### 诊断-2026-09-19-MAPPO长训终段value发散治本（winsorize + value grad clip + KL早停收紧）—— SUCCESS

- **背景**：`seed0_nep1400` 长训（1400ep）在终段 ep849→856 发散：loss 从 ~-0.01 爆到 **+0.337→+1.283**、reward 崩到 **-5371**。前期诊断（会话内已写入 mappo_agent.py 注释）定位**非单点突变，而是策略固有"偶发暴力 AB 探破车钩力>1000kN"在长训练终段碰上 value_norm(PopArt) running std 收敛，把一次性破线放大成不可回退的 value 污染**。全程 viol>0 的 ep 共 22 个（ep428 起贯穿），终段最集中。

- **根因机制**：①破线深负轨迹（暴力 AB → 车钩力冲顶 → 巨额负 reward）作为**单条极端 returns** 进入 value 训练；②value_norm 匀速平滑 running std 收缩→适得其反把一次性破线放大成全局 value 漂移；③终段 KL 早停阈值 0.015（epoch 7~10 才触发）放任多次更新累积漂移成不可回退发散。

  - **间距破界是 SLSQP 硬约束的结构性局限（非参数失误）**：gap_min=20m 为硬约束，但 SLSQP 非凸滚动时域在 437/20 次制动事件 + 长时程速度带漂移下约束不可保证满足，间距 min 达负值（追尾穿透，由 ATP 兜底）。对 MPC 而言这是"模型驱动在线优化"面对多列耦合长时程的固有局限，留待主表对比（D-RL vs MPC）作差异来源之一，不作为 MPC 单独判定项。

- **判断**：本轮为 MPC 侧 baseline 首跑（数据留痕 + 复现命令 + seed/配置齐备），**可作论文 MPC 行数据来源之一**；但间距破界意味着需与 D-RL 主对比（53km 免重辨识 protocol A）同口径跑完后再定论，且当前仅 seed0 单 seed，5-seed 审稿稳健基准待主训练 D-RL 权重就绪后补齐。
