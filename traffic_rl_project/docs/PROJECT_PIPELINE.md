### 0.5 已冻结口径（一句话 + 指针，正文不重复）

- **主判据（唯一）** = 确定性评估的**车钩断面力绝对峰值 ≤1200 kN**（`§0.2a`，ADR-067 决策三）；论文主指标必须是 maximum，「逐循环峰值均值 / 超 1000 占比」只作补充栏（ADR-066 决策四）。
- **另两个数已不作判据**：ADR-040 的 **≤1000 kN** 降为**目标值**——如实报"未达成"，禁写"物理不可能"（措辞纪律见 §0.2a ③）；ADR-066 的 **<1280 kN** 降为**中间进度门**（仅表示"优于 M1 的 1280.2"）。**三数并存 = 任何结果都可被重新解释**，故禁止恢复并存状态（ADR-067 背景②）。
- **阈值性质** = 1000 / 1500 是**铁科院建议值**（无国标、无部标；2250 才有国标依据，TB/T 1335-1996）⇒ 论文措辞只许写「采用比建议值更严的内部目标」，**禁写「满足国标 / 达到标准」**；「≤1000 / 1000–1200 / >1200」三档分界是**本项目表述（I 级）**，**禁写「文献通行分档」**。出处见 `papers/LITERATURE_FINDINGS.md` §八。
- **训练量**一律报 **episodes × 每集步数 = 总 env-steps + 更新次数**，禁止只报集数（ADR-064）。
