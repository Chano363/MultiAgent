### 1. 逐机车 RL 智能体实施（承接 P3.5 环境层，补齐训练链路）

- **`multi_loco_controller.py`**：新增 `get_action_decomposed`——规则基线（ED 优先打满 + 逐机车错峰 + ED 不足 AB 兜底）+ RL 逐机车 `[ed_mod, ab_mod]∈[-1,1]²` 调制：ed_mod 直接增减本机车 ED 深度 ±0.5（**真物理杠杆**，对比旧架构阈值协同 ±0.5km/h=带宽 1.25%）；ab_mod>0.5 抑制本机车 AB（仅 vel<v_max-0.5 才生效）、ab_mod<-0.5 提前触发 MIN 档 AB 兜底。
- **ED 可用度物理化**：原 `_ed_ab_price(v)=clip(v/5)` 使基线 AB 兜底在循环制动带内**永不可达**；改为功率约束模型 `F_ed=min(P_ed/v, 粘着上限)/F_req(m·g·最陡下坡)`——陡坡高速 ed_avail<1 → 基线真实触发 AB。
- **`train_fleet_env.py`**：新增 `decompose='loco_ed_ab'` 模式——智能体=每机车（1+1 单列=2 智能体）、逐机车 11 维 obs（含 AB 状态：激活比例/缓解剩余/制动段序号）、奖励加电空分工塑形；`train_fleet.py` 加 `--decompose` / `--decision_interval` 入口，checkpoint `dec_` 前缀隔离。
- **`src/evaluation/evaluate_decompose.py`**（新增正式评估脚本）：三方对比（decompose-M1 RL / decompose-M0 规则 / 单机单控旧架构），确定性 N seed，指标含 ATP 事件、AB 步、meanED、band 率、末速，结果落 JSON。

### 2. 冒烟门控（3000 步，两轮）→ 方案确认

- 轮1（AB 成本 0.2）：coupler **-24%**（734→560kN）但 reward 被 AB 成本等额抵消（-133）；轮2（AB 成本 0.05）：coupler -24% 复现，reward -29≈AB 成本项。
- **方案确认**：AB 是手段、车钩力是目标 → **AB 成本→0**；entropy 0.005→0.002；curriculum 顶到完整 15000 步。

### 3. ⚠️ 阻塞级 bug 修复：`ab_command=None` 残留制动拖停列车

- 首轮全量 15000 步评估发现 decompose M0/M1 **全部拖停列车**（band 2-23%、末速 0）。15000 步追迹定位：第二循环 AB 施加后**缓解永不生效** → 列车在 -10.9‰ 陡坡被残留 SERVICE 制动拖到 0 永久卡死。
- 根因：`train_env.py` `_step_decomposed` 把"无 AB 源"映射为 `ab_command=None`（=不发任何指令），**None ≠ RELEASE**（AGENTS.md 既有 gotcha 的 decompose 变体）。**修复**：无 AB 源时显式发 `RELEASE`。新增回归测试 `test_decompose_ab_release_command_issued`（**149 测试全过**）。修复后 M0：reward -213,652→**+71,261**、band 99.7%。

### 4. RL 层失败 → semi-MDP 决策间隔救回（本段会话核心成果）

- 修复后首次全量重训（60ep，无间隔）：stage-3 训练 reward 平坦 -291k，终模型 AB 挂满全程（13,206/15,000 步）拖停列车——**15000 步时域信用分配失败**（如实记录）。
- **救回方案①（实施）**：`--decision_interval 10`（semi-MDP 动作保持）——RL 每 10 步决策一次、窗口奖励求和存一条转移，信用链 15000 步→1500 决策；rule 基线逐步执行不受影响。
- 压缩冒烟 12ep 即过门控（reward>M0、coupler -23%）；全量重训 stage-3 reward 上升至 **+61,452**（原平坦 -291k）。

## 五、关键结论（给下一智能体）

1. **换架构立论成立**：论文创新点可升级为"**多机车分布式动力 × 电空双制动分工的分层 MARL**"——三层证据链（单机单控 → 规则分工 → RL 分工）全部正增量，且 RL 增量有真物理杠杆（车钩力 -21%、ATP -97%、末速 +11.2km/h），不再是旧架构的 +0.8% 天花板。
2. **旧架构全部结论作废风险**：ITSC_PAPER 仍为旧架构叙事（3 列 1+0 阈值协同），**需按新证据链改写 Methods/Results**——这是当前最大的待办。
3. **"学无可学"的教训有了新解**：旧架构问题=杠杆太小（1.25%）；新架构教训=**超长时域信用分配**（15000 步 PPO 失败）——semi-MDP 决策间隔（动作保持）是本项目验证有效的通用解法，值得写进论文/复用。
4. **场景陷阱（复现时注意）**：①long_downhill 缓坡入口下规则循环制动会过制动致**列车停死**（M0 band 19%），冒烟场景必须用朔黄线剖面+80km/h 起步；②3000 步冒烟会漏掉 15000 步才暴露的问题（WP2 教训再现）；③评估 rollout 间 reset 不完全清空动力学内部状态（seed1/2 结果恒同，首 seed 独热）。
