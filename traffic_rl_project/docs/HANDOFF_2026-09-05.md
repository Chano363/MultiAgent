## 二、本轮完成内容

### 1. 积压提交 + 根因代码审计（固化 baseline）

- **提交** `4699eec`：HANDOFF\_2026-09-04 收尾 + 三重证伪留痕 + 根因审计 + 物理修复 src + 文档治理入库（71 files）。多目录定向提交，**排除** skills/papers/checkpoints/Auto-claude-code-research-in-sleep 等大项。

- **根因审计**（DIAGNOSTICS 代码审计节）：MARL 协同无增量的四大根因——

  1. **控制权过小（最致命）**：`coor_adj` 1D + `adj_coef 0.1` → 阈值偏移仅 ±0.5km/h = 40km/h 带宽的 **1.25%** → reward 对动作梯度≈0（学无可学）；M4 规则用 0.3（3×杠杆）却只给 RL 0.1；
  2. **奖励被低层控速主导**：`speed_band_reward` 完全由规则循环制动决定、与 coor\_adj 正交；唯一敏感项 gap\_reward 分桶无渐变梯度；
  3. **多智能体一致性难收敛**：B 机制 reward 分解证 `gap_reward −82.5万` 灾难全部来自三列协同信号不一致；
  4. **阈值偏移结构不合理**：`v_max_adj=v_min_adj` 整带平移、带宽不变，可压缩的相位自由度极少。

### 2. 方向 A：放大协同杠杆 + 连续梯度（已实施 + 验证）

- **改动**（`--action_dim 2` 可选，不破坏旧评估）：

  - `hierarchical_controller.py`：新增 `get_action_2d`（v\_max/v\_min 独立偏移，可压缩/拉伸带宽，修根因4）；

  - `train_fleet_env.py`：`action_dim` 配置（2 维走 `get_action_2d`）；`gap_reward` 连续化（高斯峰 `exp(-(ge/140)²)` + 拉开>150m 线性惩罚，修根因2）；

  - `train_fleet.py`：`--action_dim`、act\_per\_drone 透传、train artifact 加 `ad{action_dim}_` 前缀隔离检查点。

- **训练**（40ep @3000 步 curriculum，19.3min）：best **+43,117**、avg +42,923、车钩力 563kN、**viol 0**、稳定收敛（best≈final）。

- **门禁**（3000 步确定性 + ETCS）：ad2-M1 **+42,116** vs M3 +41,923 vs M4 +38,923；安全事件峰值 **6,578** vs M3/M4 11,292（近减半）。**A\_PASS**。

### 3. 方向 B：全局观测 + 一致性奖励（已实施 + 验证）

- **改动**（叠在 A 上，全部可选开关）：

  - B1 `group_obs=True`：obs 追加 `[群组速度一致度, 群组制动相位一致度]`（obs\_dim 11→13），每智能体看全局而非只盯前列；默认 False 保持 11 维兼容旧评估/测试；

  - B2 显式一致性奖励：各列制动相位越"同相"越给正、相位分裂给 0（`+0.2·|frac-0.5|·2`）；

  - `train_fleet.py` 加 `--group_obs`、checkpoint 前缀 `ad{action_dim}{g}_`。

- **训练**（40ep @3000，19.6min）：best **+43,941**（> A 的 +43,117）、avg +43,202、车钩力 554kN、**viol 0**。

- **门禁**（3000 步确定性 + ETCS）：ad2g-M1 **+42,786** vs M3 +42,442，**DELTA +343**（A 仅 +193，B 翻倍）；安全事件 7,212 vs M3 11,292（保持近减半）。**VERDICT\_B=PASS**。

### 4. 结论：方案爬到 A→B 天花板，触发"换架构/换立论"决策

- A→B 链路**成立但幅度小**：协同增量从无/负 → +193 → +343（\~0.8%），最可靠增量是**安全**（少用近半 ATP 紧急制动）。

- **关键判断**："学无可学"（根因1）在阈值协同分解下**结构性无解**——加全局观测+一致性奖励（提高学习容量）只把增量从 +193 挪到 +343，**不增加物理杠杆**。继续深度=在不增产能前提前堆学习容量，无效。

## 四、待决策（重大，下一智能体须先读本节再动）

用户当前问题："**如果 MARL 仅负责协同成效甚微、学无可学，有没有必要换一种架构？**" 尚未定论。核心矛盾：**该特分解下"学无可学"是结构性的**，改学习容量救不回杠杆。三选一：

1. **换决策边界 / 换架构（ADR-009 多机车 × 电空分工）**：让 MARL 直接分配**电制动强度 / 是否触发空气制动**——真物理杠杆（非 ±0.5km/h 阈值）；有门控证据（RL 空电分工把车钩力 1116→95kN）；**名实相符**（多机车=真分布式动力多智能体，导师认可）。**这是唯一让 MARL"有真东西可学"的路，但需重构编组+环境+训练（工作量最大）**。渐进式：立论（已 ADR-009/009.1）→ 仿真器稳定（已完）→ 编组改造 → 空电分工冒烟 → 全量训练。
2. **不换主架构、换立论**：承认 MARL=协同配角，论文主打"**同等间距下少用近一半 ATP 紧急制动**" + 实时推理优势（MARL \~0.4ms vs MPC 每步 113-120ms，DIAGNOSTICS 有缩放证据）。最快落地、证据最全；放弃"MARL 增量"大卖点。
3. **找边界场景**（超长编组/极端剖面/多源故障）：唯一可能救回"增量立论"，但先前鲁棒性已证三方法在常见随机化/扰动下无差异，风险最高。

**建议**：①是要"MARL 必须当主角"的唯一解（换架构）；②是要"论文能发、论证诚实"的最快解。请用户拍板，勿擅自选向。
