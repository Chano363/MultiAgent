## 三、⭐ 核心定量结果：列尾压强 → 车钩力（§3）

工况：三列试闸结果相同的列车，k20+000 处列尾压强分别为 585 / 589 / 593 kPa；
k20+500 施加 50 kPa 减压、初速 65 km/h、降至 35 km/h 缓解，完成后续循环制动。

| 初始列尾压强 | 最大**拉**钩力 (kN) | 最大**压**钩力 (kN) |
|:--:|--:|--:|
| 585 kPa | **742** | 1161 |
| 589 kPa | **1058** | 1150 |
| 593 kPa | **1337** | 1166 |

**关键规律**：
- 585 / 589 相比 593 kPa：最大拉钩力 **−44.5% / −20.9%**；压钩力三工况**区别不明显**
- 最大拉钩力均发生于 **109 车（从控机车前钩）**；最大压钩力均发生于 **110 车（从控机车后钩）**
- 最大拉钩力均发生于**第一把闸缓解时**（制动缓解位于 −10.2‰ 长大坡道）
- **拉/压不对称**：列尾压强影响拉钩力（敏感），基本不影响压钩力（不敏感）

**机理链条（可仿真复现）**：
列尾压强高 → 从控机车**后部**车辆制动缸平衡缸压高（表 2：86.5 / 95.3 / 102.7 kPa）
→ 后部制动力强 + 缓解滞后大 → 缓解时前拉后拽 → **拉钩力增大**。

**缓解传播时序（图 5）**：
- 三工况列车**开始缓解时间**：22.3 s / 24.4 s / 27.4 s（列尾压强低→缓解更快）
- 从控机车前部车辆均 **10 s 内**开始缓解（主控+从控双向充风）
- 从控机车后部车辆平均开始缓解：**17.8 s / 19.2 s / 20.9 s**（只有从控机车供风，滞后明显）

**凹形坡压钩力（图 4，与张二田 R4 交叉印证）**：
三工况最大压钩力发生于主控机车 k42+497 / k42+498 / k42+534 处
（坡道由 −11.2‰/−9.3‰ → −2.0‰ → −1.5‰，最大变坡点 k41+136）——
**前缓后陡凹形坡、后部势能大向前涌 + 空电联合** → 大压钩力。
与张二田 2021 的"陡坡转缓坡缓解前阻后涌"规律**完全一致**。

## 五、一句话总结

> 列尾压强是循环制动拉钩力的**主导变量**：585→593 kPa 使最大拉钩力 742→1337 kN（+80%），
> 而压钩力几乎不变；机理是"列尾压强高 → 后部制动缸压高 + 缓解滞后 → 缓解时前拉后拽"。
> 低列尾压强缓解可降拉钩力——这给 Layer-1 规则增加了一条可量化的操纵约束
> （充风程度/列尾压强与缓解时机的联合约束）。
