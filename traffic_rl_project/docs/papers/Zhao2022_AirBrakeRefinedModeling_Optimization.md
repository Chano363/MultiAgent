## 二、核心贡献（作者声明，p7）

1. **空气制动精细化数学模型**：把"空走 + 稳态"两阶段改为 **响应阶段 / 暂态阶段 / 稳态阶段** 三阶段；
   引入 **制动性能修正函数 P_s(t)**（历史制动影响）与 **闸瓦压力分布函数 K_{z,i}(t)**（编组影响）。
2. **2 万吨长大下坡多目标优化模型**：以操纵平稳性、速度跟随性、运行节能性为目标，离散化 + 线性近似
   转化为**标准二次规划（QP）**求解；设计**迭代算法**解决空气制动力与优化速度曲线的适配。
3. **模型与算法验证**：基于实车数据复现运行，分析线性近似误差；用纵向动力学模型与司机实操纵对比。

## 四、公式体系（第 2–3 章）

### 4.1 基础受力（§2.1）

| 量 | 公式 | 备注 |
|:--|:--|:--|
| 单位基本阻力（通式） | w₀ = a + b·v + c·v² | v 单位 km/h |
| HXD1 机车单位基本阻力 | w₀′ = 1.48 + 0.0018v + 0.000304v² | N/kN |
| 滚动轴承货车（重车） | w₀″ = 0.92 + 0.0048v + 0.000125v² | N/kN |
| 整车基本阻力 | W₀ = (w₀′·M_p + w₀″·M_g)·g·10⁻³ | M 单位 t |
| 坡道附加阻力 | w_g = θ | 直接用坡度千分数，上坡正、下坡负 |
| 曲线附加阻力 | w_r = 600 / R | R 单位 m |
| 隧道附加阻力 | w_s = 0.00013 · L_s | L_s 单位 m |
| 空气制动力（紧急） | B = φ_h · ΣK_h | 换算法 |
| 空气制动力（常用） | B_c = β_c · B | β_c 为常用制动系数 |

**常用制动系数 β_c（牵规，表 3-1）**：货物列车（列车管定压 p₁=600 kPa）时，
减压量 r = 50/60/70/80/90/100/110 kPa → β_c = 0.17/0.28/0.37/0.46/0.53/0.60/0.67；
（p₁=500 kPa）→ 0.19/0.32/0.42/0.52/0.60/0.68/0.75。

**换算摩擦系数 / 换算闸瓦压力（式 3-2、3-3）**：

- φ_h = 0.322·(v + 150) / (2v + 150)
- K_h = 1.273·(K + 200) / (4K + 200)，实算闸瓦压力 K 取 20 kN

**机车特性外包络**（式 2-8、2-9）：PDF 文本层存在字符错位，建议以 §5.3.1 拟合式与表 5-1 为准。
优化用的拟合式：

- 牵引（式 5-6，取外包络 90%、考虑黏着限制 600 kN）：F_t(v) ≈ **min(684 − 20.14v + 0.037v², 620)**
- 电制动（式 5-7）：F_eb(v) ≈ **min(18.44v, 461, 545.342 − 0.019v²)**
- 拟合误差：牵引特性平均相对误差 **1.46%**，电制动 **3.64%**

### 4.2 纵向动力学（§2.2.2）

- 单车（式 2-17）：m_i·v̇_i = F_{t,i} + F_{co,i−1} − F_{co,i} − F_{eb,i} − B_{c,i} − W_{0,i} − W_{j,i}
- 钩缓装置：**MT-2 型摩擦式缓冲器**，加载曲线 f_u / 减载曲线 f_l + 刚度项 k·Δx（式 2-16）
- 积分器：**翟方法**（预测–校正，式 2-19），利用当前与上一时刻加速度

### 4.3 三段式空气制动精细模型（§3.2，核心）

阶段划分（图 3-3，t₀ 为手柄动作时刻）：

| 阶段 | 时段 | 物理含义 |
|:--|:--|:--|
| 响应（空走） | t₀ → t_{d,1} | 手柄动作 → 头部车辆制动缸开始充气，取常数 |
| 暂态 | t_{d,1} → t_{m,N} | 头部车辆开始充气 → **尾部车辆充气结束** |
| 稳态 | t > t_{m,N} | 列车管压力稳定的有效制动，直至缓解 |

**制动力（式 3-4）**：

- t ≤ t_{d,1}：B_c(t) = 0
- t_{d,1} < t ≤ t_{m,N}：B_c(t) = β_c · C_β · Σᵢ [ φ_h · K_{z,i}(t) ] · P_s(t)
- t > t_{m,N}：B_c(t) = β_c · C_β · Σᵢ [ φ_h · K_h ] · P_s(t)

连续性约束（式 3-5）：t = t_{m,i} 时 K_{z,i}(t) = K_h。

**实时闸瓦压力分布函数（式 3-11 ~ 3-14）**：

- K_{z,i}(t) = K_h · [ (t − t_{d,i}) / (T₁ + Δt_i) ]^{λ_z}
- Δt_i = T_{i+1} − T₁（第 i 辆与第 1 辆充气时长差）
- t_{d,i}、Δt_i 按 **1+1 编组的制动波双向传播**分段表达（式 3-13/3-14），由 γ_z、K_z 控制非线性分布

三个特性参数（§3.3.1）：

| 参数 | 物理意义 | 典型值（辨识结果） |
|:--|:--|:--|
| λ_z | 制动控制阀特性：闸瓦压力上升曲线形状（紧急/大减压量上升快） | **0.9** |
| γ_z | 制动波波速特性：<1 前慢后快；=1 匀速；>1 先快后慢 | **1.1** |
| K_z | 制动缸充气特性：越远车辆充气时间越长的"发散程度" | **1.1** |

**历史操纵修正函数（式 3-6 ~ 3-10）**：

- P_s(t) = 1 + (L_s − 1) / (1 + e^{−λ_s·(t − Q_off)·T_s})，其中 L_s = T_{LastREL} / T_{SetREL}
- Q_off = k_s · S_tmp（闸瓦温度影响因子，S_tmp 为调速制动工况闸瓦温度–时间拟合曲线）
- L_s 由上一制动段缓解时间 / 标定充风时间之比刻画；b_s、a₀/b₀/c₀ 为关联因子常数

修正函数三参数（§3.3.2）：λ_s（上升斜率，"由弱转强"）、k_s（闸瓦温度影响程度，越大越差）、
K_s（历史缓解时间影响程度，越大→开始上升越晚、幅值越小）。

**参数辨识**：遗传算法，4 个参数（λ_s、k_s、K_s、C_β）各 10 位二进制编码成染色体；
适应度 = 仿真速度曲线与实车速度曲线偏差平方和（式 3-15）。

### 4.4 QP 优化模型（§4）

- 目标（式 4-1）：J = ∫[ w_e·F_t·η_t + w_v·(v − v_r(s))² + w_f·(ΔF_eb)² ] ds（节能 + 速度跟随 + 平稳）
- 运动学（式 4-2）严格按牵规；控制量 u = F_t − F_eb − B_c（式 4-7）
- 约束（式 4-3~4-5）：能力边界（牵引/电制动包络、力变化率、牵引电制动互斥 F_t·F_eb = 0）、
  运行边界（线路限速、电分相处 F=0）、端点状态
- 离散化：里程域 Δs = 10 m，转为标准二次规划
- **迭代算法**：空气制动力无法线性近似 → 利用模式化速度曲线主体特征一致性，
  把空气制动力作为**附加阻力**引入，迭代至与优化速度曲线匹配

|:--|:--|:--|

1. **制动波传播实测参数**（t₁=0.4 s、t_N=14 s、T₁=12 s、T_N=44 s）→ 标定 `braking.py` 的波速与充气时长；

## 八、一句话总结

> 2 万吨重载列车长大下坡场景下，**用三段式空气制动精细模型替代牵规两阶段模型**（适应度好近一个数量级），
> 再以 QP 求解电制动操纵序列，压钩力最多降 29.49%，叠加操纵规则后降 33.74%；
> 但作者明确指出**其优化框架未以纵向动力学为基础，故无法把车钩力作为优化目标**——
> 这正是本项目分层 MARL 的立足点，其实测数据同时为制动波速、循环制动衰减、车钩力量级提供了标定基准。
