## 方法要点

1. **空气制动力时变预测（主贡献①）**：实车 LKJ-2000 数据统计证明同减压量下不同制动段制动力差异大且无单调性（示例一趟车：2 028→1 718→1 342→993→…→1 289 kN）；BP 网络（5-32-1，LM 优化）以「上一段制动时长/制动距离/充风时间/稳态力 + 首段稳态力」预测下一段稳态力；75% 样本误差 <100 kN、90% <200 kN。
2. **RL 设计（主贡献②）**：Q-learning + 经验池；**动作 = 级位增量** a∈{a_min..a_max}（级位限 ±12，单步变化限 3）；**空气制动 on/off 不进动作空间**——由级位越限 + 最小充风时间 180 s 派生；奖励 = 速度跟随（r + r_v，越界罚 0）**不含车钩力**（明确理由：车钩力算进单步奖励训练太贵），平稳性以级位切换幅度约束间接保证。
3. 状态空间：位置/速度/级位/加速度/空压状态 + 制动历史五元组。

## 对本项目的三处直接映射

1. **间接平滑通道替代直接车钩罚**：车钩力改善经由「级位增量动作 + 切换幅度罚」获得，而非把车钩力塞进奖励——v20（直接调 COUPLER_PEAK_W）塌缩的文献解法；我们的 `ab_notch_hold_s=90` 对应其 180 s 充风约束（更长）。
2. **空气制动性能时变性**：文献把「前序制动历史改变下一段制动力」当核心 contribution；若本项目 env 未建模此效应，既是与文献的差距，也是可增补的卖点素材（且是 real-world effect，审稿友好）。
3. **动作空间设计**：级位增量（±3 限幅）比绝对档位 + 90 s 保持更贴近文献验证过的设计；空气制动 on/off 派生化减少了动作维度。
