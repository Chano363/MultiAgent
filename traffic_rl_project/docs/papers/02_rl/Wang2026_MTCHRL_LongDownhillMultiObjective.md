## 架构（施工图价值）

1. **事件驱动任务分类**：组合空电制动任务（长大下坡，目标=钩缓力稳定+速度安全）vs 单牵引/电制动任务（起伏段，目标=速度跟随+能耗）。
2. **底层 = D3QN**（double + dueling，ε-greedy 余弦衰减 1.0→0.05），**顶层 = 动态规划**（状态=「区段索引−上一任务类型」，代价含平均速度偏差与平均最大钩缓力，不可行赋 ∞）。
3. **混合动作空间**：单制动任务=电制动/牵引比例离散 21 档；组合制动任务=电制动比例（区间缩至 (−1,0)）+ 空气制动 on/off 整型。
4. **时间累积约束入状态空间**（累计制动/缓解时长、最大钩缓力、目标速度）→ 转标准马氏过程。
5. **奖励**（每任务多目标）：速度跟踪 + 能耗 + 空气制动（即时 + 历史缓解条件）+ **钩缓力（全列最大值/限值之比）** + 行为罚。
6. **分段粒度实验**：10 km 分段 ≈2500 episodes 收敛；20 km ≈3200；50/100 km 5000 不收敛。

## 关键数字（绝对值处理务必谨慎）

| 指标 | MTC-HRL | 单智能体 D3QN |
| :--- | :--- | :--- |
| 最大拉钩力 | **315.67 kN** | 177.77 kN |
| 最大压钩力 | **−301.96 kN** | −240.16 kN |
| 平均速度 | 70.03 km/h | 59.73 km/h |
| 能耗 | −1196.66 kWh（含再生回收） | −782.38 kWh |
| 收敛 | ≈3500 s（快 40–50%） | ≈3700 s |

- **1100 kN 是安全限值（约束）而非成绩**；其仿真产力 ~300 kN，比大秦线同工况实测（循环制动 >1500、接近 2000 kN）**低 5 倍以上** ⇒ 其动力学模型产力远低于真实，**跨文献绝对值不可比**（2026-11-17 litcheck 结论）。
- 分层法相对单智能体基线车钩力**反而更大**（315 vs 178），论文自述「以部分舒适性换显著速度提升」——文献界同样在做此 trade-off。

## 对本项目的映射

- 事件驱动分段 + 任务分解是**架构升级窗口（选项 d）**的直接参考；混合动作空间（连续比例 + on/off 整型）与本项目 `loco_ed_ab`/`loco_notch` 的设计同族。
- 收敛效率提升（40–50%）主要来自任务分解降低问题复杂度，非奖励技巧。
- 自陈局限（GAP 素材）：环境剧变需重训/在线微调；未覆盖异构多机车协同（= 我们多智能体场景的差异化空间）。
