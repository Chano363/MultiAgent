## §2.1.2 研究内容

（原图 `e7496e08b10e3c91c23d609ad825ad14.png`）

为实现上述研究目标，本文围绕重载列车虚拟编组动力学建模、基于改进 MASAC 多智能体纵向稳定控制和多场景下的协同控制三个方面开展研究：

**（1）重载列车虚拟编组动力学建模与控制需求分析**

在已有重载列车多质点动力学和虚拟编组模型的基础上，建立考虑牵引力、电制动力、空气制动延迟、非线性车钩缓冲器及线路阻力的统一模型，重点分析列车内部纵向动力学与列车间速度、间距协同之间的相互影响，为后续研究车钩力主动抑制和多场景下的协同控制提供模型基础。

**（2）基于多智能体的重载列车虚拟编组纵向稳定控制**

针对现有强化学习方法控制动作离散、车钩力主要在超限后进行惩罚的问题，研究基于改进 MASAC 多智能体的连续动作协同控制方法。通过构造车钩力风险自适应奖励，并结合牵引制动动作安全修正，协调速度跟踪、间距保持、车钩力抑制和制动动作平稳性，提高虚拟编组列车的纵向运行稳定性。

**（3）多场景下重载列车虚拟编组协同控制方法**

针对长大下坡场景下空气制动延迟和纵向冲击，以及过分相场景下牵引与电制动力能力阶段性受限的问题，考虑不超过判断为通信中断的随机时延，研究基于改进 MASAC 多智能体的虚拟编组协同控制方法，实现多列重载列车在多场景下的稳定运行及过分相后的队形平稳恢复。

## 研究思路段（总述）

（原图 `27cb7ed5f817443205927736c922f5b9.png`）

针对重载列车虚拟编组纵向动力学建模、多智能体纵向稳定控制及多场景协同控制问题，本文拟按照"动力学建模与需求分析—改进 MASAC 纵向稳定控制方法设计—多场景协同控制与仿真验证"的思路开展研究。首先，建立考虑牵引与电制动、空气制动延迟、非线性车钩缓冲作用及线路阻力的重载列车虚拟编组多质点纵向动力学模型，分析影响编组稳定运行的主要因素；其次，研究基于改进 MASAC 的多智能体纵向稳定控制方法，在实现速度跟踪和间距保持的同时抑制单元列车内部纵向冲击；最后，面向长大下坡和多列重载列车依次通过分相区场景，研究多智能体之间的协同控制，并通过仿真分析所提方法的稳定性和安全性。

## §2.2 拟解决的关键问题及难点

（原图 `308191ae6399f71ff04cf4947f1c4e5b.png`，页码 7）

### 2.2.1 重载列车虚拟编组多质点动力学建模问题

重载单元列车内部存在空气制动延迟和非线性车钩缓冲作用，列车间速度与间距变化还会影响单元列车内部纵向受力。如何在保证计算效率的同时，建立能够反映列车间运行状态和内部车钩力变化的动力学模型，是后续稳定控制研究的基础。

### 2.2.2 多目标约束下的纵向稳定控制问题

虚拟编组控制不仅需要实现速度跟踪和间距保持，还应抑制车钩力和控制动作波动。如何改进 MASAC 多智能体的信息交互与奖励机制，并结合牵引制动动作安全修正，在多个控制目标之间取得合理平衡，是提高虚拟编组纵向运行稳定性和安全性的关键。

### 2.2.3 多场景下的多列车协同控制问题

长大下坡和多列车依次通过分相区场景下，列车牵引制动能力和运行状态会发生变化。如何利用多智能体之间的信息交互，协调各列车的速度、间距及运行过程，使虚拟编组在场景转换前后保持稳定并满足安全约束，是多场景协同控制需要解决的难点。

## 虚拟编组层面建模与安全边界

（原图 `f9e6487c698d5d658bcc81bb3c09b299.png`）

在虚拟编组层面，各单元列车之间没有物理车钩连接，而是通过车车通信交换位置、速度、加速度和控制指令等信息。设相邻两列单元列车之间的实际间隔为 $d_k$，期望间隔为 $d_k^*$，则间距误差可表示为：

$$e_{d,k} = d_k - d_k^*$$

结合后车运行速度、制动响应时间、制动能力及安全裕量建立列车间安全边界，使后车在前车状态发生变化时仍具备足够的制动距离。在此基础上，分析线路坡度、空气制动延迟、单元列车参数差异和初始间隔等因素对速度误差、间距误差、单元列车内部车钩力及扰动传播的影响，明确后续控制方法所需的状态信息和约束条件。

## §2.3.2 基于改进 MASAC 的重载列车虚拟编组稳定控制方法

（原图 `009889fcac80105e825ba025d12cfb3f.png`）

重载列车虚拟编组由多列能够独立牵引和制动的单元列车组成，各列车的控制行为相互影响，且牵引和制动指令属于连续控制量。因此，本文将虚拟编组稳定控制问题转化为多智能体连续决策问题，采用 MASAC 的集中训练、分散执行结构。虚拟编组中的每列单元列车作为一个智能体，训练阶段的评价网络使用各智能体的联合状态和联合动作，各策略网络根据本列车能够获得的状态信息输出控制动作；执行阶段不再依赖集中控制器，各列车独立完成控制决策。

智能体状态空间主要包括本列车位置、运行速度、目标速度及速度误差，与前车之间的实际间隔和相对速度，领航列车及直接前车的运行状态和控制信息，当前线路坡度和限速条件，牵引制动可用状态以及单元列车内部的代表性车钩力。对于第 $k$ 列单元列车，其观测状态可表示为：

$$o_k = [v_k,\ e_{v,k},\ a_k,\ e_{d,k},\ \Delta v_k,\ u_{k-1},\ g_k,\ F^c_{k,\max},\ b_k]$$

式中，$e_{v,k}$ 为速度误差，$\Delta v_k$ 为与前车之间的相对速度，$u_{k-1}$ 为领航列车或直接前车的控制信息，$g_k$ 为线路坡度，$F^c_{k,\max}$ 为单元列车内部代表性车钩力，$b_k$ 为空气制动状态。实际状态变量将根据模型分析结果进行筛选和归一化，避免将单元列车全部质点状态直接输入策略网络而造成状态维数过高。

动作空间采用连续控制量表示机车的牵引与制动需求。动作大于零时输出牵引指令，动作小于零时输出制动指令。制动过程中根据机车当前速度和电制动能力优先分配电制动力，不足部分由空气制动补充。牵引和制动不能同时作用，空气制动的施加和缓解还需要满足其传播及压力响应特性，避免控制器产生频繁的牵引—制动切换。

奖励函数由基本控制目标、运行安全约束和稳定性改进项共同构成，可表示为：

$$r_k = r_{v,k} + r_{d,k} + r_{s,k} + r_{c,k} + r_{u,k} + r_{lim,k}$$

针对固定车钩力惩罚难以反映纵向冲击风险变化的问题，本文根据车钩力接近安全限值的程度构造风险指标。（→ 见下节）

## 车钩力风险自适应奖励 + 动作安全修正

（原图 `c7f7536deec336d22b2355bb889ed977.png`）

考虑拉钩力与压钩力的允许限值不同，第 $k$ 列单元列车的车钩力风险指标可表示为：

$$\rho_k = \max\left(\frac{F^{c+}_{k,\max}}{F^{c+}_{lim}},\ \left|\frac{F^{c-}_{k,\min}}{F^{c-}_{lim}}\right|\right)$$

式中，$F^{c+}_{k,\max}$ 为单元列车内部最大拉钩力，$F^{c-}_{k,\min}$ 为最大压钩力，$F^{c+}_{lim}$ 和 $F^{c-}_{lim}$ 分别为拉钩力与压钩力安全限值。$\rho_k$ 越接近 1，表明车钩力越接近安全边界。根据风险指标动态调整车钩力惩罚权重，车钩力奖励项表示为：

$$r_{c,k} = -w_c(\rho_k)\,\rho_k^2$$

式中，$w_c(\rho_k)$ 为随车钩力风险增大而提高的自适应权重。车钩力风险较低时，控制器兼顾速度跟踪、间距保持和控制平稳性；当车钩力接近安全边界时，提高车钩力惩罚强度，使控制策略在超限前主动抑制纵向冲击。

为避免策略网络在训练探索或运行状态变化时输出不合理的牵引制动作，策略网络与重载列车动力学模型之间设置动作安全修正环节。将策略网络输出的原始动作 $u_k$ 投影至当前状态对应的安全动作集合中，实际执行动作表示为：

$$\tilde{u}_k = \Pi_{(U_k^{safe})}(u_k)$$

安全动作集合根据线路限速、列车间安全间隔、机车牵引制动能力、空气制动状态和车钩力风险确定。当间距或车钩力接近安全边界时，对可能继续增大风险的牵引制动作进行限制，并约束相邻时刻动作变化幅度，以减少频繁的牵引—制动切换。该环节仅对策略网络输出进行必要修正，不替代 MASAC 的策略学习。

## 学习要点速览（本目录内速查，详见分析）

1. **车钩力风险指标 $\rho_k$ + 自适应权重 $w_c(\rho_k)$**：拉/压分开限值、越近界惩罚越重、超限前就介入——比固定权重惩罚更平滑，无死区。
2. **动作安全投影 $\Pi_{U^{safe}}$**：安全集合 = 限速 + 间隔 + 牵引制动能力 + AB 状态 + 车钩力风险；外加**动作变化率约束**（防频繁牵引—制动切换）；"仅修正、不替代策略学习"的免责表述可直接学。
3. **状态设计**：$o_k$ 含前车控制量 $u_{k-1}$、坡度 $g_k$、AB 状态 $b_k$、代表性车钩力——与本项目 12 维 obs 对照查漏。
4. **连续动作内部分配**：电制动优先、空气制动补足、AB 传播/压力响应约束写进动作语义。
5. **建模清单**：牵引 + 电制动 + AB 延迟 + 非线性车钩缓冲 + 线路阻力（多质点统一模型）——可作模型完备性 checklist。
6. **场景扩展**：过分相（牵引/电制动能力阶段性受限）+ 通信随机时延——本项目未覆盖，可作 future work。
