## 三条必须马上知道的结论

1. **V13（已实测，结论反转）**：同 ckpt 只改 `coupler_override: release → min_brake`，**全部指标逐位相同到小数点后 15 位**。根因不是配置，而是**规则 A 逐车作用**——1+0 编组只有机车有动作，超限发生在货车，货车动作恒为 0，减 0 还是 0。⇒ **车钩保护层在 1+0 编组下等于不存在**，`release` 与 `min_brake` 等价且都无效。`safety_events` 11.9 万次全是空转。
2. **V14**：`release` 同时释放 AB 与 ED 的旧判断**已撤回**（建立在上条错误之上）。跟随列 4/8 次 AB 仅 0.1–0.2 s、速度降幅≈0 是事实，但**成因待查**（转 V15）。
3. **V02**：策略只用 `{−0.05, 0}` 两档**不是退化**，循环制动一律 50 kPa 是文献唯一做法。此前"档位退化"的判断已撤回。
