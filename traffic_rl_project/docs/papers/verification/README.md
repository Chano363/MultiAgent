> **角色**：回答一个很窄的问题——**「我们依赖的这条假设，文献支持吗？不成立的话要不要改代码/协议？」**
> **不是什么**：不是文献综述。逐篇证据、原文引述、机制对照仍在 [`../LITERATURE_FINDINGS.md`](../LITERATURE_FINDINGS.md)。
> **何时读**：动手改参数 / 改协议 / 重训**之前**；论文里写"按文献惯例"之前；有人问"这个数为什么这么取"之前。

## 一、为什么要单开这个目录

项目的「白跑」有过多次前科，类型高度一致：**某个假设没验证就进了训练或论文，事后发现不成立，前面所有机时与结论作废**。

已发生过的实例（每条都能在 `docs/logs/` 查到）：

| 事故 | 假设 | 实际 | 代价 |
|---|---|---|---|
| 80 km/h 作线路限速 | 代码默认值 80 被注释成"线路限速" | `speed_limit.xlsx` 最高 75，无 80 段 | 即将重训前发现 |
| 1400 集 × 5 seed | 把已废止口径当现行 | ADR-064 已砍 | 预算与排期全错 |
| GA 12 旋钮"搬到主协议" | 以为旋钮现行 | 那组旋钮按 LRN-20261111-001 已作废 | 差点白跑 11 min |
| 1163.69 kN 当基线 | 以为只差起点 | 旋钮组与初始条件**同时**变，混淆变量 | 该数无任何合法位置 |
| 40 km/h 记为 1 万吨值 | 记忆偏差 | 原文是 20,000-ton | 判据归属写错 |

这些都不是"文献读得少"，而是**没有把"我依赖什么假设"显式列出来逐条闭合**。本目录就是那张清单。

## 二、与其他文档的分工（避免同一口径写两遍）

| 文档 | 管什么 | 本目录与它的关系 |
|---|---|---|
| [`../LITERATURE_FINDINGS.md`](../LITERATURE_FINDINGS.md) | 按**主题**组织文献证据（阈值、降峰杠杆、参考速度…） | 分工规则写在它的 **§十**，含一张"什么内容写在哪边"的判定表 + 已建立的交叉指针。本目录产出新的 P 级证据时，**正文只写在条目文件里**，FINDINGS 不复制 |
| [`../../VALIDATION_BASELINE.md`](../../VALIDATION_BASELINE.md) | 仿真器**已完成的**验证判据（V1–V4） | 本目录只处理"尚未闭合"的；已进 VALIDATION_BASELINE 的不重复登记 |
| [`../../logs/decisions/DECISIONS.md`](../../logs/decisions/DECISIONS.md) | 拍板结论与理由 | 本目录给**输入**，不改决策；决策落地后在这里把状态改为「已进 ADR」 |

## 三、条目规范

**编号**：`V01`、`V02`… 不复用、不重排。作废条目保留并标 `作废`，不删号。

**状态机**（`LEDGER.md` 每行必填其一）：

| 状态 | 含义 | 下一步 |
|---|---|---|
| `待查` | 已识别，尚未动手 | 排优先级 |
| `查证中` | 正在查 | — |
| `已闭合` | 有确定结论，**且已判断要不要改** | 若需改 → 挂 `PROJECT_PIPELINE §0.3` |
| `不可验证` | 本地+在线都拿不到（闭源/无图/无数值） | 写清缺什么，降级为 `I` 级表述 |
| `转实测` | 文献给不出，只能自己跑 | 进实验队列 |

**证据级别**：沿用 `LITERATURE_FINDINGS.md §一` 的 P/W/C/I 四级，**不另立标准**。

**每条必答四问**（缺一条不算闭合）：

1. 我们要验证的**具体假设**是什么（一句话，可判定真假）
2. 文献**怎么写的**（原文 + 中译 + 出处级别）
3. 对我们的**判决**：支持 / 不支持 / 不足以判定
4. **要不要改代码或协议**；要改则给改动点与代价

## 五、纪律

1. **一条假设一条编号**。不要把"初速 + 升压时间 + 波速"塞进一条，否则闭合一半就说不清。
2. **判决必须落到「改/不改」**。"文献说法不一"不是结论，要么给区间，要么标 `不可验证`。
3. **数值不抄第二份**。同一个数只能在唯一位置定义，其余引用 ID。
4. **不许用"文献普遍""领域通行"**，除非有计数（n 篇中 m 篇）。样本 < 5 时只能写"本文检索到的 n 篇中"。
