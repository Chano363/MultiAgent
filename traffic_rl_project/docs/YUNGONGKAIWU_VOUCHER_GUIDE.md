## 0. 你的券的关键前提（决定策略）

- **生效日 2026-11-16**，在 **2026-07-14 之后** ⇒ 适用**新规**：三方直供模型 + 指定商品名（万相/ Happy / 向量排序 / 垂类 / 语音 / 千问全模态）的后付费费用**不支持抵扣**（7-14 之前领取的老券才不受此限）。
- **有效期 = 自领取之日起一年** ⇒ 你的券约 2027-11-16 到期。活动期本身是 2025-11-11 ~ 2027-03-31，但**已到账的券按"领取日起一年"算**。
- 券**不抵扣**已享折扣/优惠的账单（看账单"优惠"字段）；模型处于活动折扣价期间，其按量调用也抵不了。
- 代金券**不计入**账户可用现金余额；后付费场景系统会冻结当月消费额，**账户实际现金余额须 > 当月冻结金额**才能正常调用模型——这是很多"明明有券却调不通"的真正原因。

## 1. 结论：直接用 API 可以吗？

**可以，但只对"商品名称 = 百炼大模型推理"的调用**。用 OpenAI 兼容接口或 DashScope SDK 调 qwen 文本模型（`qwen-max`、`qwen-plus`、`qwen-flash` 等），账单商品名就是"百炼大模型推理"，后付费部分**自动进入抵扣池**——不用手动选券，系统按"应付金额 = 目录用量总价 - 优惠合计（含优惠券抵扣）"出账。

**避开这些**（你的券抵不了）：万相 wan 系列、HappyHorse 系列、qwen 全模态/语音/垂类/向量排序、三方直供（账单"所属产品=云市场三方"）、联网搜索等单独计费附加项、任何带折扣的账单。

## 2. 用掉 300 元的两条路径

### 路径 A：按量 API 调用（推荐，最灵活）
1. 百炼控制台开通模型服务 → API Key 页面创建 Key；
2. 写代码调 qwen 文本模型（见下方样例），真实产生 token 消耗；
3. 费用按分钟出账（2–10 min 延迟），商品名"百炼大模型推理"，系统自动用代金券抵扣；
4. 在账单明细的"费用详情"抽屉核对：应付金额 = 目录总价 - 优惠合计（含优惠券抵扣）。

适合：本就有 LLM 调用需求（论文润色、代码辅助、批量文本处理），把原本要付的钱换成消耗券。

### 路径 B：买 50 元"高校 AI 通行证模型节省计划"（一次性抵扣，最稳）
- 官方明确：可用抵扣金抵扣该节省计划的**购买费用**，单人限 1 次，首次自费购买享 5 折补贴（以活动页为准）；
- 抵扣范围同 AI 通用型节省计划，但**不享受档位折扣**；
- 注意：买节省计划 ≠ 抵扣金花完 300，只是花掉其中 50（券余额仍可用于后付费）；节省计划额度用完后转后付费的部分，仍按新规判断能否抵。

## 3. 调用样例（OpenAI 兼容，Windows PowerShell 设环境变量）

```powershell
$env:DASHSCOPE_API_KEY = "<你的百炼 API Key>"
```
```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DASHSCOPE_API_KEY"],
    base_url="https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1",
)
resp = client.chat.completions.create(
    model="qwen-plus",            # 文本模型：账单=百炼大模型推理，你的券可抵
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```
`{WorkspaceId}` 换成为你业务空间 ID（百炼控制台右上角可见）。

## 4. 省钱/防踩坑要点

- **先查券状态和余额**：费用与成本 → 账户 → 卡券 → 优惠券，确认生效 2026-11-16、失效约 2027-11-16、余额 300；
- **确保账户现金余额 > 0**：券不算现金余额，账户欠费（包括本账号 ECS/OSS 等其他产品的未结清费用）会导致百炼调用被限制；
- **别用 Token Plan / Coding Plan 的 Key 调**：那几种是独立套餐，不走后付费抵扣金；必须用"按量计费"的百炼 API Key；
- **查消耗**：百炼控制台 → 费用用量 → 模型用量，可按模型/API Key 看 token；账单明细可核对券抵扣了多少；
- **一节 Battery**：如果只是想快速花掉，优先路径 B（50 元通行证，稳）＋ 路径 A 把剩余额度用 qwen-plus 慢慢跑。
