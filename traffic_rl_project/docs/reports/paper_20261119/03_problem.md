# 3 Problem Formulation

## 3.1 研究对象与物理设定

**编组**。三列万吨级 1+0 单元，每列 1 台机车 + 108 辆货车，单列总重 10 988 t、编组长度约 1 296 m。列内车钩为 MT-2 断面力口径，**列间无机械连接**——三列在物理上是相互独立的列车，"编队"由各列的决策共同维持。

**线路**。朔黄线宁武西—北大牛 49.6 km 连续长大下坡真实纵断面（0.1 km 粒度里程-坡度数据合并为 50 个坡段），坡度范围 −1.3‰ 至 −12.0‰，含 7 个变缓点；同源分段限速表 70/75 km/h 交替 4 段，曲线半径 32 处（附加阻力按曲率计入）。

**动力学**。每列由多质点模型描述，包含非线性钩缓迟滞与制动波传播（制动建立期 + 缓解期的前向/后向波速差）。物理步长 0.1 s。

## 3.2 编队感知 MDP

把三列群组的操纵问题建模为**部分可观测的多智能体 MDP**（Dec-POMDP）。智能体划分取**机车级**：每台机车是一个智能体，本配置下共 3 个智能体（`n_agents = 3`）。

**状态与观测**。每个智能体取 12 维局部观测：

| 索引 | 含义 |
|---|---|
| 0 | 速度误差 |
| 1 | 超上限裕量（$v - v_{\max}$） |
| 2 | 低下限裕量（$v - v_{\min}$） |
| 3 | 规则基线电制动（ED）请求 |
| 4 | 规则基线空气制动（AB）请求（0/1） |
| 5 | 本机车局部车钩力（归一化） |
| 6 | AB 激活比例 |
| 7 | AB 缓解剩余比例 |
| 8 | 制动段序号（缩放） |
| 9 | 本机车位置（归一化，用于推断剖面位置） |
| 10 | **本列列间间距误差**（相对动态目标间距 $d_{\text{eff}}$） |
| 11 | **AB 充风就绪度**（距上次 AB 释放的充风时长 / $t_{\text{refill}} \in [0,1]$） |

其中第 10、11 项是**编队上下文**与**长滞后可观测量**的载体：前者使策略能感知列间几何关系，后者把"空压制动尚不可用"这一百秒量级的时标状态显式交给策略，而不是让策略从奖励里猜。

**动作空间**。本文采用**级位增量**形式：每个智能体输出 1 维连续量，为本步电制动档位的增量（限幅 ±3 级/决策步），电制动深度由级位派生，空压制动由级位越限派生。这一选择对标同组前作 Wang2023 的级位增量设计（±3 级、限 ±12），其平滑性收益来自"级位切换幅度罚"而非直接惩罚车钩力总量。

**决策时标**。策略决策间隔 10 个物理步（1 s），物理步长 0.1 s。

## 3.3 目标与奖励结构

编队目标由三部分承载：

- **领航列的速度跟踪**：锚定分段限速带，形状取"跟踪规则基线参考速度"的单峰有界二次项（全程有梯度，参考速度已限幅于 $v_{\max}$，朝参考跑快不可能越过限速）。
- **跟随列的相对锚定**：镜像前列的可行轨迹（相对速度偏差的二次衰减），避免在绝对带于多坡段物理不可达时把跟随列一起压死。
- **列间几何**：间距效率项（贴近动态目标间距 $d_{\text{eff}}$ 越好）与间距危险项（跌破 ATP 安全线 $d_{\text{safe}}$ 的陡罚，不封顶）构成 ATP 对齐的两段式。

其中动态目标间距取

$$d_{\text{eff}} = \kappa \cdot d_{\text{safe}}, \qquad \kappa = 1.1$$

$d_{\text{safe}}$ 为该列相对前列的 **ATP 制动安全距离**（从当前速度与位置把速度降到前列当前速度所需距离，含制动建立期与真实坡度分量），与安全层的 ATP 判据同源。

奖励按**加性标量化**组合。设正项集合 $\mathcal{P} = \{v_{\text{band}},\, \varphi_{\text{rel}},\, \eta_{\text{gap}}\}$，负罚项集合 $\mathcal{N}$ 覆盖超线速、间距危险、车钩力峰值与超限、制动缸压梯度、级位切换幅度、AB 与 ED 成本：

$$r_t = \sum_{k \in \mathcal{P}} m_k^{(t)} \, p_k^{(t)} \;+\; \sum_{j \in \mathcal{N}} n_j^{(t)}, \qquad m_k^{(t)} \in [1,\, m_{\max}]$$

乘子 $m_k^{(t)}$ 由第 4.3 节的抗分项交换组合算子给出，负罚项权重恒定。

## 3.4 分层安全架构

本文的核心设计选择是**安全不由奖励保证**，而由运行时确定性层强制。安全层在动作执行侧对策略输出做修正，规则按优先级顺序施加（后施加者以更严者覆盖前者）：

| 序 | 规则 | 作用 |
|---|---|---|
| A | 车钩力缓和 | 断面力接近上限时钳制电制动深度，不得为缓解车钩力而放掉已下的防追尾制动 |
| B | 间距防挤压 | 列间间距低于安全下限时施加制动力 |
| C | 反应式超速 | 超出线速时钳制 |
| D | ETCS 前瞻监督（最高优先级） | 限速超前介入、EBI 触发时强制紧急制动 |

其中 D 的优先级设定来自一条硬约束：规则的施加顺序必须与优先级顺序一致，否则"为压车钩力而放掉防追尾制动"会构成自毁闭环——后列刹不住逼近前列，列间受压车钩力破限，车钩力规则随即把刚下的电制动钳回 0，后列因空气制动建立需时（约 10 s）而失去即时制动继续下探，最终间距穿负。

**因此本文不在车钩力上主张对比胜出**：该指标由安全防护架构保证，属底线记录（详见第 5 章与第 7.3 节的边界说明）。
