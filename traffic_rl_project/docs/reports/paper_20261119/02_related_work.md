## 2.1 三类标准方法与它们各自的边界

领域内应对长大下坡多列协同的方法可归为三类，本节逐类给出其在本工况下的边界，随后说明本文的
定位。

**（一）行业规则与驾驶规程类。** 这类方法以司机操纵规程与实车试验标定的时序参数为基础
（循环制动的触发/缓解速度门、缓解时的电制力保持、最小充风时间等），在本工况下具有明确的工程
可执行性，也是本文用作对照的"规则基准"。其局限在于：时序参数是**开环标定**的，无法根据实时的
编队状态（前列的间距与速度差）调整缓解时机，因此在多列协同场景下，缓解与再施加的相位关系不受
编队状态约束。

**（二）模型优化类（MPC/MILP/DP）。** 这类方法把多列协同写进优化问题：追踪间隔进入硬约束
（多列 DMPC 工作）、不确定扰动用管束包住并在优化器内写死严格间距约束（管式 MPC 工作）。其优势
是**约束强度高**：前者给出有界性证明，后者给出闭环误差有界性。值得注意的是，这类工作普遍**不
决策空气制动的施加**，而是把"空气制动力与坡道阻力的失配"建模为**有界扰动**，仅以电制动作补充
修正——这一范式边界直接决定了它能报哪些可比项（原文报数项为速度跟踪误差与间距误差，车钩力在长大
下坡段仅给定性描述）。这一范式边界也构成本文对照设置的解释：**本文方法把空气制动的施加时机纳入
决策，同时不与之争夺约束优先级**。

**（三）强化学习类（单列 → 多列）。** 从单列循环制动的 Q-learning/DQN，到编队场景下的多智能体
方法，普遍采用加性复合奖励。最近的一篇面向重载列车组的工作把速度跟踪、列距保持与相对速度三项
误差合成复合奖励，并引入势场安全引导奖励，其对比对象是**同算法的标准版本**（"改进方法 vs 简化版"
的消融式对比），结论是训练收敛更快、速度同步精度更高、牵引能耗更低，且无安全违反。

## 2.2 领域内对比范式的横向结构：三类范式、六个指标家族

在逐篇梳理之后，一个更值得陈述的结构性事实浮现：**领域内的对比范式只有三类**，而
**指标的选择有六个家族**。这一节先把这两个横断面交代清楚，再定位本文的位置。

**三类对比范式。**

| 范式 | 对比对象 | 代表工作 | 所验证的主张 |
| :--- | :--- | :--- | :--- |
| ① 与人工/实车数据对比 | 司机驾驶、实车实测 | 级位增量 Q-learning 工作 | 该方法在实车工况下相对人工操纵的改善幅度 |
| ② **与同算法的简化版对比**（消融式） | 自己的基线实现 | 分层 RL 工作、级位增量工作、势场安全引导工作、多智能体重载列车组工作 | **机制改进本身是否有效** |
| ③ **与传统方法对比** | 规则基准、管式 MPC | **本文** | **相对既有工程做法，编队指标是否改善** |

**本文采用范式 ③**。这不是偏好，而是问题性质决定的：真实运营中不存在"三列各自独立
运行"的工况，因此"把编队拆成独立列做消融"在工程意义上不成立（这一点在领域内也被
承认——多智能体重载列车组工作明确说明不做独立消融列）。但范式 ③ 的代价是**必须赢过
传统方法**，且**不能靠车钩力赢**（车钩力在本文是安全底线，由确定性安全层保证）⇒
只能靠**编队几何**与**速度跟踪**取胜。

**六个指标家族。** 领域内用于评价的指标可归为六族：编队几何（间距误差、净空）、
速度跟踪（均速、速度偏差、超速步数）、安全软证据（碰撞时间及其倒数、暴露型/积分型
碰撞时间）、车钩力、能耗、效率。

**指标选择上的一个易犯错误值得点出。** 部分工作以**峰值车钩力高于基线**作为其方法的
"更优"证据（例如分层 RL 工作报告其方法的峰值拉钩力比单智能体基线高约 77%，并自陈
"以部分乘坐舒适性换取显著提速改善"，只要总钩力约束在安全限内即可）。这说明领域主流
做法是：**峰值只作底线达成，不作对比胜出主张**。本文遵循同一口径——这也是为什么本文
的贡献主张被限定在编队几何与安全架构的可测证据上，而不宣称在峰值上胜过他人。

**由此得到本文对比设置的两条纪律。** 第一，跨范式的数值不可直接并排：各工作的间距
参照值、计数单位与判据口径均不同（详见 §6.3 的口径表）。第二，**同一指标在两个入口
之间的计数单位可能不同源**，必须先统一到同一时间单位再比较。

## 2.3 与本文最接近的一篇工作：重合在哪里，差别在哪里

由于本工作同样采用多智能体 proximal 策略优化、同样处理重载列车组、同样观测净间距与相对速度、
同样以车钩力作为安全指标，有必要正面说明差别，避免读者误认为本文的贡献即该工作的贡献。

**重合之处**（如实承认）：算法族相同；观测面高度相似；**三个正向奖励分项的选择与该工作几乎逐项
对应**——因此本工作不把这三项的选择作为方法贡献。

**差别之处**（本文可主张的部分）：

1. **约束的保证强度不同。** 该工作以**势场引导奖励**提供安全偏置，并在文中明确指出"奖励函数中的
   '软约束'无法数学保证硬物理约束"。本工作对车钩力采用**断面力口径的硬约束 + 否决式安全层**，
   其安全证据是可计量的（介入触发率、否决后的轨迹偏离、越限残留），而非仅以"未发生事故"作定性
   陈述。这正是本文所主张的第三项 delta。

2. **工况与物理来源不同。** 该工作面向虚拟编组场景，物理模型为自行建立的纵向动力学模型；本工作在
   **真实长大下坡线路纵断面**上评估，采用含缓解波传播与分段衰减的钩缓模型、曲线附加阻力与分段
   限速联动，并显式建模**空气制动充风时序**与**循环制动的缓解相位**——这是该工作所不涉及的。

3. **对比对象不同，因而主张的强度不同。** 该工作与"同算法简化版"对比，验证的是"机制改进是否有效"；
   本工作与**传统方法**（规则基准、管式 MPC）对比，验证的是"相对既有工程做法，编队指标是否改善"。
   这两类主张不可互相替代：前者是方法内部的有效性检验，后者才是工程价值的依据。本工作采用后者，
   相应地**不能主张车钩力峰值上的胜负**。

4. **对比口径不可直接并列。** 该工作的期望间距为约 2 km（经济巡航间距），本工作的编队间距量级为
   128.7 m，相差约 15 倍；因此二者的"间距误差"数值不具可比性，本工作只报告自身口径下的绝对值
   与相对基线的改善幅度。

## 2.4 安全证据在文献中的呈现方式

领域内给出安全证据的方式有四类，本工作采用第四类：

| 方式 | 代表 | 强度 |
| :--- | :--- | :--- |
| 数学证书（前向不变集等） | 控制屏障函数类工作 | 硬（有证明） |
| 优化器内硬约束 | 多列 DMPC、管式 MPC | 硬（有界） |
| 动作级过滤 + 安全曲线 | 近期的重载列车组多智能体工作 | 半硬（信号级，无车钩力） |
| **硬约束 + 否决式安全层 + 可测证据** | **本工作** | 硬（物理量口径） |

此外，领域内用于佐证安全的指标还有一组碰撞风险指标族（碰撞时间及其倒数、暴露型/积分型碰撞时间），
它们被多篇编队类工作用作**安全证据**而非硬约束。需要提醒的是，这三个指标的"越小越安全"方向
容易被记反；本工作以硬约束实现安全保证，故这些指标在本工作中只作为补充观测，不承担主指标。

## 2.5 本工作的定位（一段式，供 Introduction 收尾）

面向长大下坡多列重载列车群组的协同控制，本文在规则基准之外提出一种**编队感知的多智能体强化
学习**方法，其可主张的差异有三：多列群组的协同决策（而非单列优化）、**车钩力断面力口径的硬约束
安全通道**、以及该通道的**可测证据**；在方法层面，本文针对长大下坡工况下"缓解时机与电制力下探
耦合"这一具体障碍，给出了空压通道解耦的实现（§4.2）与抗分项交换的奖励组合算子（§4.3），并以
确定性整程对照给出二者的量化效果（§4.2.4）。
