# 万吨108节再制动反事实与列尾装置原文核对（2026-10-18）

## 结论

仅在充风就绪时放开新增空气制动门槛，并不足以解决当前候选的超速与车钩力冲突。本轮没有获得合格的新控制器，未推广正式配置、未启动训练。

这是一项隔离的原生物理反事实试验：在同一471.1秒状态、相同ED目标0.55和相同指令渐变速度下，比较不请求空气制动与请求50kPa循环制动。不能推广为所有ED组合或所有制动时机都无解。

## 工况及试验边界

1机车+108货车，10988吨，49.6km线路，起点0m、初速80km/h，seed0、零RL。沿single108_release_recovery_source_20261018_review的完整闭环历史重建471.1秒状态；此前249.1秒缓解，222秒充风已经就绪。

重建状态与原冻结运行在位置、速度、断面力、制动压力系数、缓解比例、空气制动激活标志六项最大误差均为0。气动队列及积分历史通过完整重跑和deepcopy保留，未从NPZ拼造检查点。

ED指令按0.5/s逐步趋近0.55，两值是工程筛选参数，不是论文车辆参数。每分支运行100秒。无空气制动分支保留全部原生安全；50kPa分支只在复制的环境中临时旁路新增源否决，保留车钩ED减权、超速接管及原生物理。父环境和正式控制器门槛未放宽。

注意：两分支名称表示持续请求，不表示物理始终不制动或始终保持50kPa。ATP在超速后仍可增加或升级空气制动。当前原始信号未记录逐步物理AB档位，因此后续峰值不能归因于50kPa本身。

50kPa请求将首次超速推迟2.2秒，但仍未避免超速。首次超速时109辆均已激活空气制动，而压力建立系数最小仅0.289、平均0.451，说明在该时点已经开始施加，制动力仍在建立。系数不是副风缸压力，不能用来声称达到论文580kPa充风判据。

后续有ATP接管；上述100秒峰值是整条反事实路径的结果，不是纯50kPa档单独产生的峰值。该开环ED试验也不是完整闭环控制器性能比较。

## 对修复方向的影响

1. 仅删600kN门槛不是已验证的解决方案。
2. 缓解决策需要评估充风时间加下一次空气制动传播、压力建立期间的速度余量，不能只看当前是否到50km/h。
3. 下一轮应在完整状态下筛选充风期间ED策略与再制动策略，覆盖建立过程；普通制动准入需同时验证速度和车钩约束，不能只让单个门槛通过。
4. 仍保留222秒作为原对照，不直接换成116辆论文的150或196秒；1000kN验收不变。

## 原文核对的新发现：普通可控列尾与附加尾部充风装置必须区分

本地Zhang2025_20kT_LongitudinalDynamics_Braking.pdf实为Bo Zhang等《Research on Longitudinal Dynamics of 20,000-Ton Heavy Haul Trains Considering Braking Characteristics》，Mathematics 2026,14,158，在线发表2025-12-31，DOI10.3390/math14010158。

PDF第13页§4.3明确：在普通可控列尾制动装置之外，另外用一台仅具充风功能的机车模拟尾部充风装置。780→489kN的拉钩力变化属于附加设备两万吨工况，不是普通可控列尾的固有能力，也不是本项目万吨108辆1000kN的保证。

雷美琳《典型线路重载列车电制动力异步控制与优化》PDF第31页/印刷25页明确其研究中的可控列尾不主动充风缓解；PDF第43—44页§3.3.2比较30/35/40km/h缓解，指出降低缓解速度可能增加拉压冲击。该文为多机车编组，不能直接复制数值，更不能认为越晚、越低速缓解越安全。

已视觉核对两篇原文关键页，图保存在本报告同目录：
- Zhang_额外尾部充风装置_PDF13_20261018.png
- 雷美琳_可控列尾功能_PDF31_20261018.png

当前train.py的历史eot=True实现双向缓解，设备解释应是具备额外尾部充风能力的简化假设。本轮仅更正代码注释、VALIDATION_BASELINE、REFERENCE_INDEX和papers/README的设备语义与出处，不改变动力学行为或EOT开关。正式研究若采用普通列尾，需另做对应设备工况，不能把现有结果直接当作普通列尾结果。
