# 第32轮：全线路静态制动能力核对

本轮为独立分析，不修改正在运行的第31轮控制器或物理模型，也不作为全线路动态验收结果。

## 方法与结果

使用第29轮完整状态及相同物理源码，在49.6公里线路每100米采样。每列1台机车加108节货车，总质量10988吨。设50 kPa循环制动力已完全建立，使用模型允许的最大电制动，并保留第3段循环衰减。未模拟传播、充风和车钩瞬态。

| 速度 km/h | 最不利车头位置 km | 减速力余量 kN |
|---|---|---|
| 40 | 41.1 | 214.352 |
| 50 | 41.1 | 93.352 |
| 65 | 41.1 | 14.820 |
| 80 | 41.1 | 7.596 |

每种速度检查497个位置，均未出现完全建立制动后仍加速的采样点。但65及80 km/h的余量很小，不能据此判定建压期间不会超速，也不能证明车钩力低于1000 kN。完整线路动态验证仍在进行。

## 参数依据待核对

现有单机车定义标注HXD3B，采用188吨、6轴、9600 kW及0.85效率；电制动按功率与黏着限制计算，没有独立标定的制动力平台。容嘉欣论文图3(b)为HXD1，不能直接用其曲线替换当前车型。下一次补证应先确认研究对象的机车型号，再核对该车型电制动速度特性、低速衰减、功率和效率口径。

循环衰减来自另一编组的依据，尚不能视为本项目1+108编组的实测定标；当前模型也未完整模拟副风缸再充风。运行阻力采用现有Davis实现，其与C80参数的对应关系仍需核对。上述参数均未为使曲线好看而改动。

## 下一步验收

1. 等待第31轮尾车通过49.6公里，或记录明确失败原因。
2. 核对内部机械子步车钩峰值、所有车辆限速、最低速度、制动档位及缓解接续。
3. 重点检查41.1公里附近，不以静态余量代替瞬态验证。
4. 如失败，按事件前后完整状态定位传播、充风、策略或数值原因，再选择单项修改。
5. 单列通过后再进入三列联合验证，当前仍不是强化学习训练。
