# 万吨108节再制动门槛审计及充风阶段平滑反证（2026-10-18）

## 结论

不采用本轮候选。缓解窗口内ED恢复平滑对首次缓解有帮助，但将其延长至整个空气制动关闭阶段会延迟制动力恢复，使速度余量更早耗尽。当前瓶颈是充风期间速度可行性与正常再制动准入的联合冲突，不能靠单一ED平滑参数解决。

## 工况与口径

单列1机车+108货车，10988吨；49.6km线路，起点0m、初速80km/h，seed0、零RL调制。1000kN指标和222秒充风约束不变。均从起点完整运行，保留原生物理、制动传播、环境安全和ATP。未修改生产控制器，未改动600kN新增制动门槛。

## 门槛审计

审计对象为前一轮single108_release_recovery_trial_20261018_review，读取决策前一时间步的受力、速度、循环标志及位置，并按当前控制器的legacy电制动可用度公式核算。这里是只读静态门槛核算，不宣称从NPZ恢复完整气动状态。

249.1秒发出缓解请求，222秒充风截止对应471.1秒。471.1—484.2秒共132个时间步：
- 全部处于循环制动状态；电制动可用度0.393611—0.401311，明显不足，需要空气制动兜底。
- 决策前车钩峰值全部高于600kN，132步均命中控制器反应式封源条件；环境安全层另有同类新源门槛。
- AB请求一直为0。484.3秒首次超速，484.4秒才请求SERVICE。

因此，普通制动被门槛持续封锁具有明确代码和归档状态证据；这不代表可以直接删除门槛。预测式安全闸门可能进一步拒绝，不能声称只修改单层门槛即可安全通过。

新候选恢复限速为归一化ED指令0.5/s，属于工程试验参数，不是论文车辆参数。六项隔离契约检查通过：循环状态下的充风恢复限制、立即保护降幅、速度接管旁路、非零RL旁路、新AB指令不变、首次运行不受影响。这些检查只验证实现边界，不证明控制效果。

## 下一步

1. 保留仅缓解窗口平滑候选作为对照，不推广正式控制器。
2. 将充风可行性纳入缓解决策：用全列坡度、可实现ED、空气制动退去过程和完整内部状态，预测充风完成前速度余量，不能仅用当前50km/h判断允许缓解。
3. 对充风完成后的再制动建立单独的安全准入试验：区分普通50kPa与强制动，检查实际传播后的受力和速度，再考虑替换持续封源规则。不得直接删除600kN门槛或绕过ATP。
4. 先重读现有论文中循环可行性、缓解时机和再充风定义；若要使用数值，必须核对1+108、机车参数、坡度、初速度和减压量。现有116车与双机车资料不能直接当成108车参数。

本轮没有新检索MIS/知网；证据来自现有代码、归档状态及完整重跑，未借用论文数值调整充风时间。
