# 分段电制动序列及接续验证（2026-10-17）

## 本轮结论

生产控制器未替换，未训练、提交或推送。新增诊断支持双机车两段电制动序列，对两个既有反例各测试81组。转缓坡有120秒局部通过结果，再入坡仍超过1500 kN。所有序列均为已知反例上的定时诊断，不是可推广策略，也不是连续优化算法。

## 工况和方法

同一官方物理模型、20kt_1plus108_1plus108编组（218辆、21976吨）、49.6km线路、初速度70km/h。起点分别25013.5m和26633.5m。1350 kN为诊断余量目标，1500 kN为制动工况验收线，2250 kN为安全硬顶，未修改物理或安全限值。

预测诊断起始分别为运行35s和8s的完整原生状态；各分支保留车钩、制动及数值历史。前3秒和后3秒各选择两台机车的0/0.5/1电制动请求，共9×9=81组，指令变化限制0.5/s。该斜率是工程试验值，不冒充实车参数。空气制动请求在预测分支保持不变，原生安全层照常生效，实际续跑仍由原控制器处理空气请求和安全接管。此工况未发生空气制动档位切换。

预测母控制器为上轮的air_admission_forecast_fast冻结候选，不能把结果冒充当前生产控制器性能。完整原始代码、参数、哈希、轨迹及审计保留在各归档。

转缓坡两个续跑的前41秒轨迹、请求完全一致；仅后续接续方式不同。最佳序列35—41秒的原生预测与真实续跑车钩力逐点相同（最大差0 N），请求也完全相同。再入坡8—14秒同样逐点一致。这排除了本次对照中预测与执行不一致这一解释，但不是全局模型精度证明。

转缓坡原生产控制器在此前同起点46.0s触及1350诊断目标，空气预看母候选40.6s触及目标。本轮接回原规则45.3s触及目标，不能声称比原生产版本改善；保持候选动作才完成120s并守住1343.201kN。该结果距离1350仅约6.8kN，仍需扰动和全线复验；不允许以此单工况成功替换正式规则。

再入坡最佳6秒序列虽低于1500，继续保持仍在14.7秒达到1504.820kN。两处反例结论不得合并为整体通过。所有早停峰值仅为已观测区间峰值，不是完整120秒真峰值。

## 当前瓶颈与下一步

1. 转缓坡已找到有潜力的两机车制动分配，但必须把固定时刻操作转为根据坡度、断面力和运行状态触发的通用策略，验证退出及恢复条件。
2. 再入坡在8秒状态起步的两段有限网格仍达不到1350余量，且最佳序列续行超过1500；应研究更早介入及更多连续控制段，保留未来接续可行性，不可只最小化当前6秒峰值。
3. 原生预测较慢，尚不适合作为每0.1秒求解的在线控制器；降阶预测必须先验证对多体MT-2模型的误差，不能更换验收物理模型。
4. 保留原固定起点整线1321.486kN既有结论的适用范围。未把本轮6秒或120秒结果称为完整49.6km验收。
5. 本轮没有新搜索或新读取论文原文；方法边界沿用上轮已核对Lu2025的原文，当前有限分段网格不是该论文的NMPC复现，也未使用其车型参数、1600kN阈值。
