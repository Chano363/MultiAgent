# 长窗口接续与按需电制动验证（2026-10-17）

## 本轮结论

按实际净需求调节电制动的冻结候选，在26533.5/26633.5/26733.5m三个相邻再入坡初态都完成120秒、无超速或1500kN超限；峰1404.506/1298.402/1263.969kN。该策略不依赖指定运行时刻，复用已有净需求前馈计算，尚不是正式生产控制器。24913.5m转缓坡仍在76.1秒达到1511.059kN早停；1350余量目标亦未全部通过，不能宣称底层修复完成。

另有固定时刻干预证据：26533.5m在第5秒后平滑撤去ED，完整120秒峰1488.041kN；第8秒再开始的已测36组三段动作均不能守1500。此观察支持提前介入值得研究，不证明所有第8秒状态均无控制解，也不把固定时刻方案当作通用控制。

未修改物理参数、安全限值、主训练配置或生产控制器，未训练/提交/推送；全部候选留在冻结试验源目录。

## 按需求电制动候选

母控制器是此前空气新增时机预看候选，而非正式生产版本。本轮将既有_grade_feedforward_actions的净需求计算用于空气制动未投入/未排队的阶段：坡度重力、Davis阻力和现有制动力共同给出需由ED承担的量，再调用已有机车力模型反解请求。它是已有前馈的工程应用试验，不主张新增创新。

- 仅零RL调制、无实际空气制动、无排队/延迟源、无新空气请求、远离原速度门时启用。
- 目标请求不大于原控制器已投影的ED请求，保留原车钩保护；请求用0.5/s渐变，但原保护要求更小值时立即服从，不让渐变维持被禁止的制动。
- 近速度门、原生空气建立/排队、新空气请求或非零RL调制时沿用母控制器动作；不取消已建立空气，不变更充风/保持门，不改ATP。
- 没有固定位置/运行秒数触发，也没有改动全列空气制动压力映射。现试验在非零RL时旁路该功能，所以不能直接把它当成已经完成MARL训练对接的基线；正式接入时仍需在正确的规则/RL接口位置实现并复验。

## 验证与待办

16项单元测试通过，包括9项自定义计划验证及原7项动作/预警审计。四个原生门控检查通过：空闲时不增大原已投影ED、速度门旁路、非零RL权限保留、原生空气动作保留；所有检查均未推进被查询动力学状态、AB时钟只进一次。四个120秒/早停工况使用完全相同控制器源哈希。

当前结论是：减少不必要的满幅ED、提前匹配实际需求，对再入坡有可复验收益；它尚未解决转缓坡的动态分配/接续，不能据此取消既有安全层。下一步应固定24913.5m反例，检查按需ED与实际坡度分布、断面加载之间的时序，设计有原生验证的状态触发接续；再做完整线路、其他起点及三列联合验收。不能重新回到单点阈值反复扫参，也不把有限分支失败当作所有控制无解。

本轮未新查/读取论文，未引入新的外部车型参数；复用项目已核对的重力、Davis和机车制动力模型。试验0.5/s和各分段时长均是工程测试量，非实车定值。
