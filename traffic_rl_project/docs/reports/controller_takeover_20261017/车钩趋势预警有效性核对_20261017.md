# 车钩趋势预警有效性核对（2026-10-17）

## 结论与工作范围

本轮没有新跑物理仿真，没有取得新的车钩力下降结果。正式控制器、物理参数、训练配置均未改变，未启动训练或推送。对既有8条原生轨迹进行因果预警审计，排除“车钩力变化率加邻车速度差即可作为可靠提前干预条件”的简单方案。它能覆盖已观察到的超限窗口，但在安全运行时误报严重，不能据此接入安全层。

## 方法

新增src/evaluation/audit_coupler_warning.py与tests/test_coupler_warning_audit.py。逐断面保留正压缩/负拉伸符号，仅使用当前和过去0.5秒的力计算变化率；对未来1、2、3秒分别外推。对照包括：当前力、力及变化率、再加入相邻车辆速度差的加载方向门、再加入过去1秒因果均值滤波。滤波时间及外推时域都是信号处理试验设置，不是车型物理参数。

方向门采用正压缩时后车追近、负拉伸时前车拉离，分别允许相应的载荷外推。未来实际最大断面力只用于审计标签，不作为预警输入。当前已超限的采样不计入提前预警样本。

## 早停和因果性处理

初版v1只使用完整未来窗口，在早停案例中会丢掉末尾已有超限证据的正样本；不是拿未观测未来当安全，但统计信息不充分。v2改为：未来窗口已观察到超限的，即使后续缺失也可标为正；不完整且未观察到超限的窗口保持未知并排除。v3在该标签口径上新增滤波方法。三个归档独立保存，不覆盖历史；以v3为本轮最终依据。

例如早停记录最后一帧越线时，其前2秒内的20个状态均已有可确认的正标签，而末尾未观测后续且未见越线的负尾部不能臆造。四项测试覆盖末帧超限、未知尾部排除、未来标签变化不改变先前因果预警、压缩/拉伸加载方向。最终4项全部通过；第一次调整标签后测试中漏报计数预期仍是旧窗口数，已更正为已知三个正样本，不改变预测算法或降低验收线。

8份原始NPZ哈希与冻结审计源哈希验证一致，时间步均匀性误差小于1e-6秒。原始数据只读。审计metadata以参考档案构建，逐案例另保留原始metadata；不冒充本轮重新仿真的物理成绩。

## 判断与下一步

变化率外推将一段时间内的载荷上升延续到未来，不能表达车钩加载/卸载和沿列传播的回落；在217个断面中取最坏预测时，局部短时变化容易造成频繁预警。现有数据证明这个简单预警不适合直接控制，但尚不能据此断定仿真器物理错误、所有趋势方法无效或控制问题无解。

下一步应先验证候选动态预测模型能否预测不同制动动作下的逐断面响应，并纳入相邻车速、加载历史及动作变化；再用受约束的连续动作和接续条件做原生仿真闭环复验。不能把当前线性趋势外推作为硬安全边界，也不应继续只调单点触发阈值。

本轮没有新搜或新读论文，没有新增外部参数依据。此前已核对的ECP逐车控制文献和简化车钩NMPC仍有适用范围限制，本轮不声称其方法已复现。当前生产版本及上轮状态候选的原有性能范围不变。
