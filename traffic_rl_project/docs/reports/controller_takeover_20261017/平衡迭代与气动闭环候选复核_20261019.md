# 平衡迭代与气动闭环候选复核

## 本轮修复对象

上一候选仅在原Newmark停止后检查力残差。小步长下，绝对位移变化先小于1e-9m，即使末状态力误差仍148N也会停止；继续缩步未必消除这一问题。新独立候选在每次加速度迭代中同时检查力平衡和局部位移残差，避免用两次大绝对位置之差作为唯一停止依据。

采用同一Newmark β=0.25/γ=0.5和0.5松弛，保持质量、车钩力函数、阻力和制动力模型不变。试算运动学位置/速度由本步初始状态与候选加速度形成，只有同时满足力残差和局部位移残差才接受；失败则细分重算，整个原输入间隔失败时恢复完整机械状态。该方法是工程候选，不是声称忠实复现常崇义文中使用切线刚度的平衡迭代算法。10N/1N残差、步长和1e-9m容差为本地数值试验值。

## 接入气动的边界

只在诊断上下文临时替换机械求解；原0.01秒空气压力、命令传播和控制更新节奏不变，机械细分不重复推进气动。每个原生气动机械子步开始前保存完整dynamics字典，任何机械失败或后续异常恢复该子步全部状态及统计记录。上下文退出恢复原类方法。这里不提供整个0.1秒环境步的全局事务：若其后续子步失败，先前已完成的原生子步保留；调用者必须停止并报告，不应吞掉异常继续训练。

20秒零RL接续来自同一765.5秒完整原生状态、同一冻结50秒恒力/10秒准备控制候选。原求解控制采样峰381.305kN，平衡候选控制采样峰167.292kN；后者内部微步峰244.595kN（不能只报较低控制采样峰）。两者短窗口完成，最大单车速度42.679/42.675km/h。候选2000个气动子步、32000个接受机械步、0拒绝，最大已接受力残差9.999916N。

这只是短冒烟；完整248.5秒窗口仍在运行，最终结果须追加。起点继承旧积分器历史，不是从冷态开始的全新精确轨迹。后续需要从冷起点重跑和进一步细化闭环，才能评价全线及三列效果。

248.5秒窗口已结束。原求解器在235.5秒控制采样峰1004.882876kN失败，2355×6个样本与round10旧预测逐项相等，baseline_replay_audit.json留痕。平衡候选完成全部2485个控制步：控制采样峰572.461850kN、内部细步峰572.462226kN，最高单车70.247772km/h、最低均速40.288053km/h、末均速70.211470km/h。前20秒与独立短试验逐项一致。

候选推进24850个原生气动子步、397600个接受机械细步、0拒绝，最大已接受力残差9.999998N。力平衡要求在每个细步接受时检查；位移容差1e-9m、最大迭代100、机械最大步0.000625秒。本轮未调整1000kN、约40—80km/h速度带或222秒充风约束。

结果只支持本次同原生起点、同冻结控制、同气动节奏下的248.5秒局部可行。起点沿用旧积分历史、每个气动0.01秒内控制力和坡度固定，仍有输入离散误差。原生预测中的_probe_active设置用于避免递归预测，原空气准入与ATP仍保留，不能将此结果直接当全策略在线保护已经验收。不把1004→572当纯规则调参收益或实车效果。
