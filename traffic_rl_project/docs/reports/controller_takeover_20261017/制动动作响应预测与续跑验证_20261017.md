# 制动动作响应预测与续跑验证（2026-10-17）

## 本轮结果

一个此前失败的相邻起点得到局部120秒通过：24.9135km、70km/h，在35秒后平滑撤去两机车电制动，120秒内峰1266.293kN、最高车辆速度77.882km/h、无超速和1500kN超限。另一个26.5335km反例仍14.3秒达到1511.695kN验收早停。两者都是指定时刻介入的诊断干预，不是可部署通用控制器，因此生产控制器、物理参数和训练配置没有替换，未训练、提交或推送。

新增的动作响应预测审计有一定筛选作用，但没有取得可靠的安全预测模型。逐车位移/速度插值后代入原MT-2非线性公式，也不能弥补预测状态偏差，本次出现最高313.081kN低估，未采用。

## 数据、工况和未泄漏的验证划分

- 共用官方20kt_1plus108_1plus108编组，218辆/21976吨、中部分布动力、49.6km真实剖面，初速70km/h。1350为诊断余量目标、1500为制动工况验收、2250为硬顶，未改变限值。
- 使用既有两个81点分支档案：原转缓坡25013.5m运行35秒和原再入坡26633.5m运行8秒的完整原生状态。每条分支前3秒、后3秒各指定两台机车0/0.5/1电制动请求，0.5/s平滑请求，空气请求固定但原生安全层保留。
- 四维动作插值只用16个0/1角点响应拟合，其余65个中间力度动作作验证；二段插值固定第一段，每个中间状态用4个第二段角点拟合，共45个第二段中间力度动作验证。验证的是同初态下未用于拟合的动作，不是跨初态泛化。
- 新增两处已知失败相邻起点：24913.5m/35秒、26533.5m/8秒。在运行前登记各16角点及3个验证动作，共19点；3个验证动作是全0.5中心及先前两处序列锚点，均未用于拟合。每处都重新用当地原生角点建局部模型，并非旧模型零样本跨位置预测。
- 新增38种动作分支后，原样复演38条补录逐车/逐钩数据；复演不是38个新独立动作样本。38条rows和commands逐元素一致。短记录开关冒烟的5种动作亦逐元素一致。
- 逐车记录包含位置、速度、Newmark加速度记忆、坡度、逐断面力、制动缸压力系数、缓解系数和生效标志；初态另含质量。未包含全部气路队列，因此明确不是完整可恢复的checkpoint，真实分支始终从原生环境深复制获得。

## 逐车状态加原生车钩公式的核对

两处新数据记录的每条真实位置/速度，传入现有原生MT-2力函数，逐断面受力复现最大差均为0 N。审核还检查原动力学源哈希一致，保存了原生力函数/车钩曲线源码及实际逐钩参数。

随后只用16角点预测中间动作的位置与速度，再用同一原生车钩非线性公式算力。相对位移最大误差约9.32—17.86mm，相邻车速差最大误差约0.089—0.171m/s；新再入坡峰值MAE187.157kN、最大低估313.081kN，比直接插值峰值更差。现有车钩加载/卸载分支由相对位移和相对速度共同确定，不应假设存在未在代码中实现的独立迟滞状态变量。Newmark记忆与气路状态仍会影响未来运动。

这说明该近似状态预测不够准确，不能由“用了原车钩公式”推导为预测正确；它也不是原物理模型真实有效性的独立验证，不能据此要求修改车钩物理。

## 原生续跑验证

动作按四维局部模型在19点集合中的预测最小峰值选取，然后在同一原生环境实际续跑，第二段保持至预算结束，原速度门和ATP仍优先。两次均选到已采样的角点，而非未测试中间动作，因此本轮控制收益可以由角点原生搜索解释，不能归为插值模型的新增贡献。

转缓坡的上一轮状态规则在同起点43.4秒达到1516.238kN早停，本轮完成120秒1266.293。原有起点、配置、物理和诊断预算一致，仅控制器试验源不同；运行时差异只涉及实际事件记录，已复核。由于旧轨迹未满120秒，不计算等时域峰值下降百分比或均速改进百分比；更不能把这称为相对正式生产控制器的整线提升。

再入坡上轮13.9秒超限，本轮14.3秒仍超限，不称修复成功。它在8—14秒真实执行的峰值轨迹/请求与原生分支逐元素一致，6秒峰1482.365kN；0.3秒后1511.695kN。这是窗口结束后的接续失败，不是把六秒预测错误说成原因。

转缓坡35—41秒的原生分支与实际执行亦逐元素一致（0N差）。全部早停峰值只是截至停止时已观察峰值，不是完整120秒真峰；本轮没有整线49.6km或三列联合验收，也没有把新起点结果替换原固定起点整线1321.486kN结论。
