# 模板：沉淀历史经验（可复用知识，区别于一次性失败教训）

> **定位区分**：`TEMPLATE_FAILURE` 记"这次踩坑→怎么修"（事件）；本模板记"这背后
> 哪条方法论/知识下次还能用，哪里不能乱用"（规律）。一条经验通常伴随一次失败或
> 一次成功而得出。append-only，进 `docs/logs/learnings/LEARNINGS.md` 或 `docs/logs/decisions/DECISIONS.md`。

---

### 经验-日期-主题

- **适用场景**：什么条件下该用这条知识（正例集）
- **不适用 / 反例**：什么情况下别用、常用错（负例集，防过度泛化）
- **依托的证据**：来源（论文作者+年份+DOI / 实验 / 代码），附 `computer://` 溯源链接
- **一句话速记**：≤30 字，能直接进团队口头语
- **验证状态**：已在何种规模上验证（如 N=5 seed / 2 剖面 / 全量）；
  未验证的部分明确标注，不夸大

---

### 示例（本项目既有经验的规范化形态）

> **经验-2026-08-21-安全层修正必须重算 log_prob**
> - 适用：MALO 策略训练中动作被安全层改动的场景
> - 不适用：动作未被修正、或无需重要性采样的离线评估
> - 证据：SafetyLayer 修正→log_prob 失配→viol 每 10ep 爆 85 倍（V5.1 三层 bug 链）
> - 速记："安全层改动作，log_prob 要跟着改"
> - 验证：修复后多 seed 训练收敛、viol 归 0
