# 文献整理与对比设计 — 论文方向讨论（2026-10-16）

> 缩写约定：行业通用词（RL 强化学习、MPC 模型预测控制、DQN、ATP 列车自动防护、ETCS 欧洲列车控制系统）直接用；其余非通用缩写在首次出现处括注。

## 一、关键文献：主张 / 作者自述局限 / 对比方法

**读表要点**：
1. 这一行的主流做法是"自己 vs 自己的弱化版"（单基线、无消融）；只有 Guo2025、Hu2026 把对比 + 消融做全了。我们的对比结构比多数工作完整。
2. 作者自述局限集中在三类：**模型简化**（忽略车间力、区段化降精度）、**单列/同质假设**、**环境泛化**（天气/载荷/换线重训）。

## 二、我们设计的对比表

**原则**：所有方法用同一仿真器、同一环境、同一安全层；主要结论只由消融对比（见最后一行）得出。

| 方法 | 是什么 | 编队上下文 | 车钩约束 | 对位文献的对比设计（我们的区别） |
| :--- | :--- | :--- | :--- | :--- |
| **D-Rule（规则基线）** | 文献里成熟的循环制动规则，无学习 | 有 | 规则 + 安全层 | Song2026 MAPPO 没有规则基线；我们有 |
| **单列 RL 行** | Zhang2024 式逐列独立的单列 RL | 无 | 同安全层 | 文献里的 RL 对比都发生在单列内部，跨范式对比是我们的加项 |
| **Formation-MPC（编队 MPC）** | 仿照 Song2026 Tube-MPC 架构的 MPC 基线 | 有 | **主动关掉车钩约束**（不占它便宜） | Song2026 Tube-MPC 根本没有算法基线；我们主动把 MPC 拉进同台 |
| **D-RL（编队）** | 我们的方法：每台机车一个智能体 + MAPPO | **有** | 安全层强制 + 超限惩罚项 | Song2026 只比标准 MAPPO、无消融；我们是三类方法 + 消融 |
| **D-RL（独立）** ← 消融 | 同一算法，**遮蔽编队观测** | 无 | 同 | 文献消融的是模块（记忆网络等），我们消融的是"编队上下文"本身 |

> **2026-10-17 注（ADR-038，append-only，原表保留）**：上表"单列 RL 行"已随 ADR-038 移出主对比表——本项目并未复刻文献的单列 RL 实现，自建网络逐列单训充数则与 D-RL（独立）消融列高度重复、行标签与实现对不上。现主表 = D-Rule / Formation-MPC / D-RL（编队）+ D-RL（独立）消融列，文献单列 RL 降为 related work 文本。以 `docs/logs/decisions/DECISIONS.md` ADR-038 为准。

**评价指标**（5 个随机种子，取显著性）：

| 指标 | 含义 | 方向 |
| :--- | :--- | :--- |
| 列距误差 | 实际间距与目标间距的偏差，达标线 ±5% | 越小越好 |
| 速度带内占比 | 各列车速度保持在同一带内的比例 | 越大越好 |
| 车钩力达标率 | 断面车钩力 ≤1000 kN 的比例 | 不劣于规则基线 |
| ATP 触发次数 | 安全系统紧急介入次数 = 控制失败次数 | 越少越好 |
| 旅行时间 / 能耗 | 运行效率 | 不劣于规则基线 |
| MPC 求解耗时 | MPC 每步计算时间，用于列数扩展对比 | 记录 |

**对比公平性**：所有方法共用同一仿真器与坡度数据，调参力度对等；RL 换线不微调。三个待验证假设：① 编队观测显著降低列距误差；② 车钩零超限且编队组峰值更低（安全层介入更少）；③ 旅行时间/能耗不劣于规则基线。编队独立组先试跑 1 个种子，增益不明显就不烧满预算。

## 三、当前架构为什么这么做

```
编队目标（最终目的）: 安全列距 + 速度带一致 + 车钩力达标
      ↓ 同一套 RL 承载（以编队为上下文）
学习层: MAPPO，每台机车 = 一个智能体，输出对规则动作的调制量（幅度上限 0.5）
规则层: 列内规则循环制动 + ETCS 目标距离曲线（逐级减速监督）
安全层: 全列紧急制动，最高优先级、不被任何规则释放
校验层: 评估时强制"追尾步数 = 0"，非 0 该组结果作废
```

1. **为什么分层，不让 RL 直接管百节车厢？** 直接学单列循环制动试过多次都失败：制动缓解波传播要 6 秒，奖励信号来得太晚学不会；车钩多体耦合一探索就出危险值。领域惯例也都是规则管执行、学习管分配。最关键的是——**最接近的对手 Song2026 在引言里自己写明"奖励软约束无法数学保证车钩力这样的硬物理约束"**，所以硬保证必须有独立通道，这是对手原话。
2. **为什么保留规则层？** 规则来自文献里的成熟循环制动方法（是"文献锚定的规则基线"，不冒充行业标准）。分工明确：**规则管单车安全制动，RL 管多车编队协同**。规则有盲区（刘博阳2022：判断标准全过、拉钩力仍从 742 涨到 1337 kN）——这是"为什么还需要学习"的论据。
3. **为什么用 MAPPO、每台机车一个智能体？** 导师批评过"3 条列车曲线叫多智能体名不符实"，所以智能体必须锚定**物理上独立的动力源**：3 列 × 双机车 = 6 个智能体，编组对齐朔黄线实际 2 万吨列车。MAPPO 采用集中训练、分散执行（CTDE，训练时共享全局信息、运行时各机车独立决策），分散执行本身就是可部署性优势。算法上一阶段无人机项目已跑通可直接复用；每 10 步决策一次才收敛（决策太频繁，奖励信号链条太长学不动）——这一权衡要如实写清代价。
4. **为什么动作是"调制"不是直接指令？** RL 只输出对规则动作的上下偏置（幅度上限 0.5），探索被限制在物理合理范围内，规则层永远兜底。试过全幅度（1.0），对 RL 有害无益，已回退。
5. **车钩力的位置**：由安全层强制执行（限值按工况分档：正常运行 1000 kN / 制动工况 1500 kN / 安全硬顶 2250 kN，依据朔黄、大秦实测文献），奖励里只放"超限才生效的惩罚项"，不做均值最小化。**车钩力的证据在规则层 + 安全层，不在 RL 消融**。
6. **诚实边界**：ATP 安全距离曲线隐含"前车不减速"的假设，目前只能说"对前车保持速度/缓减速安全"，改完才能说"对前车紧急制动安全"。

## 四、别人自述的局限，在我们身上同样存在

这些局限在我们身上同样存在，逐条对照现状与应对：

| 文献自述局限 | 我们的状态 | 应对 |
| :--- | :--- | :--- |
| Si2025：粒度大、区段化降精度 | 我们同样有粒度换取：每 10 步才决策一次 | 要如实说清代价（动作保持期内响应变慢），不能只报收敛结果 |
| Guo2025：同质假设不代表混编 | 我们默认同构，异构只是可选附录 | 只说跨线/规模/初速泛化，**不声称混编泛化** |
| Wang2026：换线需重训 | 我们主张换线零微调，**但该实验还没跑** | 实验落地前不把这条写成结论 |
| Zhang2024：天气/轨道/载荷不在范围 | 我们同样没覆盖（载荷、风、黏着都是固定值） | 写研究范围时照实列排除项 |
| Hu2026：模型无车间惯性 | 我们是多质点 + 真实车钩模型，这点确实更强 | 可以正面讲，用文献口径佐证 |
| Song2026：结论不声明局限 | 我们有专门的边界说明 | 这是加分项，坚持写；但不暗示"它没写就是它有问题" |

**小结**：换线零微调、混编泛化、粒度代价三项目前都只做了一半，讨论时不要把"对手没做的事"当成"我们做成的事"。
