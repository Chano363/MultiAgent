## 二、本轮完成内容（治理模块）

### 1. 参数中心化 `src/physics_config.py`

- `PhysicsConfig` 类统一管理所有物理参数（v\_max\_mps=80/3.6、v\_min\_mps=40/3.6、max\_accel=1.0、min\_speed\_band=5、dt=0.01、train\_mass=10188e3、loco\_mass=138e3、num\_cars=100、grade\_profile 名称）

- 训练/验证/测试脚本统一 `from physics_config import PhysicsConfig`，禁止手写物理值

- `physics_version()` 函数对当前配置做哈希，用于元数据版本标识

### 2. 工况枚举与运行时断言 `src/physics_governance.py`

- `SimCase` 枚举：`OFFICIAL`（正式朔黄工况，禁止调试物理）/ `DEBUG_SIMULATION`（调试仿真工况）

- `assert_case_allows(simcase, debug_params)` 运行时断言：official 模式下若传入黑名单参数立即抛异常

- `train.py` 初始化时接入枚举门禁，调试参数（enable\_cyclic\_degrade / tail\_pressure\_kpa / brake\_reduction\_override\_kpa）无法静默启用

### 3. 元数据自动落盘 `src/metadata.py`

- `save_metadata(output_dir, simcase, config, seed, entry_script)` 自动写入 `metadata.json`

- 记录项：git commit 哈希、物理工况版本（SimCase + physics\_config 哈希）、全部关键动力学参数、随机种子、入口脚本 `__file__`

- 训练脚本接入：`train_fleet.py` / `train_cyclic_braking.py` / `train_dqn_cyclic.py` 启动时调用

### 4. `project_constraint.md`（项目根目录新增）

- 参数黑名单表 + 禁止历史开关列表 + 实验引用规范

- 每运行必需元数据清单 + 资产目录（`experiments/official/` vs `outputs/deprecated_results/`）

### 5. 物理隔离

- `outputs/deprecated_results/` 已建立，含 `decompose_pre_release_fix/`、`decompose_smoke/` 等子目录
