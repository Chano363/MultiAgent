## 2. 本轮的根因与治本（已完成，勿重做）

**根因（非单点突变）**：策略固有"偶发暴力 AB 探破车钩力>1000kN"（全程 viol>0 共 22 个 ep、ep428 起贯穿）→ 深负破线轨迹作为单条极端 returns → 碰上 value_norm(PopArt) running std 长训后收缩 → 放大成全局不可回退的 value 污染（终段 ep849-856 loss +0.337→+1.283、reward -5371）。

**三项治本杠杆**（全在 `src/algorithms/mappo_agent.py`，只影响训练不影响推理，已 py_compile+b4 通过）：
1. **per-trajectory winsorization**（新增 `_winsorize_by_traj`，`compute_gae` 调用于 returns，lo_q=0.02/hi_q=0.98）：按 done 切轨迹，仅把 <2% 分位的深负异常轨迹整体均摊抬升到 lo 分位，正常段零改动 → 掐污染入口。
2. **value 网络独立 grad clip**（整体 clip 之前先对 `self.value.parameters()` 独立 `clip_grad_norm_(max_grad_norm*0.5)`）→ 掐放大端。
3. **KL 早停收紧**：`target_kl*1.5→*1.2`（0.015→0.012）→ 提前拦截漂移累积端。

**30ep 验证（ep843-872，107.7min）SUCCESS**：全程 viol 0、loss -0.010~+0.001、车钩力 686-875kN、原发散区 ep849-856 **零复发**（ep849 loss=-0.002、ep856[原+1.283] 现 -0.010），KL 早停提前到 epoch 3-4。

## 4. 已调查但未改动（dt / 向量化，供记录）

- **为何 dt=0.1 合理**：Zhang2024 DQN 论文实际用 **Δt=100s**（非 0.1），且它是单质点、明忽略车钩力（`docs/papers/Zhang2024_DQN_CyclicBraking_Downhill.txt` line 823）。本项目不能拉大物理 dt——缓冲器冲击事件 50-100ms，`train.py` L527-543 内部自动拆 `≤0.01s` 子步否则发散，车钩力 ≤1000kN 是论文硬底线创新点，拉 dt 会吞制动脉冲自毁卖点。
- **物理积分器已向量化**结论：车钩力（`_coupler_forces` line331）、Davis 阻力、坡度、Newmark 迭代主体均向量化（np.where/数组切片）。残余**逐车 for 循环**仅在控制力计算 `_tractive_forces`/`_air_braking_forces`/`_electric_braking_forces`（line396/433/452，每控制步执行一次非每子步），非第一瓶颈，**不建议**优化（收益可忽略）。
- **降本建议**：唯一能成量级省时是 GPU 批量物理重构，但风险大易污染已锚定的车钩力/Newmark 验证数值，项目规则禁止为省时破坏物理保真 → **不推**。若只求墙钟更快，可改为**并行多 seed 进程**（不同 CPU 核各跑一 seed），但需先确认 CPU/内存够（暂未评估）。
- **【2026-09-20 已执行】并行多 seed 进程已验证并被采用**（详见 §1）：机器 8 物理/12 逻辑核 + 31.6GB 内存（WSL 上限 15.8GB），跑 5 个 seed 单核进程富余。**代价为内存带宽竞争 → 单 ep 由 150s 涨到 ~268s，净提速 ~2.8×（非 5×）**。结论：追加并行度无益（已带宽受限），不必再评估。
