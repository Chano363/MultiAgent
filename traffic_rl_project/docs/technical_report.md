# 多智能体无人机编队控制强化学习项目技术报告

## 1. 项目概述

### 1.1 项目背景
本项目是一个基于强化学习的**多智能体无人机编队控制系统**，研究目标包括：
1. **保持稳定距离** - 维持无人机之间的恒定空间间隔
2. **解决扰动放大问题** - 抑制编队中的扰动传播
3. **编队协调** - 实现多无人机协同控制
4. **提高运输效率** - 最大化平均速度

### 1.2 核心目标
- 开发基于专业物理仿真器的多智能体编队控制环境
- 实现基于 gym-pybullet-drones 的真实物理训练
- 优化编队控制性能指标

### 1.3 技术亮点
- 使用 gym-pybullet-drones 专业物理仿真器
- 支持多智能体协同训练
- 集成 Agent Lightning 优化框架
- 支持 GPU 加速训练

## 4. 仿真器集成

### 4.1 gym-pybullet-drones 简介

gym-pybullet-drones 是多伦多大学动态系统实验室开发的专业无人机仿真平台：

- **开发机构**: 多伦多大学 UTIAS DSL 实验室
- **许可证**: MIT 许可证（开源免费）
- **发表会议**: IEEE IROS 2021
- **物理引擎**: PyBullet

### 4.2 环境配置

**配置文件**: `configs/env_config.yaml`

```yaml
environment:
  name: "formation_control"
  num_drones: 3
  target_distance: 5.0
  max_speed: 10.0
  max_acceleration: 2.0
  max_steps: 1000
```

### 4.3 状态空间（每无人机24维）

| 维度 | 含义 | 范围 |
|-----|------|-----|
| 位置 | XYZ坐标 | [-inf, inf] |
| 速度 | 线速度 | [-max_speed, max_speed] |
| 姿态 | 四元数 | [-1, 1] |
| 角速度 | 角速度 | [-inf, inf] |
| 电机转速 | 四个电机RPM | [0, 20000] |

### 4.4 动作空间（每无人机4维）

| 维度 | 含义 | 范围 |
|-----|------|-----|
| 电机0-3 | 四个电机转速指令 | [0, 1] (归一化) |

## 5. 奖励函数设计

### 5.1 奖励组成

| 奖励项 | 权重 | 说明 |
|-------|-----|------|
| **距离保持** | 0.2 | 惩罚与目标距离的偏差 |
| **速度奖励** | 0.2 | 奖励较高速度 |
| **平滑性惩罚** | 0.2 | 惩罚剧烈加速变化 |
| **协调奖励** | 0.2 | 奖励速度一致性 |

### 5.2 奖励计算公式

```python
reward = -distance_weight * distance_error + \
         speed_weight * normalized_speed - \
         smoothness_weight * acceleration - \
         coordination_weight * speed_difference
```

## 7. 训练流程

### 7.1 训练命令

```bash
# 基础训练（50回合）
python src/scripts/agent_lightning_train.py --algorithm PPO --episodes 50

# 完整训练（500回合）
python src/scripts/agent_lightning_train.py --algorithm PPO --episodes 500

# 从检查点恢复
python src/scripts/agent_lightning_train.py --algorithm PPO --checkpoint outputs/checkpoints/ppo_formation_ep50.pt
```

### 7.2 训练参数

| 参数 | 说明 | 默认值 |
|-----|------|-----|
| `--algorithm` | 训练算法 | PPO |
| `--episodes` | 训练回合数 | 500 |
| `--device` | 训练设备 | cuda |
| `--checkpoint` | 检查点路径 | None |

## 8. 性能评估指标

### 8.1 评估指标

| 指标 | 计算方式 | 说明 |
|-----|---------|------|
| **平均奖励** | 所有回合奖励均值 | 训练效果整体评估 |
| **最佳奖励** | 单回合最大奖励 | 峰值性能 |
| **平均速度** | 所有无人机速度均值 | 运输效率 |
| **距离误差** | 与目标距离的偏差 | 编队精度 |
| **收敛状态** | 奖励标准差阈值判断 | 是否收敛 |

### 8.2 收敛判定

- **窗口大小**: 50回合
- **标准差阈值**: 0.1 × 平均奖励
- **连续检测**: 5次收敛判定
