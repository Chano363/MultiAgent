## 3. 相关性

## 4. 结论：RL 学到的是否是"规则启发式"？

RL 学到的协同策略**与"间距/速度差反馈"规则方向一致**（负相关于间距、正相关于速度差），即 RL 学到了类似"后列快/间距近 → 提前制动"的启发式。

**但需与 M4（规则启发式基线）对比**：若 RL 协同的性能 ≥ 规则启发式（PID/分段规则），则 RL 增量在于**自适应权重/非线性**（RL 学到的是数据驱动的精确映射，而规则需手工调参）；若 RL < 规则，则需重新设计。
