## 页 2 · 优化动力学建模

- **正文**
  - 车钩缓冲器统一为 MT-2 摩擦式迟滞缓冲器，机车与货车连挂钩同一模型：
    - 静摩擦 750 kN / 动摩擦 500 kN，Stribeck 特征速度 v_er = 0.2 m/s
    - 预压（阻抗）200 kN；行程 83 mm 时饱和 2270 kN
    - 机车 QKX100 弹性胶泥分区模型全部移除，仅作文献追溯
  - 新增车钩间隙死区（默认 10 mm），复现「间隙 → 纵向冲动」的物理规律。
  - 空气制动双向传播 + 多源制动：常用制动波速 200 m/s、紧急制动 250 m/s；缓解过程按缓解波速传播并叠加指数排风。
  - 修正两处历史性动力学偏差：Davis 空气阻力改为标准形式（不再被车重放大）；Newmark 迭代收敛后取未松弛候选解（此前欠松弛中间量污染最终状态，等效动力学缩水约 25%）。
- **公式**

  Davis 阻力（标准形式，独立于车重）：

  ```
  R(v) = a + b·v + 0.0018·C·A·v²
  ```

  制动传播延迟（按车辆累计长度，非车钩自由行程）：

  ```
  Δt_i = ( Σ_{j<i} L_j ) / v_wave ,   v_wave = 200 m/s（常用）/ 250 m/s（紧急）
  ```

## 页 4 · 新的强化学习架构（一）：框架变化

- **正文**
  - 变化要点一：实验对象由 3 列 × 1+0 改为 3 列 × 1+1，智能体数由 3 增至 6（每台机车一个智能体）。
  - 变化要点二：废止「编队层阈值 RL + 列内层 RL」两层叠加表述，仅保留一套编队感知的机车级 ED/AB 分工 RL。
  - 分工机制：电制动连续可调（仅机车，受功率与粘着约束）；空气制动为离散档位（缓解 / 最小 / 常用 / 紧急），沿车列按波速向后传播。RL 输出逐机车调制量，规则层负责列内循环制动与单车安全兜底。
  - 分层关系（自上而下）：
    ```
    编队目标（最终目的，非 RL）：多列群组长大下坡协同
      安全列距 + 速度带一致 + 车钩力 ≤ 1000 kN
            ↓ 由同一套 RL 承载（编队上下文）
    RL 落位（唯一手段）：机车级 ED/AB 分工，每台机车 = 智能体
            ↓ 目标速度 / 档位
    底层执行（确定性）：列内规则循环制动 + 车钩力安全层
    ```
- **表格（架构对照）**

| 维度 | 上次（2026-08-31） | 本次 |
|---|---|---|
| RL 落位 | 编队层阈值 RL（每列车 1 智能体）+ 列内规则 | 机车级 ED/AB 分工（每机车 1 智能体） |
| 智能体数 | 3 | 6 |
| 编组 | 1 机车 + 100 货车 | 1 机车 + 94 货车 + 1 机车 |
| 动作 | 速度带阈值偏移 c_adj ∈ [−1,1] | 逐机车 [ed_mod, ab_mod] ∈ [−1,1] |
| 制动 | 空电混合 | ED 连续 / AB 离散档位，分离 |
| 底层 | 规则循环制动 | 规则循环制动 + 车钩力安全层（确定性） |

## 页 5 · 新的强化学习架构（二）：奖励设计

- **正文**
  - 领航列锚绝对速度带（编队节奏负责人）：带内越接近带中心奖励越大，越带线性硬罚，超线路限速额外惩罚。
  - 跟随列改为相对锚定：镜像前列轨迹的相对速度匹配奖励，不再被绝对速度带与全局速度标准差拖累（绝对同速在 53 km 多坡段物理不可达）。
  - 列间安全：列距误差高斯奖励 + 过大线性罚；间距进入 40% 动态安全距后由追尾势场强罚兜底；另设追尾趋势早期惩罚。
  - 车钩力定位：作为硬安全层约束（钳制 |F| ≤ 1000 kN）与观测上下文，不进入奖励，不作为策略最小化对象。
- **公式**

  领航列速度带奖励（v_center = 60 km/h，band_half = 20 km/h）：

  ```
  norm_dev = |v − v_center| / band_half
  norm_dev ≤ 1 →  +6 · (1 − 0.9 · norm_dev)
  norm_dev > 1 →  −20 · (norm_dev − 1)
  v > v_max    →  额外 −5 · (v − v_max)
  ```

  跟随列相对锚定（Δv = 本列速度 − 前列速度）：

  ```
  r = +2 · max( 0, 1 − (Δv / 3)² )
  ```

  列距与追尾势场（ge = 实际列距 − 目标列距）：

  ```
  r_gap  = exp( −(ge / 140)² ) − 0.02 · max(0, ge − 150)
  r_pot  = −2 · (min_gap − actual_gap)² ,  actual_gap < 0.4 · 动态安全距
  ```

## 页 7 · 完整的 ATP 安全保证

- **正文**
  - ETCS 目标距离速度监督：以前车尾车位置为监督目标构建制动曲线，列车速度被持续约束在紧急制动干预曲线之内，从机制上杜绝追尾。
  - 安全层永久启用、无开关：限速监督、车钩力钳制（≤ 1000 kN）、最小列间距三项始终生效。
  - 空气制动减权限：反应式禁止新增空气制动源（避免多机车同步触发造成车钩力冲击），同时对已建立制动的滞后峰值做预测式钳制。
  - 口径统一：安全层输入、违规计数与评估指标统一为「单钩断面力」`coupler_interface_forces`，消除此前多口径并存导致的一致性问题。

## 页 10 · 遇到的问题（请导师指导）

- **正文**（编号、单行、不求解释）
  1. 算力紧张：物理仿真单线程，5 seed × 1400 回合本机需连续运行数天。

  4. 跨线剖面难选：既要训练阶段未见过，又要落在训练状态分布内。
