## 页 1 · 研究定位与本轮进展概览

- 论文题目 + 研究对象（一万吨级 1+1 重载列车群组）
- **主轴**：编队是目的（多列群组，安全列距 + 速度带一致 + 车钩力 ≤ 1000 kN）；MARL 是手段
- 唯一 RL 落位：**机车级 ED/AB 分工**（每台机车 = 智能体）；底层 = 列内规则循环制动 + 车钩力安全层
- 本轮新增（2026-10-03~10-07，五项）：
  1. **安全层补漏**：牵引纳入 ATP 钳制；ATP 制动置于最后、不可被车钩力缓和放掉；AB 否决按 90 s 真实滞后预测 → 沙盒 80 集**列距穿透归零**
  2. **间距奖励对齐 ATP**：安全底线取 ETCS 制动距离，越线惩罚不封顶
  3. **训练起点随机化**：短窗不变而覆盖全路，评估中未见坡段占比 **83.9% → 4.1%**
  4. **训练并行提速**：`n_env` 改进程级并行，单 seed 机时由约 3.5 天降至约 1.5 天
  5. **观测加 AB 充风计时**：把 222 s 充风滞后编进状态，替代拉长窗口（ADR-030）
- **当前最要紧的一件事（详见第七部分）**：训练地平线 120 s 短于空气制动最小充风 222 s，导致"训得好、跑完整剖面就破线"

## 第二部分 · 物理仿真与建模（页 2–6）

### 页 2 · 动力学建模总体
- 总方程：`m_i a_i = F_trac,i + F_ED,i + F_air,i − F_res,i − F_grade,i + F_cpl,i`
- 逐项一句话说明（牵引 / 电制 / 空气制动 / Davis 阻力 / 坡度 / 车钩）
- **力的分层**：控制力（F_trac / F_ED，仅机车，RL 动作）｜ 离散控制力（F_air，波速传播）｜ 环境力（F_res / F_grade，不可控）｜ 耦合力（F_cpl，靠安全层约束）
- 不放 MT-2 公式（后置专页）

### 页 3 · 车钩模型（MT-2 摩擦式迟滞）
- 阻抗 = 预压力 + 弹性力 ± 库仑摩擦（加载 / 卸载两支形成迟滞环）
- 公式链：
  - `F_mag = F0 + k·x + sgn(Δv)·μ(|Δv|)·F_N`
  - 加载：`F_cpl = F0 + k·x + μF_N`；卸载：`F_cpl = F0 + k·x − μF_N`
  - 约束：`|F_cpl| ≤ F_max = 2270 kN`、`|x| ≤ s_max = 83 mm`
  - Stribeck 分段：`750 kN → 500 kN`（线性过渡），`v_er = 0.2 m/s`
- 参数表（无单位列，含义不加括号）：

| 符号 | 含义 |
|---|---|
| F₀ = 200 kN | 缓冲器预压力 |
| k = 1.89×10⁷ N/m | 弹性刚度，由行程打满恰达最大阻抗反推 |
| 静摩擦 750 kN | 相对速度趋零时的摩擦阻抗 |
| 动摩擦 500 kN | 相对速度达 v_er 后的摩擦阻抗 |
| v_er = 0.2 m/s | 静动摩擦过渡的特征速度 |
| 饱和 2270 kN | 缓冲器最大阻抗 |
| 最大行程 83 mm | 缓冲器最大压缩量 |

- 参数三类来源：文献实测（F₀ / s_max / F_max）｜ 文献结构 + 标定（μ_s / μ_k / v_er）｜ 约束反推（k）
- 迟滞耗能：加载支 − 卸载支 = `2μ(|Δv|)F_N`；摩擦恒反对相对运动、低速不消失（区别线性阻尼）
- 四条支 = 2 方向（压缩 / 拉伸）× 2 状态（加载 / 卸载），是**同一迟滞回线的四分支**
- 图：MT-2 迟滞环（`images/02a-coupler-hysteresis.png`）——**待按纯英文标注重画**（见文末待办）

### 页 4 · 空气制动
- ED 连续 + AB 离散档位；AB 沿列车**双向波速传播**（1+1 编组两端向中间汇合）
- 波速：常用 / MIN 档 200 m/s，紧急档 250 m/s
- 缓解两段式排气（波传播期满 + `exp(−t/τ)`）
- 缓解再充风时间约束（困难区段最短充风 222 s）

### 页 5 · 数值求解
- `dt = 0.1 s`（控制 / 观测频率）；车钩冲击内部子步 `≤ 0.01 s`（`n_sub = ceil(dt/0.01)`）
- Newmark-β 隐式（β = 1/4，γ = 1/2）+ Picard 迭代（欠松弛 α = 0.5，`max_iter = 30`）
- 取**未松弛**解作为收敛解

### 页 6 · 模型验证（实测锚点）
- 张二田 S1 统计对照：92 次循环，均值 685 kN（实测 1021 kN）；>1000 kN 11/92（实测 11/19）
- 全程峰值 1677 kN ∈ 四源实测带 [1000, 1800] kN
- 结论：量级疑点已解除（**注意：旧稿"车钩力峰值低约 40%"为过期结论，勿再引用**）

## 第三部分 · 控制方法（页 7–9）

### 页 7 · 控制架构流程

主链（自上而下，闭环）：

```
状态观测（编队上下文）
   ↓
MAPPO（每台机车 = 一个智能体，共享 Actor-Critic）
   ↓
动作（逐机车 2 通道）
   ↓
底层执行层（确定性；= 规则层 + 安全层两个模块串联）
   ① 规则层 MultiLocoController：循环制动基线 + RL 加性调制 + 车钩力缓和
   ② 安全层 SafetyLayer(ATP)：ETCS 防追尾 + 限速 + 车钩力 ≤ 1000 kN 钳制 + AB 禁新增源
   ↓
纵向动力学（MT-2 车钩 + ED/AB 双向缓解波 + Newmark-β）
   └────────→ 闭环反馈回观测
```

**动作（逐机车 2 通道）——人话版**
- 每台机车每步输出两个数：`ed_mod`、`ab_mod`，都落在 [−1, 1]
- `ed_mod` = 电制动调多深：规则层已给基础深度，RL 在基础上最多 ±0.5（`ed_mod_coef = 0.5`），再卡在 0~1
- `ab_mod` = 空气制动何时介入：`> +0.15` 压住本机车 AB 源（该挂时不挂）；`< −0.15` 提前挂 MIN 档兜底；中间不动
- 一句话：**RL 不直接踩刹车，只在规则层给的底子上做微调**

**底层执行层 = 包含关系**
- "底层执行层"是 PPT 概念分组（代码中无此类），= 规则层 + 安全层两个模块**串联**
- 规则层 ⊂ 底层执行层；安全层与规则层同级、位于其后、有否决权
- 规则层管"正常怎么开"，安全层管"不许越线"

观测 = **逐机车 12 维**：速度误差 · 超上限裕量 · 低下限裕量 ｜ 规则基线 ED / AB ｜ 本机车车钩力 ｜ AB 激活比例 · 缓解剩余比例 · 制动段序号 ｜ 本机车位置 ｜ 列间间距误差 ｜ **AB 充风就绪度（新增）**

- 新增第 12 维 = 距上次 AB 释放的充风时长 ÷ 222 s：**把充风滞后做成可观测量**，短窗内即可感知，不必拉长窗口

**修正记录（相对旧架构图）**：① 单一 `alpha` → 逐机车 2 通道 `(ed_mod, ab_mod)`；② 补安全层 ATP 支路；③ 补闭环反馈；④ 1+1 编组、AB 双向缓解波；⑤ 观测 11 → 12 维（AB 充风计时）

### 页 8 · 底层执行层的运算顺序（一个控制步 10 步链）

```
① 规则层出基线 baseline = get_action_cyclic_braking(...)
     队首速度 ≥ v_max → 制动：ED 打满 × 逐机车错峰(队首 1.0/队尾 ~0.7) × scale；
        ED 可用力/需求力 < 0.99（陡坡高速 ED 不够）才引入 AB 源
     ≤ v_min → 缓解：ED = 0、AB = 0
② RL 调制叠加到基线（逐机车）
     电制动：final_ed = clip(baseline_ed + 0.5·ed_mod, 0, 1)
     空气制动三分支 × 四道关：
       基线已挂 AB 且 ab_mod > +0.15 → 想压住：过【速度裕量】+【保持时间】两关
       基线未挂 AB 且 ab_mod < −0.15 → 想提前挂：过【力比 <0.6】+【并发 ≤1】
                                        +【安全层源头否决】+【充风时间】四关
       |ab_mod| ≤ 0.15 → 不动
③ 车钩力缓和：ratio = 断面力峰值/1000；ratio ≤ 0.8 → scale = 1；
     ratio > 0.8 → scale 从 1 线性降到 0；final[:,0] *= scale、final[:,1] *= scale
④ 规则层自身新 AB 源复查充风门（off→on 且未满 222 s → 本步不发）
⑤ 提交 AB 状态（记录 0→1 施加 / 1→0 释放时刻）→ 交回 env
⑥ env 投影（**带符号**）：牵引以正号进安全层（`>0` 牵引 / `<0` 制动），制动 = −max(ED 深度, AB 档位深度)
⑦ 安全层 protect()，**顺序 = 优先级**：A 车钩力缓和 → B 间距防挤压 → C 反应式超速 → D ETCS（最后施加、不可被覆盖）
     命中 ETCS EBI → 全列空气紧急制动，并清空本步 AB 源
⑧ 安全层修正**回写**：牵引与 ED 同步归零，否则安全层被绕过
⑨ 安全层 AB 减权限：`ab_new_source_veto()` 命中 → 丢弃本步全部新源（绝不撤销已建立源）
⑩ 交纵向动力学：dynamics.step_vehicles_ed_ab(throttle, ed_throttle, ab_command, ab_sources)
→ 输出 每节车位置/速度 + 车钩断面力 → 闭环回观测
```

**纵向动力学（被底层执行层调用）**
- 输入：`throttle`（逐车指令）· `ed_throttle`（逐车电制动深度）· `ab_command` + `ab_sources`（空气制动指令与波源）· 坡度剖面
- 内部四步：① 空气制动**波速传播**（1+1 双向，常用/MIN 200 m/s、紧急 250 m/s）→ 每节车闸瓦力 ② **逐车受力**（`F_trac` / `F_ED` / `F_air` / Davis 阻力 / `F_grade` / MT-2 车钩力）③ **Newmark-β 隐式**（β = 1/4，γ = 1/2）+ Picard 欠松弛（α = 0.5，≤30 次），子步 ≤0.01 s ④ 更新位置 / 速度
- 输出：每节车位置 `pos` / 速度 `vel` + **车钩断面力**（指标口径）

- AB 最小充风时间门 `ab_min_refill_s = 222.0`（依据 Zhang2024 式 (9)）；单步并发新增源 ≤ 1
- 规则层管单车安全制动，RL 只做**加性调制**、管多车编队协同
- 两处本轮修正：牵引须进安全层（否则 ATP 管不住牵引）；AB 否决的预测时域取 90 s 真实滞后（原按波到达时间约 6 s，拦不住滞后峰值）

**底稿（不上幻灯）**：牵引此前被投影为 0，EBI 触发时仍满牵引 ⇒ 长大下坡虚耦合穿透；`coupler_veto_lag_s = 90.0` 取自实测「AB 首现 → 车钩力首破」约 90.1 s，需足够历史长度才启用，防短历史噪声被 90 s 外推放大成"全禁 AB"

### 页 9 · 安全层（ATP）与规则层的关系

**不是包含，是"串联 + 否决权"**：规则层在前生成候选动作，ATP 在后复核，且 ATP 能改 / 丢规则层产出，反之不成立。

| 维度 | 规则层 `MultiLocoController` | 安全层 `SafetyLayer`（ATP） |
|---|---|---|
| 定位 | 正常怎么开（固化司机经验） | 不许越线（安全兜底） |
| 职责 | 循环制动基线 + RL 调制 + 车钩力缓和 | ETCS 防追尾 · 限速 · 车钩力 ≤ 1000 kN 钳制 · AB 禁新增源 |
| 内部规则顺序 | — | A 车钩力缓和 → B 间距 → C 超速 → D ETCS（**最后施加、不可被覆盖**） |
| 位置 | 前（生成） | 后（复核） |
| 权限 | 生成 | **否决**（可改 / 丢规则层产出） |
| 开关 | 有 | **永久启用、无独立开关** |
| 调 AB 能力 | 全（可建立 / 撤销源） | **只减不增**（仅丢新源，绝不撤销已建立源） |

- 一句话：**规则层提案，ATP 否决**；规则层产出必须过 ATP 才能进动力学
- `ab_new_source_veto()`：断面力 ≥ 0.6·limit 禁止新增 AB 源（反应式）/ 外推峰值 ≥ 0.9·limit（预测式，**外推时域 = 90 s 真实滞后**，ADR-025）

**ATP 到底管不管用（定向压测：合成更慢前列，−12‰ 陡坡）**

| 后列动作 | 修复前最小列距 | 修复后最小列距 |
|---|---|---|
| 全牵引 | **−65.3 m（穿透）** | **+75.4 m** |
| 惰行 | +82.5 m | +82.5 m |
| 全制动 | +192.2 m | +192.2 m |

- 一句话：**只有牵引档穿透**，且修复前 EBI 已触发 2316 步仍压不住 ⇒ 穿透的唯一因子是牵引未进安全层；修复后沙盒 80 集穿透归零

**底稿（不上幻灯）**：修复后 `gap_min` 最小 +46 m（同 seed 修复前 ep20 −7 m、ep25 −53 m）；价值函数污染同步消失（`vstd` 由阶跃 1.7×10⁴ 回到全程 819→2105）；追尾不作指标，评估入口以 `assert rear_end_steps == 0` 守卫，主表报 ATP 触发次数

## 第四部分 · 对比基线（页 10–11）

### 页 10 · MPC 基线怎么设才公平

- 唯一 MPC 基线 = `NMPCController`（在线优化 + IPOPT；旧的简化 MPC 已删除，历史数值作废）
- **公平三件套**（避免比出"人为劣势"）：
  1. **信息给足**：逐线重新喂入该线真实坡度图纸，并在线标定阻力系数 `b₀`；不按坡道切换模型
  2. **架构对齐**：MPC 与 D-RL 各自都叠同一层规则循环制动 + 同一个安全层（ATP）
  3. **动作权限对齐**：MPC 输出反解为与 D-RL 相同的 `(ed_mod, ab_mod)` 加性调制
- 比什么：**不比"谁控得更准"，只比"谁扛得住部署"**

### 页 11 · 主 claim：免重辨识成本

- D-RL 跨线**零微调**：同一 ckpt 直接上（声明 `no fine-tuning on target line`）
- NMPC 要**逐线重标定**（重喂该线坡度 + 重标 `b₀`）才能达到同等性能
- claim：**零微调的 D-RL ≈ 逐线重标定后的 NMPC** —— 省掉的是重辨识成本
- 不做"MPC 不重辨识就失配"的论证：那属领域常识，不构成贡献

**奖励设计**（每条：激励条件 / 惩罚条件 / 效果）

1. **速度跟随**
   - 激励：领航车速度落在 40–80 km/h 带内，越靠中心奖励越大；跟随车与前车速度差越小。
   - 惩罚：领航车越出带外，偏离越远惩罚越大；超过线路限速时加重。
   - 效果：全队贴在容许速度带内运行，且不要求各车绝对同速。

2. **车间距**（底线 `d_safe` = ETCS 制动距离，与 ATP 介入线同源）
   - 激励：实际间距接近效率目标 `d_eff = 1.1·d_safe`，越近越高；拉得过远衰减为 0。
   - 惩罚：跌破 `d_safe` 时按越线比例平方陡罚，**不封顶**。
   - 效果：不触发 ATP 的前提下尽量缩小列距，且"越线"绝不被速度带收益抵消。

3. **纵向冲动**
   - 激励：无。
   - 惩罚：加速度幅值越大，扣分越多。
   - 效果：抑制纵向冲动，削减车钩力冲击的来源。

4. **车钩力**
   - 激励：无。
   - 惩罚：车钩力越大扣分越多；超过 1000 kN 时加重。
   - 效果：在硬安全层之外提供梯度信号，引导策略避开破线工况，不作均值最小化。

5. **电空分工**
   - 激励：无。
   - 惩罚：领航车越带或超速却未投入空气制动；电制动使用按深度收小额费用。
   - 效果：空气制动仅在电制动不足时介入，避免过度用闸。

注：防追尾、限速与车钩力上限由规则层与安全层硬性保证，不依赖奖励。

**奖励设计（公式版，论文用）**　`dev = abs(v − v_c) / band_half`，`v_c = 60 km/h`，`band_half = 20 km/h`；`Δgap` = 实际列距 − 目标列距；`Δv` = 本列速度 − 前列速度

| 奖励项 | 公式 |
|---|---|
| 领航列速度带 | 带内 `+6 (1 − 0.9 dev)`；越带 `−20 (dev − 1)`；超线路限速额外 `−5 (v − v_max)` |
| 跟随列相对锚定 | `+2 max(0, 1 − (Δv / 3)²)` |
| 列距·效率项（v4） | `gap ≥ d_eff` 时 `+3.0·max(0, 1 − (gap − d_eff)/150)`，`d_eff = 1.1·d_safe` |
| 列距·危险项（v4） | `gap < d_safe` 时 `−60·over²`，`over = (d_safe − gap)/denom`，`denom = d_safe`（`d_safe>1 m`）否则 `= 100 m`；**不封顶** |
| 追尾保护 | `gap < 5 m` 再 `−10 / 对`（仅最后兜底，主要靠危险项） |
| 加速度惩罚（抑制纵向冲动） | `−0.3 mean(a²)` |
| 车钩力 | 常态 `−0.2 mean(断面力) − 0.2 峰值归一`；破线时额外 `−6 min(峰值归一 − 1, 2)`（上界 −12） |
| 电空分工 | 带外 / 超速却无 AB 时 `−0.5`；ED 使用 `−0.02 Σ 深度` |

注：车钩力**不作均值最小化对象**；安全（车钩力 ≤ 1000 kN · 防追尾 · 限速）由规则层 + ATP 硬性保证。

## 第七部分 · 问题与下一步（页 18–21）

### 页 18 · 主问题：训得好，跑完整剖面就破线

**症状（同一批 ckpt，两种口径对照）**

| 口径 | 车钩力峰值 | 超限步数 |
|---|---|---|
| 训练窗（1200 步 = 120 s） | ≤ 864 kN | 0 |
| 完整 53 km 评估 | **1149–1168 kN** | **109–444** |

- 达标判据（超限 = 0 且峰值 ≤ 1000 kN 且末速带内）**五个 ckpt 一次都没满足**
- 一句话：**训练窗里"干净"的权重，放到完整剖面就稳定破线**

**根因：物理时域不够（三步链）**

1. 单条训练回合 = 1200 步 × 0.1 s = **120 s**
2. 空气制动最小充风 = **222 s** ⇒ 一个回合内连一次完整充风都完成不了
3. ⇒ 循环制动"充风 → 二次制动"的峰值**结构性落在回合之外**，RL 拿不到针对它的梯度

**已排除（这些都查过，不是原因）**

- 不是新配置引入的回归：旧配置同剖面也是 1157.6 kN
- 不是训练轮数不够：ep50 → ep240 恒在 1149–1168 kN
- 不是并行实现缺陷：串行 / 并行同 ckpt 峰值同档
- 不是评估口径假象：评估与训练同参后复评仍 1149.3 kN
- 不是某段坡度的问题：16 km 切片已覆盖破线里程 25.4–37 km，其上却不破线

**诚实边界（汇报口径，勿越线）**

- **不能说**"峰值学不会"：旧配置曾在完整 53 km 达标（956 kN / 超限 0）
- **只能说**：短窗给不出针对该峰值的梯度

**顺带解释**：沙盒与短训长期"全绿"（795–901 kN、超限 0），因为它们的窗口同样短于 222 s
