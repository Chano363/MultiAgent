**二、项目简介**

  -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  重载列车群组在连续长大下坡路段行驶时，空气制动延时与坡道扰动会引起列车间时距波动，并沿编组向后逐级放大，导致车钩力冲击超标、制动可控性下降，制约万吨级1+0编组的运输效率。本项目面向长大下坡场景，研究基于多智能体强化学习（MARL）的万吨级重载列车群组自动控制方法，以循环制动、多列群组协同、车钩力约束为三大支柱。基于朔黄线宁武西---北大牛49.6km真实纵断面构建列车-线路耦合仿真环境，将多列万吨级列车虚拟耦合群组的协同控制形式化为多智能体决策问题，设计电制动/空气制动解耦的动作架构与融合车钩力抑制、间距保持与速度协同的安全奖励，采用集中式训练分布式执行（CTDE）架构的MAPPO算法并搭建传统控制对比基线，实现长大下坡工况下列车群组的间距保持、速度协同与车钩力安全控制。研究成果可为我国重载铁路的智能化发展提供理论和方法支撑。

| （1）重载列车群组多智能体建模与环境构建。将群组中的每列"1+0"万吨列车建模为1个智能体，共三列列车编组，3个智能体。建立包含列车纵向动力学、空气制动延迟、车钩非线性及线路 |
| 坡度/弯道阻力的仿真环境。将长大下坡道的群组协同控制问题形式化为多智能体马尔可夫决策过程，明确全局状态、各智能体局部观测、联合动作空间和奖励函数的定义。                |

**四、项目实施进展**

+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| （一）已开展的工作                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （1）文献调研与技术方案确立（2026年6月）。项目启动后，团队系统调研了重载列车运行控制、列车纵向动力学与多智能体强化学习三个方向的国内外文献50余篇，重点研读了MAPPO等集中式训练分布式执行架构及安全约束强化学习的代表性成果；经对标分析发现，现有多列列车群组控制研究在协同循环制动场景下普遍弱化或忽略车钩力约束，据此确立"循环制动、多列群组协同、车钩力约束"三大支柱的研究定位，并按期完成立项答辩。                                                                                 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （2）无人机编队仿真平台方法论验证（2026年7月）。作为技术路线的第一阶段，基于gym-pybullet-drones构建3机编队仿真环境（速度控制模式），实现MAPPO算法训练并稳定收敛（最优回报235.5、稳态编队误差0.497 m）；同步开展算法选型对比，发现PPO训练不稳定、SAC后期策略退化，引入KL早停机制后策略坍缩率由11.8%降至0。该阶段验证了CTDE多智能体训练框架的可行性，确立了以MAPPO作为重载列车场景的算法基座。                                                                                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （3）重载列车动力学仿真环境搭建与校验（2026年7月---9月）。参考NeTrainSim建模思想自研万吨级重载列车纵向动力学：对每节车辆建立牵引力、电制动、空气制动、Davis基本阻力、坡道附加阻力及前后车钩力模型，采用半隐式Euler积分，实现空气制动充/缓解波沿列车管的传播物理与ATP安全限速层，并以Gym接口封装；导入朔黄线宁武西---北大牛49.6km真实纵断面，在万吨编组循环制动工况下完成环境验收测试40项，车钩力峰值稳定守住1350                                                                      |
| kN安全红线；期间重构缓解波传播物理与数值积分方法，修复了动力学失真缺陷。                                                                                                                                                                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （4）MARL问题形式化（2026年8月中旬---9月中旬）。以朔黄线3列万吨级"1+1"编组列车虚拟耦合群组为对象，将长大下坡协同控制问题形式化为多智能体马尔可夫决策过程：每列车观测速度误差、间距误差、车钩力与位置等局部信息，动作为电制动/空气制动解耦的离散档位，奖励函数以冲动（车钩力）最小化为主、辅以间距保持与速度带同步项；设计了协同/独立控制的对比实验方案以量化群组协同收益。                                                                                                            |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （5）MAPPO训练链路搭建与训练诊断迭代（2026年9月中旬至今）。完成训练与评估代码链路及实验元数据管理，搭建NMPC、单列独立规则控制、忽略车钩力的群组MARL等对比基线；开展多轮训练与判别性诊断实验，针对车钩力超限、策略发散等问题完成归因分析，并实施奖励量级重构、安全层制动权限、充风时间门控、逐智能体优势估计等改进措施；当前正在开展1400回合×5随机种子的重训练，部分策略权重在49.6km全剖面评估中实现速度带宽率很高、车钩力峰值有效降低，满足1350kN安全红线要求，总体进度符合实施计划。 |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （二）项目实施存在的困难及解决办法                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （1）列车动力学建模方面：空气制动充/缓解波沿列车管的传播与数值积分欠松弛问题曾导致动力学状态失真，直接影响训练与评估的有效性。解决办法：重构缓解波传播物理与半隐式Euler积分方法，以工况枚举替代布尔开关并隔离旧版本仿真资产，采用朔黄线49.6km真实纵断面与万吨编组循环制动工况对模型进行系统校验，环境验收测试全部通过。                                                                                                                                                               |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （2）奖励设计与安全通路方面：车钩力项在奖励中量级占比过低且超限无跳变，学习信号被速度带收益淹没；空气制动通路一度绕过安全层，策略倾向于多用空气制动，导致车钩力超限破线。解决办法：将车钩力超限改造为量纲受控的非线性显著项纳入优化目标，赋予安全层对空气制动的削减权限（含90秒滞后否决），引入最小充风时间门控，并参考对标文献将充风约束纳入动作空间设计。                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （3）多智能体信用分配方面：标量优势函数广播使多台机车共享同一梯度信号，且训练有效视界远短于空气制动到车钩力峰值的物理滞后（约90秒），车钩力峰值难以归因到肇因动作。解决办法：改为逐智能体优势估计并延长回报视界覆盖延迟窗口，设计"在飞波锁止"等判别性对照实验验证机制有效性，实验中车钩力峰值由1268.9 kN降至777.1 kN。                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| （4）训练稳定性与算力方面：多随机种子训练出现发散与长训震荡（策略坍缩、价值归一化遗忘），单种子训练机时实测远超估算。解决办法：标准化KL早停判据、修正价值归一化方法、主结果采用末次权重；精简实验矩阵并错峰调度租用的GPU图形工作站，算力资源总体满足训练需要。                                                                                                                                                                                                                        |
