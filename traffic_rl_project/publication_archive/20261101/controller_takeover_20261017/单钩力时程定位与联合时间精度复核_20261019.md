# 单钩力时程定位与联合时间精度复核

日期：2026-10-19。分支：xmc-dev。生产动力学与规则层默认参数未替换；本轮修改为可选数值诊断候选。

## 结论

迭代残差、机械步长和气动/控制力更新时间必须分开检查。现阶段不能宣布规则层修复完成，也不能以低于1000千牛的峰值代替全线及三列验收。

本轮完成13组带来源记录的诊断运行和86项相关回归测试。没有启动强化学习训练，没有推送本轮改动。

## 1. 定位：最大力包络掩盖单个车钩误差

同一原始暖起点、相同控制器重放248.5秒，两组观测轨迹均与各自既有归档逐项完全相同，证明新增记录未改变轨迹。

在预测233.8秒，第101个车钩的两组力为211.0038与71.1082千牛，单钩差139.8956千牛；全车最大力包络差只有81.4460千牛。两组最大力发生的车钩不同。

该处位移差约8.5微米，相对速度分别为-0.00620与+0.00281米/秒。保持原速度差只替换位移，力变化约0.38千牛；保持原位移只替换速度差，力变化约139.80千牛。这是现有公式的代数归因，不是独立实测证明。

因此加入逐断面有符号力、相对位移和相对速度记录，不能继续仅用最大包络评价力时程。

## 2. 已实现的候选与检查

- 为现有MT-2查表/tanh模型推导完整解析切线，同时包含位移和速度导数；保留原始力公式和参数。
- 解析Newton仍以原始力平衡残差检查、线搜索及失败回退，不以解析近似代替最终受力。
- 独立差分检查覆盖游隙、加载卸载切换、饱和、刚性限位以及整个原始受力向量。
- 新增气动/控制力更新时间细化诊断：外部控制频率不变，每个指令只施加一次，失败时回滚整个原始区间。
- 新增保持原0.01秒坡度更新的隔离选项，避免把所有变化都归因于压力传播。
- 保存了预测200秒处的完整压力、车辆、控制器及计时状态，并校验文件来源。它是诊断预测状态，递归预测保护仍处于旁路模式，不能直接当成正式在线控制验收检查点。

## 3. 共同完整起点的48.5秒短窗口

共同起点来自0.000625秒机械步长、0.1牛顿迭代容差形成的预测200秒状态。以下均从同一完整状态开始；前200秒的历史精度仍不是全局误差证明。

| 独立检查 | 设置 | 最大同断面有符号力差 |
|---|---|---:|
| 迭代停止容差 | 0.01牛顿与0.001牛顿，机械步长均0.000625秒 | 0.000217千牛 |
| 机械时间步长 | 0.000625与0.0003125秒，迭代容差均0.01牛顿 | 6.3853千牛 |
| 机械时间步长 | 0.0003125与0.00015625秒，同上 | 3.1252千牛 |
| 气动/控制力更新时间 | 0.01与0.005秒，机械步长均0.000625秒 | 90.2764千牛 |
| 气动/控制力更新时间 | 0.005与0.0025秒，同上 | 45.7873千牛 |
| 坡度更新隔离 | 同为0.0025秒气动更新，保持原坡度更新与同步细化坡度比较 | 12.0027千牛 |

机械三档的控制采样峰值分别约455.141714、455.141685、455.141670千牛。它们非常接近，但局部力时程仍存在差异。这个48.5秒窗口的峰值不能和前200秒包含在内的约572.45千牛、或旧冷起点前缀约719.82千牛当作前后改进对比。

保持原坡度更新后，细化气动/控制力更新相对0.01秒仍有约130.73千牛的最大局部差异；所以坡度不是唯一来源。剩余差异仍同时包含压力传播、制动力随速度更新等因素，尚不能进一步断言只有某个压力参数错误。

全部短窗口制动请求一致。本文未设立新的工程验收误差门槛；数值容差的单位是牛顿，与1000千牛车钩指标不同。

## 5. 当前瓶颈及下一步

瓶颈从“求解是否收敛”转到“耦合瞬态是否足够准确且算得足够快”。继续微调规则层容易把数值误差当成控制改善。

下一轮优先核对波到达跨步时刻、到达后实际充气时长与区间制动力的计算顺序，形成事件对齐/分段积分候选，再用相同窗口做联合时间细化。涉及修改充气规律或车钩过渡规律时，需要同型试验与定标依据，不能以缩小力峰值为调参目标。

专项检索提示词已另存同目录。优先重读现有王青元/赵紫宁2022、李彬卓及周占松相关原文，不必重新泛搜MARL。需要补充的主要是50千帕缓解后再制动的连续压力数据，以及MT-2过渡参数和串联坐标定义。
