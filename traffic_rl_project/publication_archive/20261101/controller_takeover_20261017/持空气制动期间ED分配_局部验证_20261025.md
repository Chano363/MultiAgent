# 持空气制动期间的ED分配：局部验证（2026-10-25，round80—82）

## 基线延长失败

54km/h领航候选的1000.1—1200秒round80已正常跑完，但不能验收：54次ATP接管，全为第三列SBI，首事件1176.6秒、最后1182.4秒。内部峰578.972103kN，单车49.659202—74.933119km/h，最小实际列距362.173352m。没有速度或车钩力越界，并不等于无需安全接管。

首事件时三列均速69.466208/55.338939/70.720506km/h；实际ED输入均1；第三列充风计时已为0、普通AB源已建立。第二列尚余充风145.9秒。不能再把该事件归结为第三列充风未结束；这轮暴露的是相位与普通制动力建立时机不足。1200秒两对列距1532.202535/362.173352m，仍有很大的编队误差。

## 对增距过程的归因

对720.1—1000秒原始轨迹按空气源状态分段：第二、三列间列距278.849477→849.876227m，净增长571.026751m。两列空气制动源均开启的132秒区间，速度差积分贡献约412.568610m；前列源开启、后列源关闭阶段约143.269508m。速度积分为右端样本近似，与几何差值有离散误差；源开启不等于所有车辆已同压。这是关联归因，不能单凭该表证明ED是唯一原因。

原始归因JSON位于54候选1000秒目录phase_gap_attribution.json。结果说明只改缓解门槛不足，应尝试在保持空气源时避免不必要的额外ED减速，而不是通过提前松闸缩短后续充风窗口。

## 新候选机制

仅在第三列诊断分支启用held_air_speed_balance：零RL、单机车、已有AB源、当前仍请求AB且已产生物理空气力、列距大于实际动态参考183.333056m、本列比前列慢时才允许调整ED。速度参考取前列当前速度与当前运营安全速度上界的较小者；接近目标保持一个现有0.5m/s迟滞带，前列显著变慢或列距不足则立即交回原控制。

每步按原生当前坡度、Davis阻力及实际空气制动力计算：

B_ED = max(0, F_grade - F_resistance + F_air - M*a_target)

F_air取带方向的负制动力，B_ED为正大小，再通过原生ED曲线反算请求。目标加速度来自速度误差/60秒，限在±0.02m/s²；ED下降速率0.05/秒。它们是工程试验值，不是论文气动参数。只减小原控制器给出的ED，不增加牵引，不改AB档位、压力传播、222秒门禁、1000kN目标或ATP；保护层仍在下游。

该试验允许ED低于旧循环规则300kN经验下限，不声称仍满足该经验下限；没有把它改成生产默认或更改物理能力。新机制可能改变空气制动持续时间，后续需统计循环和持压时长，不能仅凭数值仿真宣称实车操纵或热负荷合格。

相关入口：src/evaluation/held_air_speed_balance.py、diagnose_held_air_balance.py、run_held_air_balance_validation.py。continue_fleet_numerics.py只新增按源码SHA恢复此诊断上下文的分支；没有该标识的既有候选路径保持原样。此前round80进程使用启动时的源代码，原entry_source.py已冻结，未被本轮修改替换。
