# 三列数值精度与效率瓶颈

## 当前结论
本轮未修改生产控制器、物理参数或默认求解器，没有运行强化学习。继续调规则层前，须区分真实控制超限与数值计算差异。实验Newton方法的120秒诊断内部峰值719.799001 kN，无超速、安全事件或负列距；并非全程验收。末列车尾仍在负里程扩展段，不代表三列都已走过实际线路。

## 步长核对
以下均使用相同控制指令，比较未经平滑的完整有符号接口力，气动和控制时钟不变。

| 相邻步长（ms） | 比较时长（s） | 最大力时程差异（kN） |
|---|---:|---:|
|0.625 / 0.3125|25|93.201624|
|0.3125 / 0.15625|7|34.531232|
|0.15625 / 0.078125|7|14.208671|
|0.078125 / 0.0390625|7|6.563915|

各次最敏感位置均在5.7秒、第67处车钩；最大差异所在列车随舍入与离散误差略变，不能把所有对照写成同一列。最后两档内部峰值719.592206与719.592834 kN，峰值接近并不意味着完整时程误差等于峰值之差。相邻更细步长的最大车速差为0.000513774 km/h。

第2列在0.078125 ms结果中的该敏感点，力对相对速度的局部导数约-1.39215亿 N/(m/s)，双车局部线性化松弛尺度约0.359 ms。这只是孤立双车的局部尺度，不能作为全列误差或稳定性界。

## 已确认的瓶颈
0.0390625 ms的7秒对照使用537600个机械子步，零拒绝。当前方法只在Newton等求解失败时二分步长，尚未按时间积分误差自动选步。力平衡残差小于0.01 N不等于时间误差满足要求。全程统一小步长的计算量不适合直接推广到训练；不能以忽略切换点、平滑曲线或任意放宽阈值解决。

## 已重读文献
实际重读了本地Zhou、Shi、Hecht论文原文提取文本的摘要、方法相关检索段，以及翟婉明1990的既有原文提取卡。Zhou文讨论速度依赖切换的步长敏感性及额外耗时，与当前现象方向一致；其算例步长不能直接作为本项目标准。翟文提取卡强调多步长数值试验；本轮未新下载或登录知网，不声称已重新目视核验全部PDF公式。

## 下一阶段最小方案
1. 保留本轮结果作为短区段参考，不继续机械式地全段减半。
2. 核对步长加倍误差估计：一步与两个半步比较位移、速度和有符号车钩力；明确各量绝对/相对容差及拒绝回滚规则。
3. 控制与气动事件时刻保持一致；拒绝机械试步不得重复推进气压、控制计时或历史状态。
4. 在5.7秒切换附近进行局部自适应加密；非敏感段允许较大步长。先验证误差与耗时，再考虑生产接入。
5. 若改用具有高频耗散的积分方法，必须对照冲击峰值与完整力时程，不能只比较曲线平滑程度。
6. 替换车钩过渡模型属于物理建模变更，须独立论证和标定，不混入纯求解器修复。
7. 精度与效率通过后才继续三列制动切换、速度、列距与1000 kN联合验收。
