# 底层控制瓶颈：原文复核与模型差异清单

复核日期：2026-10-14。范围：本地5篇论文重点章节、仓库赵紫宁学位论文与张二田实测论文，共7份原文。仅开展文献与当前代码核对，本轮未修改控制策略、未重新仿真，未联系队友。结论分为原文事实、模型差异、待验证建议；不把论文中的经验数值直接移植。

## 1. 最有价值的发现

1. **传播时间不等于制动力建立时间。** 王青元等2022正文73页/PDF4式(13)–(16)分别描述开始充气时刻、充气时长及结束时刻：t_m,i=t_d,i+t_Δ,i+T_1。双源列车传播分布分段，而非全列单向延迟。这个关系描述论文模型，不自动构成ETCS安全包络。
2. **当前循环衰减数据是特定三段工况的辨识结果。** 赵紫宁2022正文51页/PDF65表5-5给出Cβ=1.379/0.972/0.932。表5-3的三个制动段初速度62/45/46km/h、制动持续946/1358/918秒、缓解持续226/219/273秒，最大坡度-12‰。不能将其推成任意制动/缓解切换都固定衰减、第三次之后永远饱和的实车规律。
3. **222秒是实测最短充风时间，不是通用最短许可时间。** 张二田2021正文76页/PDF3§3.2指出该工况最短222秒，并讨论165秒及减压70kPa条件所需256秒；初减压大于60kPa有充风不足风险。应结合减压量、管压恢复核对规则门限。
4. **三种“保持/调整时间”含义不同。** 杨辉等2020正文176页/PDF8有缓解后保持电制动10秒；赵文涛等2020正文55页/PDF6的10秒从最大拉钩力出现后计时，讨论降低两台机车电制动力的时机；马志强等2023正文74页/PDF4把开始缓解后维持恒定电制动力50秒加入优化约束。它们不是同一控制规则，更不是退出紧急监督的固定延时。
5. **平均速度平顺不代表列内相对运动小。** 赵文涛等讨论缓解后前后车辆速度差导致先拉后压；马志强等同时优化控制力变化和速度跟踪，并用纵向动力学检查车钩分布。结合项目已归档结果，可推断仅限制普通ED请求变化无法解决安全层接管与列内不同步；这项推断仍需同工况实验验证。

## 3. 当前代码差异及队友核对清单

- train.py的常用/紧急升压采用18/10秒统一线性渐入；空气论文及学位论文考虑分车充气时长差异。请队友给出各档位、各车位的制动缸压力时间曲线或明确当前简化依据。
- fleet的监督建立时间来自全列长度/250m/s，且常用沿用同值；执行端的常用、紧急波速及升压不同。应核对双源、可控列尾配置和最不利建立过程，不能仅把两个时间机械相加。
- braking.py按制动段计数使用0.972/1.379、0.932/1.379，再永久饱和；论文表5-5同时有历史充风和段内温度函数。当前简化的可适用范围、恢复机制和重新制动计数需要模型负责人确认。特别核查安全层反复制动/缓解是否错误累计为“完成的循环”。
- 控制器固定充风222秒须重新审视减压量映射；来源实测并没有给出“任意减压量222秒必够”的结论。
- 先建立模型核对表：真实质量、机车功率/ED曲线、空气档位对应减压量、两源位置及通信延迟、列尾装置、各车位压力/力、各循环段恢复条件、断面力符号及车位编号。
- 论文公式编号、模型输出单位、车辆编号与项目零基索引要明确映射；图中力峰值不能只凭正负号叫拉/压。

## 4. 下一轮单变量实验建议（尚未执行）

A. 固定物理、固定控制，记录一次完整SERVICE/RELEASE/EMERGENCY的分车压力与力。先验证两源生效、压力连续、波前及升压完成时间，再校准监督曲线。拒绝条件：未核验的时间常数直接设为正式默认。

B. 保持其余策略不变，核查循环计数是否对应完整制动—缓解过程，以及充风恢复状态；比较原模型与经队友确认的计数/恢复模型。此为物理版本对照，不能冒称只调控制器，也不能拿改前训练模型与改后基线直接比较。

C. 在正常控制权限内测试“缓解阶段按实际ED力分配＋实际执行反馈”，禁止覆盖EBI紧急指令；分别关注平均速度jerk、列内相对速度、群组速度差、拉/压断面峰、超速、最小列距。两工况及至少两个完整循环均有收益后再扩到整线；不能只凭jerk下降接受。

优先级：先A完成监督—执行一致性核对，再B确认物理简化，之后C做控制优化。本清单支持与队友同步核对，不要求暂停全部工作。

## 6. 留痕与结论

原文提取、关键页图片和文件SHA256保存在“原文复核_20261014”；已目视核验2022空气模型公式页与2020多质点表2。学位论文与实测论文已补充原始PDF指定页提取和图片，参数由原始PDF交叉核对。

结论：论文支持将空气制动动态、循环历史、机车分配和控制阶段共同考虑；目前没有证据支持把10秒/50秒/222秒直接设成两万吨统一常数。现有数据足以先做模型—监督一致性诊断；精确的车型参数和全过程安全保证仍需模型数据及同工况验证。
