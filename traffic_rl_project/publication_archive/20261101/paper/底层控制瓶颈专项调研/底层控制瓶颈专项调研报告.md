   - 阶段②暂态：t_{d,1} < t ≤ t_{m,N} 时闸瓦压力逐渐增大

   - 公式(6)给出了分段制动力表达式，含历史操纵修正函数P_s(t)和实时闸瓦压力函数K_{z,i}(t)

4. **历史制动修正函数**（第73页，式8-12）

1. **缓解时主增从减策略**（第4-5页，文字描述）
   - 增大主控机车电制动力 → 抑制前部车辆增速
   - 减小从控机车电制动力 → 让后部车辆增速，形成压缩趋势

### 论文6：Safety Guardrails (CBF平滑混合)

| 项目 | 内容 |
|------|------|
| **完整题名** | Safety Guardrails in the Sky: Realizing Control Barrier Functions on the VISTA F-16 Jet |
| **年份/来源** | 2026，arXiv:2603.27912v1 |
| **本地路径** | `paper/SafetyGuardrails_CBF_SmoothBlending_2026.pdf` |
| **全文获取** | ✅ 全文已获取 |
| **领域** | 航空/通用控制，非列车领域 |

**核心方法**
- λ加权混合：u = (1-λ)·u_desired + λ·u_backup
- λ∈[0,1]，由距离安全边界的距离决定
- λ=0：标称控制完全通过；λ=1：备份控制完全接管
- 安全保证依赖CBF前向不变性证明

**迁移条件**
- 需要明确的安全集合定义和CBF构造（本项目难以严格构造）
- 假设两个控制器在同一控制空间（本项目安全层是修正量不是完整控制）
- 模型精度影响安全性保证的有效性
- **可迁移的是思想，不是理论保证**

- 方向B：电制动力矩"卸载—保持—增载"波动 → 车钩力波动的**物理机制与定量量级**——直接支撑实验2（电制动速率限制/平滑）

### 二、监督曲线与动力学模型的参数不一致

#### 已确认的不一致

1. **80km/h名义减速度 vs 模型实际能力**
   - 监督曲线：0.382 m/s²（第69页）
   - 模型静态查询：首段0.416/0.455 m/s²（紧急+全ED），第三段0.292/0.331 m/s²（第73页）
   - 矛盾：首段能力比曲线强，第三段比曲线弱
   - **问题：监督曲线用的是常值还是分段？循环衰减如何考虑？**

2. **制动建立时间**
   - 监督曲线：常用/紧急运行建立时间均为10.536 s（仅传播时间）
   - 执行模型：另有约18 s常用升压、10 s紧急升压（第73页）
   - **问题：传播时间和升压时间是叠加关系还是包含关系？需要从物理原理判断**
   - **新证据（贺相林2026，印刷页56-58）**：
     - 《牵规》的"空走时间"**本身已经包含了制动力由0上升到最大值的过程**；按《牵规》算出的空走时间**小于**"全部车辆制动缸压力上升到最大值的时间"
     - 即制动距离用的是"空走时间"这一**集总近似**，它已把传播+升压"打包"，**不是**"传播时间+升压时间"简单相加
     - 常用制动空走时间：T_k=(3.6+0.00176rn)(1−0.032i_j)；非定压全排制动在该式基础上**加Δt**，Δt取0~10s（车尾风压>460kPa取0，≈400kPa取10s）
     - **对本项目的意义**：10.536s若只对应"传播时间"，而执行模型另有18s/10s升压，则**不能**把两者直接相加当空走时间；正确做法是回到《牵规》空走时间定义（覆盖0→最大力的上升过程），按本项目减压量、辆数、坡度代入式1核算
   - **仍待队友确认**：执行模型中t_d（开始充气）与T_D（充气时长）的物理定义，才能判断10.536s对应的是哪一个

3. **实车量级校核基准（魏伟等2012，大秦线2万t）**
   - 常用制动170kPa、初速79.6km/h：制动距离1083m（试验），最大车钩力−1631 kN
   - 紧急制动、初速78.1km/h：制动距离672m（试验），最大车钩力−1930 kN
   - 制动缸出闸时间：1车1.63s、157车6.22s、210车2.59s；从控1响应2.35s
   - **用途**：本项目两万吨编组的制动距离/时间/车钩力可直接与这组实车数据做量级对比；**注意紧急制动实车车钩力已达1930 kN，远超1000 kN**——说明"紧急制动下1000kN约束"本身极难满足，不能据此单独判定控制器失败

4. **论文中的佐证**
   - 王青元2022（第72页）：牵规的"空走+有效"两段式模型在短距离制动准确，长距离制动误差大
   - 王青元2022（第73页）：上一制动段缓解时间偏小会导致本次制动性能变弱
   - **推论：循环制动中，监督曲线如果按最大能力算，在循环末段会偏乐观**

#### 待确认的问题

1. 监督曲线的0.382 m/s²是按什么编组、什么制动方式、什么速度范围标定的？
2. 常用制动和紧急制动的等效减速度是否不同？
3. 建立时间10.536s是如何计算的？是否包含制动缸升压？
4. 循环制动的衰减是否已考虑在监督曲线中？

### 三、前部、中部机车协调控制的建议

#### 有论文证据支持的方向

1. **缓解时"主增从减"电制动分配**（赵文涛&魏伟2020，第4-6页）
   - 物理依据：缓解波从前向后传播，前部先缓解先加速，后部还在制动，列车被拉长
   - 策略：增大头部机车电制动（拉住前部），减小中部机车电制动（让后部跟上）
   - 定量效果：10.2‰坡道下，拉钩力降约13%，压钩力降约52%
   - **注意：本项目坡度更缓（4‰），最优分配比例需要重新标定**

2. **缓解后电制动保持**（马志强&王青元2023第74页：50s操纵准则；杨辉2020第176页：10s经验值）
   - 物理依据：缓解不同步产生纵向振荡，电制动保持可以起阻尼作用
   - **50s和10s都是特定场景的经验值，不能直接照搬**
   - 需要在本项目仿真中标定合适的保持时间和保持水平

3. **拉钩力峰值后及时降低电制动**（赵文涛&魏伟2020，第6页）
   - 物理依据：拉钩力峰值后车钩会回弹为压钩，此时电制动力太大会加剧压钩
   - 论文结论：延迟10s以内压钩力可控，12s以上可能超限
   - **10s是特定工况的值，仅作数量级参考**

4. **机车（制动源）滞后时间必须严格控制**（魏伟&于忠建2011，第4-5页）
   - 物理依据：多机车/多制动源不同步→制动波不同步→纵向力剧增
   - 定量（3万t、1+1+1、平道）：
     - 常用制动：从控二滞后5s，最大车钩力**+80.2%**
     - 紧急制动：从控一滞后5s，最大车钩力**+335.9%**
     - 都滞后5s → 3030.5 kN（同步时仅约695 kN）
     - 结论：紧急制动下**从控机车滞后不超过4.1s**才能把最大车钩力控制在2000kN内
   - **对本项目的意义**：安全监督接管时"两台机车被强制全电制动+紧急空气制动"，如果两机的电制动建立时刻、空气紧急波到达时刻不一致（哪怕差几秒），就会把车钩力放大数倍——这为"最大冲击出现在紧急接管时刻"提供了机制解释
   - **注意**：论文是3万t/3机车/平道，数值不能直接移植到本项目2万t/2机车/长大下坡，需按本项目编组重新算

5. **电制动力矩的"波动/跳变"本身就是车钩力波动的直接来源**（曾周等2024，第109、111-113页）
   - 物理机制：车轮滑行触发防滑控制 → 力矩"卸载—保持—增载"反复 → 车钩力随之波动；论文明确"从控机车再生制动力异常波动导致列车纵向冲动大"是实车故障原因
   - 定量（"1+1"两万吨、70km/h纯电制动）：干燥接触最大压钩力527.89 kN；**中部机车滑行时其中部机车前部车辆压钩力增大**、后部降低；头部机车滑行时整车压钩力降低
   - 结论：**低黏着时应降低制动力矩**以减轻纵向冲动
   - **对本项目的意义**：诊断报告中"62次ED上跳/下跳"若由控制器/黏着共同引起，则单纯用速率限制压制跳变可能只治标——还需区分"黏着物理波动"与"控制指令波动"

6. **中部机车电制动力存在"垂向安全上限"，不能盲目增大**（凌亮等2021，第310页）
   - 空制缓解工况下，钩头摩擦因数0.08、垂向转角限值8°时，**电制力施加比例仅40% + 初始高差40mm即可诱发跳钩**
   - 机理：钩缓由"压缩→拉伸"过渡时，电制力使连挂车钩垂向跳动，大高差+差摩擦→自锁力不足→垂向位移>300mm→车钩分离
   - 防控：严格限制初始高差、**适当减小机车电制动力/牵引力**
   - **对本项目的意义**："主增从减"里的"中部减电制动"不仅是降低纵向冲击的手段，也**符合抑制中部机车跳钩的垂向安全要求**；反之，若按对称逻辑给中部机车加电制动，可能带来垂向风险

#### 不建议仅凭直觉就做的

1. **对称编组≠对称分配最优**
   - 诊断报告已验证：ed_grade_feedforward（按坡力分配）反而恶化
   - 分段分配（自研候选）也使车钩力从2026→2262 kN，超限从7344→10124（第45页）
   - 论文支持：赵文涛&魏伟明确显示**非对称分配（主增从减）**效果更好
   - 论文支持（魏伟&于忠建2011）：**常用制动时"从控二机车滞后"影响更大，紧急制动时"从控一机车滞后"影响更大**——同一列车在常用/紧急两种工况下，对"哪个源更重要"的敏感度不同，说明最优分配/时序是**工况相关**的，不能靠编组对称性直接推断

2. **提前电制动不一定改善车钩**
   - 诊断报告：ed_grade_feedforward使峰从917→1410 kN（第21页）
   - 原因：提前电制动导致列车被"压紧"，后续空气制动介入时冲击更大
   - **提前减速能减少超速，但可能恶化车钩——二者需要权衡**

### 五、下一轮最值得做的三个单变量对照实验

#### 实验1：缓解时"主增从减"电制动分配（安全层退出场景）

**改什么**：
- 在安全层开始缓解（SBI退出）的瞬间，将头部机车电制动增大X%，中部机车电制动减小Y%
- 保持总电制动力不变（或略微增大），只改变分配
- X和Y从较小值开始（如头部+20%，中部−20%），逐步增大

**保持什么不变**：
- 空气制动缓解逻辑不变
- 安全层介入逻辑不变
- 安全曲线参数不变
- 物理模型不变
- 其他控制参数不变

**观察哪些指标**：
- 最大拉钩力（主要指标，预期降低）
- 最大压钩力（需注意是否反弹增大）
- 拉钩力峰值出现的时间和位置
- 速度误差RMSE
- jerk RMS
- 安全层介入次数和持续时间

**出现什么结果应拒绝采用**：
- 最大压钩力反而增大并超过阈值
- 速度跟踪性能严重恶化（超速增加>50%）
- 平均速度下降过多导致列距问题
- 总车钩力超限次数不降反升

**为什么做这个实验**：
- 赵文涛&魏伟2020有直接的定量支持，且物理机制清晰
- 只改电制动分配，不改空气制动和安全逻辑，风险小
- 单变量，结果易于解释
- **安全约束佐证**：凌亮等2021显示空制缓解工况下中部机车电制力40%即可诱发跳钩，因此"中部减电制动"符合垂向安全要求，方向与文献一致

#### 实验2：电制动指令速率限制（安全加强制动绕过）

**改什么**：
- 对普通控制器输出的电制动指令施加变化率限制
- 限制值：从较松的值开始（如每0.1s步变化不超过0.1深度单位），逐步收紧
- 安全层的"加强制动"指令（ED增加方向）绕过速率限制，立即执行
- 安全层退出时的ED降低仍受速率限制（平滑退出）

**保持什么不变**：
- 空气制动逻辑不变
- 安全层触发阈值不变
- 控制器其他参数不变
- 物理模型不变

**观察哪些指标**：
- 电制动指令跳变次数（≥0.5/0.1s的次数）
- 车钩力峰值和超限次数
- jerk RMS
- 速度误差和超速次数
- 安全层响应时间（从触发到ED达所需值的时间）
- 安全层介入次数

**出现什么结果应拒绝采用**：
- 安全响应变慢导致制动距离不足、超速显著增加（>30%）
- 车钩力不降反升（可能性较低，但需验证）
- 安全层介入次数显著增加（说明速率限制导致正常控制跟不上速度变化）

**为什么做这个实验**：
- 直接对应"23次较大的电制动指令跳变"的问题
- 速率限制是工程上最常用的平滑手段，实现简单
- 安全加强绕过限制保留了安全性
- Herbst 2015有通用控制理论支持
- **新证据（曾周等2024）**：电制动力矩"卸载—保持—增载"波动会直接引起车钩力波动，且实车存在"从控机车再生制动力异常波动→纵向冲动大"的故障——本实验同时需**区分"控制指令跳变"与"黏着物理波动"**：若跳变主要来自黏着/防滑，则速率限制效果有限，需另设黏着工况复核

#### 实验3：安全监督曲线按分段能力重新标定（仅对标，不改默认）

**改什么**：
- 用当前仿真模型的实际制动能力（分常用/紧急，分循环段）重新计算监督曲线
- 或者在现有曲线上增加安全裕度（如建立时间按传播+升压叠加计算）
- 此实验仅做对标和评估，不修改默认参数

**保持什么不变**：
- 控制逻辑完全不变
- 物理模型不变
- 只是重新计算/调整监督曲线参数

**观察哪些指标**：
- 新曲线下，安全层介入时机是否更合理
- 介入时的减速度裕度（实际可用减速度 vs 曲线标称减速度）
- 车钩力峰值和超限次数
- 超速次数和最大超速量
- 列距变化

**出现什么结果应拒绝采用**：
- 新曲线偏保守导致频繁误介入，车钩力反而增大
- 新曲线偏激进导致安全裕度不足
- 不能只因为车钩力变好就采用——必须同时保证安全裕度

**为什么做这个实验**：
- 诊断报告明确指出：监督曲线（0.382 m/s²）与模型实际能力（第三段0.292 m/s²）不一致
- 如果曲线偏强（标称比实际大），则安全层介入后可能发现制动力不够，导致介入更深、冲击更大
- 这是一个根本性的参数不匹配问题，可能是车钩力大的重要原因
- **建立时间的核算方法（贺相林2026，印刷页56-58）**：不要简单把"传播时间+升压时间"相加；应按《牵规》空走时间定义 T_k=(3.6+0.00176rn)(1−0.032i_j)（非定压再+Δt）核算，因为空走时间本身已覆盖0→最大力的上升过程

## 第四部分：通俗解释——为什么"速度更平顺，但车钩力更大"

### 一句话回答

**因为正确的制动执行让空气制动力真正发挥出来了，制动力更"猛"了，但列车那么长，头尾不同步，猛的制动力反而把列车"折"得更厉害。**

### 打个比方

想象一列200多节车厢、2.6公里长的火车是一根长长的弹簧。你拉住弹簧的一头往后拽（制动），弹簧会被拉长——这就是拉钩力。

**之前有bug的时候**：
- 你说"紧急制动！"，但系统没真正执行紧急，还停留在常用制动的力度
- 相当于你拽得比较轻、比较慢
- 弹簧慢慢被拉长，最大拉力不算特别大（但速度可能控制不好，因为制动力不够）

**修复bug之后**：
- 你说"紧急制动！"，系统真的执行紧急制动了
- 相当于你猛地一拽
- 弹簧"唰"地一下被拉得很长，拉力峰值很大（但速度控制得更准了，因为制动力够了）

### 具体到本项目的证据

1. **空气源升档修复后**（第39页）：B工况峰值从1410→2026 kN，增长44%。紧急制动真的生效了，车钩力变大是正常的物理现象。

2. **重叠缓解修复后**（第89页）：峰值从3892→4839 kN，又增长了24%。缓解执行正确后，缓解不同步导致的冲击也真实地显现出来了。

3. **为什么速度反而更平顺？**
   - 制动力真正发挥了，速度能及时被控制住
   - 之前制动力不够，速度飘来飘去，看起来"不平顺"
   - 但速度平顺 ≠ 车钩力小——这是两个不同的物理量

4. **为什么ed_prelimit（提前电制动）在60s看起来好，120s就崩了？**
   - 60s窗口内，提前电制动让速度不超限，而且还没触发紧急制动，所以看起来车钩力小
   - 但时间拉长到120s，只靠电制动刹不住，速度越来越高（最高88km/h），最后还是得空气制动介入
   - 速度更高时制动，冲击更大，所以车钩力反而更糟

### 哪些原因已有证据支持？

✅ **执行正确性修复暴露了真实动力学**——这是最确定的。修复了5个执行bug，每次修复后车钩力都变大或有变化，说明之前的低峰值是bug掩盖的结果。

✅ **紧急制动全量ED + 全空气制动同时作用，冲击巨大**——诊断报告第29页明确记录：峰值时刻EBI、两机ED1/1、空气紧急，普通控制被覆盖。最大峰值都出现在EBI接管时。

✅ **缓解不同步导致纵向冲击**——赵文涛&魏伟2020、王青元2022等多篇论文从物理机制和实验上验证了这一点。

✅ **制动源不同步/制动缸充气特性改变，会让车钩力成倍变化**——魏伟等2012（大秦线2万t实车）显示：去掉列尾装置（相当于少一个尾部制动源）后，列车中部压钩力增加875 kN（增幅54%），拉伸车钩力从约200 kN升到约850 kN。这直接说明"多一个/少一个制动源、源与源之间差几秒"就足以让车钩力翻倍，与本项目"单源→双源""安全层强制两机全制动"的观察方向一致。

✅ **机车滞后几秒，紧急制动车钩力可翻数倍**——魏伟&于忠建2011显示：紧急制动下从控机车滞后5s，最大车钩力增加335.9%；都滞后5s时达3030 kN（同步时仅约695 kN）。这解释了为什么"最大车钩冲击出现在紧急安全监督接管时"——接管瞬间两机的电制动与空气紧急波若不同步，冲击会被放大。

✅ **电制动力矩一波动，车钩力就跟着波动**——曾周等2024（"1+1"两万吨、70km/h纯电制动）显示：车轮滑行触发防滑控制，力矩反复"卸载—保持—增载"，车钩力随之波动；中部机车滑行时中部机车前部车辆压钩力增大，头部机车滑行时整车压钩力反而降低。实车故障记录也证实"从控机车再生制动力异常波动导致纵向冲动大"。这说明诊断报告里的"电制动指令跳变"很可能不只是控制器问题，还叠加了轮轨黏着的物理波动——单靠速率限制压制跳变，可能只治标。

✅ **中部机车电制动力开太大有"跳钩"风险**——凌亮等2021显示：空制缓解工况下，钩头摩擦因数0.08、垂向转角限值8°时，电制力只要施加到40%、初始高差40mm就可能跳钩（车钩分离），机理是钩缓由"压缩→拉伸"过渡时电制力使车钩垂向跳动。所以"缓解时把中部机车电制动力减下来"不只是为了减小纵向冲击，也符合中部机车的垂向安全要求。

### 哪些仍待验证？

❓ **监督曲线与实际能力不匹配，是EBI频繁介入的主要原因吗？**
- 目前只知道0.382 vs 0.292的差值，但不知道这差值在实际运行中导致多少次额外介入
- 需要实验3来确认

❓ **电制动指令跳变对车钩力的贡献有多大？**
- 已知有62次上跳62次下跳与SBI相邻
- 但"相邻"≠"因果"，需要实验2（速率限制）来验证减少跳变是否降低车钩力

❓ **主增从减的电制动分配在本项目工况下能有多大改善？**
- 论文在10.2‰坡道下降了12.8%的拉钩力
- 本项目坡度更缓，改善幅度可能不同
- 需要实验1来确认

### 核心矛盾

> **要安全（及时制动防超速），就要承担制动冲击带来的大车钩力；要小车钩力，就要让制动更柔和，但可能超速。**

这不是"哪边对哪边错"的问题，而是两个目标之间的**权衡**。修复的方向不是简单地"让车钩力变小"，而是：
1. 确保制动力够用（安全第一）
2. 在安全的前提下，让制动介入和退出尽可能平缓
3. 合理分配两台机车的制动力，减少纵向冲击
4. 校核监督曲线，避免不必要的紧急介入
