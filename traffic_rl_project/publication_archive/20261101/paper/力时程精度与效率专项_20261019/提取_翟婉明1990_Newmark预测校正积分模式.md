## 2. 积分方法与求解器（PDF2/印52、PDF3/印53）

原文明确给出两类格式：

**Newmark 隐式（假定）式(2)，PDF2/印52：**
```
{X}_{n+1} = {X}_n + {V}_n Δt + (1/2 − β){A}_n Δt² + β{A}_{n+1} Δt²
{V}_{n+1} = {V}_n + (1 − γ){A}_n Δt + γ{A}_{n+1} Δt
```

**显式积分格式式(3)，PDF2/印52（引入两个积分参数 φ、ψ）：**
```
{X}_{n+1} = {X}_n + {V}_n Δt + (1/2 + ψ){A}_n Δt² − ψ{A}_{n−1} Δt²
{V}_{n+1} = {V}_n + (1 + φ){A}_n Δt − φ{A}_{n−1} Δt
```

**预测-校正基本模式（PDF3/印53），共四步：**
```
(I)  预测：{X}_{p,n+1}、{V}_{p,n+1}                    — 式(4)，用显式格式(3)
(II) 计算：{A}_{p,n+1} = [M]⁻¹({P}_{n+1} − [K]_{n+1}{X}_{p,n+1} − [C]_{n+1}{V}_{p,n+1})   — 式(5)
(III)校正：{X}_{c,n+1}、{V}_{c,n+1}                    — 式(6)，用隐式格式(2)（以 A_{p,n+1} 代入）
(IV) 计算：{A}_{c,n+1} = [M]⁻¹({P}_{n+1} − [K]_{n+1}{X}_{c,n+1} − [C]_{n+1}{V}_{c,n+1})   — 式(7)
```

**关键：非线性力/刚度阵的评价时刻与方式（原文明确）**
- 式(5)、(7) 中刚度阵与阻尼阵均取 **n+1 时刻的 [K]_{n+1}、[C]_{n+1}**，原文注明"上述式中 [C]_{n+1}、[K]_{n+1} 表示 (n+1)Δt 瞬时的阻尼、刚度矩阵，**仅对线性问题才为定数**"（PDF3/印53）。
- **该模式不做迭代收敛**：预测一次、校正一次即推进，不存在"迭代到满足容差"的环节。因此原文**没有**迭代容差、迭代上限、不收敛后的动作。

**求解器特征（原文明确）**：全过程只涉及**质量阵 [M] 的求逆**；"倘若 [M] 为对角阵或已对角化，则积分中始终可避免求解高阶线性代数方程组"（PDF4/印54，式(14)前后）。摘要（PDF1/印51）亦称"对具有对角质量阵的非线性动力学方程积分，无需解高阶线性代数方程组"。

**修正与误差补偿（PDF3/印53）**：给出截断误差展开式(8)(9)，及预测式修正(10)、校正式修正(11)，误差补偿系数 ε 见表1（PDF3/印53）：
- φ=ψ=1/2 时：ε_ep = −5/6，ε_ev = 1/6
- φ≠ψ 时：ε_ep = (1/2−φ)/(φ−ψ)，ε_ev 相应由 (1/2−γ)/(φ−ψ) 给出（表1 该格排版需以原页为准）
- ψ=β=1/6 时：ε_mp = −3/4，ε_mc = 1/4
- ψ≠β 时：ε_mp = (1/6−ψ)/(ψ−β)，ε_mc = (1/6−β)/(ψ−β)

含修正后共六个环节：(I)预测(4) → (II)改进(10) → (III)计算 A_{p,n+1}(12) → (IV)校正(6) → (V)改进(11) → (VI)计算 A_{c,n+1}(7)。

**初始条件（PDF4/印54）**：式(13) {X}(0)={X}_0、{Ẋ}(0)={V}(0)={V}_0；式(14) {A}_0 = [M]⁻¹({P}_0 − [K]_0{X}_0 − [C]_0{V}_0)。原文注明"起步时我们只需令 γ=φ=β=ψ=0"。

## 3. 稳定条件与精度条件（PDF2/印52、PDF4/印54）

原文明确（线性分析结论，PDF2/印52）：
1. 取 **φ=ψ=1/2 时方法具有二阶精度**；
2. **条件稳定**，临界步长与中心差分法相同，例如 φ=ψ=1/2 时 **Δt_cr = T/π**（T 为系统自振周期）；
3. 人工阻尼：φ=1/2 时无阻尼；φ>1/2 时引起人工阻尼；φ<1/2 时产生负阻尼；
4. 计算周期呈缩短趋势，相对周期误差较小，φ=ψ=1/2 时约为隐式法（β=1/4）的一半（图1，PDF2/印52）。

**非线性情形（PDF4/印54）原文明确**：
- "对于非线性系统的分析显得十分复杂，没有统一结论，一般是对非线性系统的增量方程仍运用线性稳定条件进行积分计算。但是，研究指出，对于线性系统来说是稳定的积分，**对于非线性系统而言却不一定稳定**。一种较为流行的观点认为，隐式时间积分对非线性问题**往往不再保持其原有的无条件稳定性**。因此，非线性分析中时间积分步长必须谨慎选取。"
- 作者主张用**数值试验方法**确定稳定范围与有效计算步长区段。

## 4. 步长选择方法（PDF4/印54、PDF6/印56）

原文明确的方法（这是本文最可操作的一条）：
> "判断一个实际问题的数值分析结果真实与否，不能简单地取某个步长（不论大小）计算一次定论，而应变动时间步长计算若干次，然后观察结果的变化趋势，最终取数值结果彼此十分接近的步长区段作为有效计算步长区段进行计算。从工程应用的角度来看，**只要在三个相距一定间隔的步长下所获得的计算结果具有相当好的接近度，相对偏差为工程应用所允许，即可取中间那个步长下的计算结果作为实际问题的合理近似解**。"

具体数值（原文明确）：
- 算例1（§四，PDF4/印54—PDF5/印55）：步长取 **0.005、0.05、0.1** 秒三种情况对比（表2）。
- 工程算例（§五，PDF6/印56）：积分步长分别取 **Δt₁=0.005、Δt₂=0.010、Δt₃=0.015 秒**，三种结果十分接近，**最大车钩作用力偏差仅为 3%**，故取 **Δt₂=0.010 秒**为计算步长。

## 6. 计算效率（PDF6/印56，原文明确）

- 本文方法各步积分**无需求解高阶线性代数方程组**，可在普通微机上实现；**计算列车前进一秒仅耗费 IBM/PC-AT 微型机 CPU 90 秒，整个计算时间约 20 分钟**。
- 对比：Gogineni 和 Garg [13] 用**四阶 Runge-Kutta 法**对 60 辆车模拟，**最大积分步长仅能取 0.001 秒**（本文方法步长为**其 100 倍**），在 IBM-370/158 中型机上前进一秒"竟需 100 秒 CPU 之多"。

## 8. 与本项目的对应关系（区分原文明确 / 依据原文的推断 / 本项目待验证建议）

**原文明确可直接引用的**：
- 步长选择应"变动步长计算若干次、取结果接近的步长区段、取中间步长"；判据是三个相距一定间隔步长下结果的相对偏差在工程允许范围内（PDF4/印54）。
- 误差应按**逐时刻**相对偏差评价，而非只比较峰值（表2 的组织方式，PDF5/印55）。
- 线性无条件稳定结论**不能**外推到非线性（PDF4/印54 原文即如此表述）。
- 该类模式的计算效率来自"只需求质量阵逆、不解高阶线性代数方程组"（PDF1/印51、PDF4/印54）。

**依据原文的推断（需在报告中标注为推断）**：
- 本文的"预测-校正"是**显式预测 + 单次隐式校正**，与本项目"松弛固定点迭代到残差 1e-5"是**不同机制**；本文的稳定/精度结论**不能**直接用于证明本项目迭代收敛性。
- 表2 的 δmax 是在**已知精确解**的标量算例上定义的；本项目无解析精确解，只能以"细步参考解"代替精确解，这属于方法迁移而非原文结论。

**本项目待验证建议**：
- 建立"三档步长（相距一定间隔）结果接近度"检查，作为本项目细步参考网格的选取依据；不要只取一个步长单次定论。
- 用逐时刻力偏差（如全程最大相对偏差 + 时程范数）替代只看峰值，作为力时程可信度指标。
- 不得把本文 Δt=0.010 秒或"步长为 RK4 的 100 倍"直接规定为本项目步长。
