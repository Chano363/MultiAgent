## 4. 原文给出的关系式（可直接用于敏感性分析）
p.119，式(5)：

```
T = A + B·Δp + C·Δp² + D·R
```

式中 T 为充风时间(s)，Δp 为列车管减压量(kPa)，R 为从控机车滞后时间(s)，取值 0–3 s。

表 1（p.119）拟合系数：

| 编组方式 | A | B | C | D |
|---|---|---|---|---|
| 1+0 | −99.794 | 5.740 | −0.015 | 0 |
| 3+0 | −62.062 | 3.982 | −0.009 | 1 |
| 2+1+0 | −54.169 | 2.931 | −0.008 | 1 |
| 1+1+1 | −28.478 | 1.249 | −0.003 | 1 |

**计算（非原文值）**：
- 1+0、Δp=50：T = −99.794 + 5.740×50 − 0.015×2500 = **149.7 s**
- 1+0、Δp=110：T = −99.794 + 631.4 − 181.5 = **350.1 s**，与原文 387 s 偏差 **−9.6%**
- 2+1+0、Δp=50：T = **73.4 s**（原文 72 s，偏差 +1.9%）
- 3+0、Δp=50：T = **115.5 s**（原文 114 s，偏差 +1.3%）

→ 该拟合式对 2+1+0、3+0、1+1+1 吻合较好，对 1+0 在 110 kPa 偏低约 10%，故 1+0 的 50 kPa 拟合值 149.7 s 只能作**计算参考**，不能当原文值。

## 5. 与当前模型的关系
**可用于当前模型**：
- "充风时间 = 从司机缓解指令到**尾车副风缸 ≥580 kPa**"这一计时语义，与本项目应采用的判据一致。
- 单机车（1+0）与多机车（2+1+0/1+1+1）充风时间存在 2.4 倍量级差异，说明**不能用两万吨的时间按辆数折算**；本项目 1+0 必须走单机车一档。
- 拟合式(5)可用于回答"若把再充风间隔从 222 s 改动，对应哪个减压量/哪个编组"，但必须先声明是拟合值。

**仅方法参照**：
- 编组方式—充风能力的对比方法（同一仿真模型换编组）。

**不可迁移**：
- 387 s / 162 s / 114 s / 72 s / 28 s 均为 **116 辆 C80**、且 2+1+0、3+0、1+1+1 含**从控机车主动供风**，与本项目"1 机车 + 108 辆、无中部/尾部补风机车"不同。
- 不能把 2+1+0 的 162 s（110 kPa）、72 s（50 kPa）当作"加个列尾就能达到"——本文缩短来自**从控机车供风**，不是列尾监测装置。

## 6. 适用边界
- 适用：神华铁路万吨级、HXD1、C80、120 阀系、尾车副风缸 580 kPa 判据、司机缓解指令计时。
- 不适用：108 辆；未给出 1+0 在 50 kPa 的实测/仿真值；未给出制动缸排空或列尾收到缓解作为计时起点。

## 7. 缺失
- 1+0 编组 50 kPa 的**直接**充风时间（原文只给 110 kPa 的 387 s 与拟合式）。
- 定压未在正文明确写出（由 170 kPa 常用全制动档可推定 600 kPa，属**推断**，非原文值）。
- 108 辆工况完全未涉及。
