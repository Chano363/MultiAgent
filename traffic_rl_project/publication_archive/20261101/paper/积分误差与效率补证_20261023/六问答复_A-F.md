## B. 如何同时控制位移、速度、车钩力的时间积分误差？Newton 残差与截断误差的区别

### B.1 两类误差的本质区别

| | Newton 迭代残差 | 时间截断误差 |
|---|---|---|
| 定义 | 把**已离散的**方程解到多准：`R = M·a + F_int(x,v) − F_ext` | **离散本身**与真解的差距：`x_h(t) − x(t)` |
| 本项目现状 | 每步 **< 0.01 N** | **未知**，只能用步长加密估计 |
| 随步长 h→0 | 与 h 无关（只与迭代次数/容差有关） | **∝ h^p** |
| 能否互相替代 | **不能** | **不能** |
| 文献依据 | 郭炎冰式(12) 属此类（位移增量差），页 148 | 翟婉明表 2 的 δmax 属此类，PDF5/印55 |

**一句话**：残差 0.01 N 只证明"这一步的代数方程解开了"，不证明"这一步的时间离散是对的"。用户当前的判断（残差低于 0.01 N ≠ 时间积分精度合格）**与文献的区分方式一致**。

### B.2 为什么必须分别核验三个量

车钩力不是位移/速度的光滑函数，而是**经加载/卸载包络 + 切换判据的强非线性泛函**：

```
F = F( x, v ; f_l(x), f_u(x), v_ε )
```

- 在 |v| < v_ε 的过渡带内，F 对 v 的敏感度为 `∂F/∂v = ½(f_l−f_u)·sign(v·x)/v_ε`。
- 本项目 `v_ε = 0.002 m/s`。若包络差 (f_l−f_u) 为数百 kN，则过渡带内**每 1 mm/s 的速度误差可造成数十至上百 kN 的力误差**（量级估算，具体值取决于该处包络差，须由本项目数据代入）。
- 因此 **e_x 很小，e_F 仍可能很大**；反之亦然。**不能用位移误差代替车钩力误差。**

这与本项目实测一致：最新一档对照中，内部峰值差仅 **0.206 kN（0.029%）**，而完整有符号时程最大差 **6.564 kN（0.912%）**——**时程差是峰值差的约 32 倍**。

### B.3 建议的三量误差定义（本项目判断，无文献直接给此定义）

对同一物理时刻的细步参考解 `ref` 与待评解 `h`：

| 量 | 定义 | 归一化基准（建议） |
|---|---|---|
| 位移 | `e_x = max_t ‖x_h(t) − x_ref(t)‖∞` | 列车总长 或 最大缓冲器行程 |
| 速度 | `e_v = max_t ‖v_h(t) − v_ref(t)‖∞` | 名义运行速度 |
| 车钩力 | `e_F = max_t max_k |F_h,k(t) − F_ref,k(t)|` | **车钩力目标 1000 kN** |

并同时报告：
- 相对 L2 范数 `‖F_h − F_ref‖₂ / ‖F_ref‖₂`
- 峰值差 `ΔF_peak` 与**峰值时刻偏移** `Δt_peak`
- 冲量差 `∫(F_h − F_ref)dt`

**必须在共同时间网格上比较**（见 C.3、方案第 2 步），否则"最大差异"会被采样相位差污染。

### B.4 文献支持与缺口

- **【原文明确】** 翟婉明表 2 用**逐时刻**相对偏差 δmax（PDF5/印55），这是文献中唯一"逐时程点"而非"只看峰值"的误差定义。但它是**标量算例、只有位移、且有解析精确解**。
- **【原文明确】** 郭炎冰只有**平均相对误差**（2.46%/2.50%/4.73%，页 149），同样是标量算例。
- **【未取得】** 没有任何已取得原文给出"万吨列车、多自由度、车钩力时程"的误差范数定义。

## C. 加载/卸载切换处是否需要事件定位或局部加密？外部阶跃、气动传播、控制采样如何对齐

### C.1 文献怎么处理这个间断

**【原文明确】** Zhou 2022 摘要：加载/卸载包络间的间断"becomes a mathematical integration issue"，"might cause integration divergence and wrong results if ignored"。

**但它的解法不是事件定位，而是改力定律**——三种过渡策略（式 1–2 的 v_ε、式 3–5 的 k、式 6 的 α）。

**这意味着**：
- 文献主流路径 = **消除间断**（改物理模型），不是**定位间断**（改数值算法）。
- 中间斜率法式(4) `F = F_{t−Δt} + k(x_t − x_{t−Δt})` 与平滑逼近式(6) 都依赖**上一时间步的 F**，本质是**用历史状态跨过间断**，也不做事件定位。
- 速度法式(2) 用 `sign(v_t·x_t)` 做切换，在 |v|→0 附近仍然连续（线性插值），但在 |v| = v_ε 处**导数不连续**（tanh 版本则处处光滑但陡峭）。

### C.2 本项目若坚持不改力定律，怎么办

**【本项目判断，无原文支持】** 只能在 |v| < v_ε 邻域做**局部加密**（子步细分）。理由：

- 间断不可消除时，误差主要来自"跨越间断的那一步"。
- 局部加密把跨越步缩小，误差随之下降。

**但必须如实说明**：已取得的四篇原文**都没有**给出"事件定位/局部加密用于滞回车钩"的收敛性证明或误差估计。这是一个**方法学空缺**，不能写成"文献支持局部加密"。

### C.3 三个时钟的对齐（这是本项目当前的一个实质问题）

**【原文明确】** Zhou 2022 第 3.1 节给出预处理离散尺度：线路 1 m、缓冲器 F-D 0.01 mm、机车速度 1 mm/s、**驱动控制序列 1 ms**。其速度法步长 0.1/0.2 ms 恰好**整除 1 ms**（10 步 / 5 步），控制阶跃必然落在步边界上。

**【本项目判断——重要】** 本项目当前步长阶梯与 1 ms 控制网格**不整除**：

| 步长 (ms) | 1 ms 内的步数 | 是否整除 |
|---|---|---|
| 0.625 | 1.6 | **否** |
| 0.3125 | 3.2 | **否** |
| 0.15625 | 6.4 | **否** |
| 0.078125 | 12.8 | **否** |
| 0.0390625 | 25.6 | **否** |

后果：**控制指令的阶跃时刻落在积分步内部**，每次减半步长时，"控制阶跃在步内的相对位置"也随之改变。于是相邻档的力时程差异**混入了"事件对齐方式不同"这一非截断误差因素**，不能纯粹读成离散误差收敛。

这可以解释为什么观测到的收敛比（见下）不规整。

**建议**：改用与控制周期**可通约**的阶梯——0.5 / 0.25 / 0.125 / 0.0625 / 0.03125 ms（每个都是 1 ms 的整数分之一），并在每个控制/气动事件时刻**强制断步**。

### C.4 收敛阶的实测估计（本项目数据）

只取口径相同的三档（均为 7 s 窗口、同一敏感点）：

| 相邻档 | 最大差异 (kN) | 相邻比 | 观测阶 p = log₂(比) |
|---|---|---|---|
| 0.3125 → 0.15625 ms | 34.5 | — | — |
| 0.15625 → 0.078125 ms | 14.2 | 2.43 | **1.28** |
| 0.078125 → 0.0390625 ms | 6.5639 | 2.16 | **1.11** |

- 观测阶 **p ≈ 1.1–1.3，趋于 1**，**不是** Zhai 法在光滑线性问题上的二阶。
- **【据原文推断】** 这与"力定律在切换点附近不光滑（|v|=v_ε 处导数间断）"一致：间断使高阶方法的阶数优势退化。翟婉明也明确"非线性不保证线性稳定结论"（PDF4/印54）。
- **实践含义**：不能用 Richardson 外推一次跳到高精度；**要把误差减半，就得把步长减半**。当前从 0.625 ms 减到 0.0390625 ms 是 **16 倍**加密，机械子步数同比 16 倍增长。
- 注意：93.2 kN 那一档是 **25 s 窗口**，与前两档**口径不同**，不参与上表，也不得与它们合并成"全程误差"。

### C.5 外部制动力阶跃与气动传播

- **【原文明确】** Zhou 只给控制序列 1 ms 网格，**未给气动传播的时间离散**（其模型是否含详细气动未在已读章节中明确）。翟婉明、郭炎冰的算例均为力学非线性，**未涉及气动状态**。
- **【未取得】** 没有任何已取得原文处理"气动波传播 + 机械子步 + 控制采样"三时钟对齐问题。
- **【本项目判断】** 气动波到达时刻是**物理事件**，其不确定度来自气动模型自身的时空离散，**不属于机械积分误差**。因此验收时必须**分开**：
  1. 机械积分误差（固定气动输入，只改机械步长）；
  2. 气动离散误差（固定机械步长，只改气动网格）。
  两者混在一起测，无法归因。

| Zhou 2022 | 各算例**最大车钩力**（Table 1 形式，如 −1319/123 kN） | **否**，只比峰值 | 无法支撑时程精度 |
| 郭炎冰 2023 | 平均相对误差（标量算例）、车钩力曲线图 | **否**，只有平均值与图形 | 无量化时程误差 |

### E.2 直接回答

**没有任何已取得原文做过"相同控制输入、不同步长、完整有符号车钩力时程"的对比。**

- 翟婉明的"三档步长 + 逐时刻偏差"是**方法论最接近**的一条（PDF4/印54、PDF5/印55），可借用其**判据形式**，但其对象是标量位移，**不能**直接搬为车钩力判据。
- Zhou 2022 的做法（只比峰值）**恰恰是本项目要避免的**：本项目数据显示，峰值差 0.029% 的同时时程差 0.912%，**只比峰值会提前宣布收敛**。

### E.3 因此这是本专项的"缺失证据"

必须在缺失清单中登记为：**"万吨 1+0 编组、同输入、多步长、完整有符号车钩力时程"的公开验证方法——未取得。**

替代做法只能**自建**（见《最小数值对照方案》），并明确标注为"本项目自建方法，无文献先例"。

## F. 若建议改过渡模型，必须单列为物理模型变更

### F.1 三篇原文里，"改过渡"到底改了什么

**【原文明确】** Zhou 2022 的三种过渡策略，全部是**改力定律本身**，不是改求解器：

| 策略 | 新增参数 | 参数物理含义 | 原文是否给出数值 | 原文是否给出标定方法 |
|---|---|---|---|---|
| 速度法 式(1)(2) | **v_ε** | 正则化速度（"regularization velocity"，允许包络间稳态过渡） | **未给出** | **未给出** |
| 中间斜率 式(3)–(5) | **k** | 包络间过渡斜率 | **未给出** | **未给出** |
| 平滑逼近 式(6) | **α** | 逼近外边界的速率 | **未给出** | **未给出** |

→ 关键事实：**Zhou 2022 全文没有给出 v_ε、k、α 的任何数值或标定流程**。它只给出"速度法需 0.1/0.2 ms、耗时约 8 倍"的**后果**，没给**参数从哪来**。

### F.2 Lei 2019 提供的是"物理量标定路径"，不是 v_ε

**【原文明确】** Lei 2019 式(8)，PDF5/印4：

```
μ = h1 + h2·exp(−h3·|v|)
```

- h1 → 动摩擦系数；h1+h2 → 静摩擦系数；h3 → 静→动转换速率。
- 标定依据：**93 t 车以 8 km/h 初速撞击同型静止车**的冲击试验数据（PDF5/印4）。
- 全文检索 `regular`：**0 处**。→ Lei2019 **没有** v_ε 正则化。

**因此必须区分**：

| | Lei2019 的 μ(v) | 本项目 friction_v_eps |
|---|---|---|
| 类别 | **物理量**（摩擦系数随速度变化） | **数值正则化参数**（过渡带宽） |
| 依据 | 冲击试验标定 | **无实测定标依据** |
| 改它意味着 | 改**物理模型** | 改**数值过渡** |

**结论（必须写进任何对外表述）**：`friction_v_eps = 0.002 m/s` **不得**被说成"文献实测值"或"由 Lei2019 标定"。它目前是**数值选择**，来源不明。

### F.3 若建议改过渡模型，必须这样单列

**物理模型变更单（模板）**

| 项 | 要求 |
|---|---|
| 变更内容 | 明确写出旧式 → 新式（如 tanh 切换 → Lei2019 式(8) 的速度相关摩擦，或 → Zhou 式(4) 中间斜率） |
| 新增参数 | 逐个列出（h1, h2, h3 或 k 或 α），并注明单位与物理含义 |
| 参数来源 | **必须**是试验标定（说明试验类型、试件、工况、拟合方法、残差）；**不得**写"取文献值"而不给页码；**不得**写"调参使曲线好看" |
| 与求解器修复的边界 | 明确声明"本次变更改变物理预测，不属数值精度修复"，并给出**变更前后在同一求解器、同一步长下的力时程差异**，以量化"物理变更贡献" |
| 验收影响 | 说明 1000 kN 判据在新模型下是否需重新基线；**不得**为迁就新模型放宽 1000 kN |

**禁止事项**（与用户约束一致）：
- 不得为使曲线好看而修改 `friction_v_eps` 或 MT-2 包络。
- 不得把物理模型变更混入"求解器修复"一起汇报。
- 不得把 Lei2019 的 2 万 t "1+1" 参数直接搬到本项目 1+0 编组。

### F.4 结论

- 现阶段**不建议**改过渡模型。理由：三篇原文均未给出过渡参数的标定流程；本项目也无对应的冲击试验数据可用于标定 h1/h2/h3。
- 现阶段应做的是**纯数值**工作：步长加密 + 事件对齐 + 三量误差分别核验（A/B/C/E）。
- 若将来要改，必须按 F.3 模板单独立项，并先取得 Wu 2014/2015 两篇综述/建模原文（**当前未取得**）。
