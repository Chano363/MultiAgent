# 最小数值对照方案（不改变车钩力定律）

**目标**：在**不改 MT-2 包络、不改 `friction_v_eps = 0.002 m/s`、不改控制周期/气动时钟/物理参数**的前提下，给出可复核的"时间积分精度 + 效率"联合验收。

**性质声明**：本方案是**本项目自建**的对照方法。已取得的四篇原文中**没有**"万吨 1+0 编组、同输入、多步长、完整有符号车钩力时程"的先例（见缺失证据清单 E-01）。因此本方案只能作为工程判据，不能声称"遵循某文献方法"。

---

## 0. 为什么必须换步长阶梯

当前阶梯 0.625 / 0.3125 / 0.15625 / 0.078125 / 0.0390625 ms **均不能整除 1 ms 控制周期**（分别为 1.6 / 3.2 / 6.4 / 12.8 / 25.6 步）。

后果：控制指令阶跃时刻落在积分步内部，每次减半时"阶跃在步内的相对位置"随之改变，相邻档差异**混入事件对齐误差**，不能纯读为截断误差。

**改为与控制周期可通约的阶梯**（均为 1 ms 的整数分之一）：

| 档位 | 步长 (ms) | 1 ms 内步数 | 用途 |
|---|---|---|---|
| L0 | 0.5 | 2 | 全程粗网格 |
| L1 | 0.25 | 4 | 全程/窗口 |
| L2 | 0.125 | 8 | 窗口 |
| L3 | 0.0625 | 16 | 窗口 |
| L4 | 0.03125 | 32 | 参考解（窗口） |
| L5 | 0.015625 | 64 | 仅用于**校核 L4 是否已收敛**（短窗口） |

## 2. 三阶段执行（按算力裁剪，不要一次跑全程细网格）

### 阶段 1：全程粗网格（L0、L1）

- 步长：0.5 ms、0.25 ms，**全程 49.6 km**。
- 目的：确认全程无超速、无安全事件、无负列距；取得全程峰值与峰值位置。
- 产出：`F(t)` 全程时程（按 1 ms 控制网格输出，见 §3）。
- 注意：**两档都粗**，其差异**不能**当作精度结论，只用于看趋势。

### 阶段 2：敏感窗口（L2、L3、L4）

- 窗口：以 **5.7 s、第 2 列、第 67 处车钩、相对速度接近零**的事件为中心，取 **7 s 窗口**（与现有对照口径一致）。
- 步长：0.125 / 0.0625 / 0.03125 ms。
- 参考解：**L4（0.03125 ms）**。
- 校核参考解：在**同一窗口**再跑 **L5（0.015625 ms）**，比较 L5 与 L4 的时程差。若该差 **≤ L4 与 L3 之差的 1/2**，则 L4 可作参考解；否则参考解下移。

### 阶段 3：桥接窗口（L1、L2）

- 窗口：**25 s**（覆盖阶段 2 的 7 s，并向两侧扩展）。
- 步长：0.25 / 0.125 ms。
- 目的：检查"7 s 窗口内收敛"是否在更长时段仍成立；**只作趋势检查，不作验收**。

> **口径纪律**：25 s 窗口与 7 s 窗口的差异**必须分表报告**，**不得**合并为"全程误差"。现有 93.2 / 34.5 / 14.2 / 6.56 kN 四个数字中，93.2 来自 25 s 对照，后三者来自 7 s 对照——**不能并成一个序列**。

## 3. 时间对齐（关键，否则差异是假的）

1. 所有解都输出到**共同的 1 ms 控制网格**（与 Zhou 2022 的控制序列尺度一致，其第 3.1 节）。
2. 若某档步长不落在 1 ms 网格点上（本方案下不会发生），用**线性插值**到网格，并记录插值引入的误差量级。
3. 车钩力在**每个车钩位置**单独比较（108 个位置 + 机车后钩），不先做空间平均。
4. **不做任何滤波、不平滑、不取包络**——比较的是原始有符号力。
5. 事件时刻（控制阶跃、气动波到达）必须落在步边界；若某实现无法保证，则把这些时刻作为**强制断点**（该步截短到事件时刻）。

## 4. 误差指标（三个量分别算，不得互相替代）

设参考解为 `ref`，待评解为 `h`，共同网格上逐点比较。

### 4.1 车钩力（主指标）

| 指标 | 定义 |
|---|---|
| `e_F,max` | `max_t max_k |F_h,k(t) − F_ref,k(t)|`（kN） |
| `e_F,L2` | `‖F_h − F_ref‖₂ / ‖F_ref‖₂` |
| `ΔF_peak` | `|max_t F_h − max_t F_ref|`（kN） |
| `Δt_peak` | 峰值时刻偏移（ms） |
| `ΔJ` | `|∫(F_h − F_ref)dt|`（冲量差，kN·s） |
| 位置 | 记录 `e_F,max` 发生的**时刻、列车号、车钩号** |

### 4.2 位移

| 指标 | 定义 |
|---|---|
| `e_x,max` | `max_t max_i |x_h,i(t) − x_ref,i(t)|`（mm） |
| `e_x,L2` | 相对 L2 范数 |

### 4.3 速度

| 指标 | 定义 |
|---|---|
| `e_v,max` | `max_t max_i |v_h,i(t) − v_ref,i(t)|`（m/s） |
| `e_v,L2` | 相对 L2 范数 |

### 4.4 为什么三者必须分开

车钩力是位移/速度经"包络 + tanh 切换"的强非线性泛函。过渡带内 `∂F/∂v = ½(f_l−f_u)·tanh′(|v|/v_ε)/v_ε`，在 `v_ε = 0.002 m/s` 下对速度误差极敏感。**位移收敛不蕴含车钩力收敛。**

现有数据即为实证：峰值差 0.206 kN（0.029%），而完整时程差 6.564 kN（0.912%）——**时程差约为峰值差的 32 倍**。

### 4.5 内层 vs 外层（必须同时记录）

| 层级 | 记录内容 | 作用 |
|---|---|---|
| 内层（Newton） | 每步迭代次数、最终残差 `‖R‖`、是否触上限 | 证明"方程解开了"，**不证明**时间精度 |
| 外层（截断） | 上述 `e_F / e_x / e_v` | 证明"时间离散够细" |

内层残差建议仍保持 < 0.01 N 的记录，但**不得**用它替代外层指标。

## 5. 建议验收阈值（**需用户确认，本方案不自作主张**）

| 指标 | 建议阈值 | 依据 |
|---|---|---|
| `e_F,max`（L3 vs L4） | **≤ 10 kN**（即 1% × 1000 kN） | 以 1000 kN 判据的 1% 为量级 |
| `e_F,L2` | ≤ 0.5% | 工程惯例量级 |
| `ΔF_peak` | ≤ 0.5% × 峰值 | 峰值须与参考解一致 |
| `Δt_peak` | ≤ 1 ms | 一个控制周期 |
| `e_x,max` | ≤ 0.01 mm | 与 Zhou 2022 缓冲器 F-D 离散尺度 0.01 mm 同量级（**类比，非原文规定**） |
| `e_v,max` | ≤ 0.001 m/s | 与 Zhou 2022 机车速度离散 1 mm/s 同量级（**类比**） |
| 收敛比 | 相邻档差异比 ≥ **1.8** | 接近一阶收敛（当前实测 1.11–1.28，**未达标**） |

**如实提示**：当前 L3→L4 等价的 6.5639 kN 已满足 10 kN 阈值，但**收敛比只有约 1.1**，说明尚未进入渐近收敛区。建议**同时**满足"绝对阈值 + 收敛比"，否则可能只是"两档碰巧接近"。

1. 先跑**阶段 2**（7 s 窗口，L2/L3/L4/L5）——成本最低，直接回答"敏感点是否收敛"。

## 9. 本方案**不能**证明的事（必须写进报告）

1. 不能证明"全程时间精度合格"——细网格只覆盖窗口。
2. 不能证明"更细步长一定更好"——`v_ε = 0.002 m/s` 固定时，步长细到一定程度后，误差可能被**力定律的过渡带宽度**而非离散误差主导（过渡带本身是模型误差，不是积分误差）。
3. 不能替代气动离散误差的核验——本方案固定气动时钟，只测机械积分误差。
4. 不能作为"优于其他方法"的依据——无同类公开算例可横向比较。
