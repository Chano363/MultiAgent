### 三种过渡策略的真实公式

**模型 1：速度相关过渡（velocity-dependent）**

式(1)，第 2.1 节：

```
F = F_spring ± F_f                , |v| ≥ v_ε
F = F_spring + (v/v_ε)·F_f        , |v| < v_ε
```

式(2)，查表包络形式：

```
F(x_t, v_t) = ½(f_l(x_t)+f_u(x_t)) + ½(f_l(x_t)−f_u(x_t))·sign(v_t·x_t)              , |v_t| ≥ v_ε
F(x_t, v_t) = ½(f_l(x_t)+f_u(x_t)) + ½(f_l(x_t)−f_u(x_t))·sign(v_t·x_t)·(|v_t|/v_ε)  , |v_t| < v_ε
```

要点：
- 切换判据用的是 **sign(v_t · x_t)**，即相对速度与相对位移的**乘积符号**，不是单纯 sign(v_t)。
- 过渡带内是 **|v_t|/v_ε 的线性插值**，不是 tanh，也不是指数。
- 原文把 v_ε 明确定义为"a regularization velocity ... to allow a steady transition"，即**数值正则化参数**。
- **原文正文未给出 v_ε 的数值**（全文检索未发现具体取值），也**未说明其标定方法**。

**模型 2：中间斜率法（intermediate slope）**

式(3)(4)(5)，第 2.2 节：

```
F(x_t) = f_l(x_t)                          , x_t ≥ x_{t−Δt}      (3)
F(x_t) = f_u(x_t)                          , x_t <  x_{t−Δt}      (3)
F(x_t) = F(x_{t−Δt}) + k·(x_t − x_{t−Δt})                        (4)
|f_u(x_t)| ≤ F(x_t) ≤ |f_l(x_t)|                                 (5)
```

要点：
- 过渡力由**上一时间步的 F 与 x** 递推（式 4），即**强历史状态依赖**；k 为中间斜率。
- 式(5) 是边界钳位，保证力不越出加载/卸载包络。
- **k 的数值与标定方法原文未给出**。

**模型 3：平滑逼近（smoothing approximation）**

式(6)，第 2.3 节：

```
F(x_t) = f_l(x_t) + (F(x_{t−Δt}) − f_l(x_t))·exp(−|x_t − x_{t−Δt}|/α)  , x_t ≥ x_{t−Δt}
F(x_t) = f_u(x_t) + (F(x_{t−Δt}) − f_u(x_t))·exp(−|x_t − x_{t−Δt}|/α)  , x_t <  x_{t−Δt}
```

要点：
- 同样依赖**上一时间步的 F**（历史状态）。
- α 为控制"逼近外边界速率"的参数；**数值与标定方法原文未给出**。

### 积分方法（原文明确）

- 采用**翟氏两步显式法**（"modified Newmark-β approach, also called 'Zhai' method"），式(9)(10)，第 3 节：
  ```
  X_{n+1} = X_n + V_n·Δt + (½ + ψ)·A_n·Δt² − ψ·A_{n−1}·Δt²     (9)
  V_{n+1} = V_n + (1 + φ)·A_n·Δt − φ·A_{n−1}·Δt                (10)
  ```
- 取 **ψ = φ = 0.5**；**首步自启动时令 ψ = φ = 0**。
- 该法**不迭代**、无残差判据、无步长拒绝机制。

### 积分格式（原文明确）

隐式假定式(2)，PDF2/印52：
```
X_{n+1} = X_n + V_n·Δt + (½ − β)A_n·Δt² + β·A_{n+1}·Δt²
V_{n+1} = V_n + (1 − γ)A_n·Δt + γ·A_{n+1}·Δt
```

显式格式式(3)，PDF2/印52：
```
X_{n+1} = X_n + V_n·Δt + (½ + ψ)A_n·Δt² − ψ·A_{n−1}·Δt²
V_{n+1} = V_n + (1 + φ)A_n·Δt − φ·A_{n−1}·Δt
```

预测-校正四步，PDF3/印53：
```
(I)   预测 X_{p,n+1}, V_{p,n+1}                 — 式(4)，用显式格式(3)
(II)  A_{p,n+1} = M⁻¹(P_{n+1} − K_{n+1}X_{p,n+1} − C_{n+1}V_{p,n+1})   — 式(5)
(III) 校正 X_{c,n+1}, V_{c,n+1}                 — 式(6)，用隐式格式(2)
(IV)  A_{c,n+1} = M⁻¹(P_{n+1} − K_{n+1}X_{c,n+1} − C_{n+1}V_{c,n+1})   — 式(7)
```

**关键事实**：该模式**一次预测 + 一次校正即推进，不做迭代收敛**。因此原文**没有**迭代容差、迭代上限、失败步回退、状态回滚的任何说明（PDF3/印53、PDF4/印54）。

误差补偿（PDF3/印53）：给出截断误差展开式(8)(9)、预测修正(10)、校正修正(11)，系数 ε 见表 1：
- φ=ψ=1/2 时：ε_ep = −5/6，ε_ev = 1/6
- ψ=β=1/6 时：ε_mp = −3/4，ε_mc = 1/4

### 稳定性与精度条件（原文明确）

1. φ=ψ=1/2 时**二阶精度**（PDF2/印52）。
2. **条件稳定**，临界步长与中心差分法相同，φ=ψ=1/2 时 **Δt_cr = T/π**（T 为系统自振周期）（PDF2/印52）。
3. 人工阻尼：φ=1/2 无阻尼；φ>1/2 引入人工阻尼；φ<1/2 产生负阻尼（PDF2/印52）。
4. **非线性情形**（PDF4/印54 原文）："对于线性系统来说是稳定的积分，对于非线性系统而言却不一定稳定"；"隐式时间积分对非线性问题往往不再保持其原有的无条件稳定性"；"非线性分析中时间积分步长必须谨慎选取"。
5. 主张用**数值试验**确定稳定范围与有效步长区段。

### 步长选择方法（原文最可操作的一条，PDF4/印54）

> "判断一个实际问题的数值分析结果真实与否，不能简单地取某个步长（不论大小）计算一次定论，而应变动时间步长计算若干次，然后观察结果的变化趋势，最终取数值结果彼此十分接近的步长区段作为有效计算步长区段进行计算。从工程应用的角度来看，只要在**三个相距一定间隔的步长**下所获得的计算结果具有相当好的接近度，相对偏差为工程应用所允许，即可取**中间那个步长**下的计算结果作为实际问题的合理近似解。"

### 算法结构（原文明确，页 147–148）

1. 系统方程：`M·Ẍ_t + C·Ẋ_t + K·X_t = F_t`（式 1，印147）。
2. 隐式 Newmark-β 假定式(2)(3)，位移/速度式(6)(7)，加速度式(9)（印147–148）。
3. **γ=0.5、β=0.25 时无条件稳定且二阶精度**（印148 原文）。
4. 非线性困难（原文明确）："对于非线性系统，在 t+Δt 时的 F_{t+Δt} 通常与 t+Δt 的速度和位移响应有关，在求解 Ẋ_{t+Δt}、X_{t+Δt} 时又必须需要 F_{t+Δt}，导致隐式 Newmark-β 法无法计算"（印148）。
5. 显式预测初值式(10)(11)，起步令 ψ=φ=0（印148）。
6. 迭代校正：预测 → 式(9) 得 A⁽¹⁾ → 式(6)(7) 得 X⁽¹⁾、Ẋ⁽¹⁾ → 再得 A⁽²⁾ ……（印148）。

### 迭代终止判据（原文式 12，印148）

```
|X⁽ⁱ⁾_{t+Δt} − X⁽ⁱ⁻¹⁾_{t+Δt}| ≤ e
```

- i 为当前步长内的迭代次数，e 为设定的误差限。
- **这是相邻两次迭代位移增量之差，属非线性迭代收敛判据**；原文**未给出 e 的具体数值**（检索未发现）。
- **原文没有截断误差估计量**，也没有 Richardson 外推或局部误差控制。

### 步长接受/拒绝规则（原文明确，印149）

> "设置每个时间步长内的迭代次数不能超过允许的最大迭代次数，当迭代次数超过最大迭代次数，则减小步长，若迭代小于最低迭代次数就满足式(12)，则增加步长。"

- 记 H = 允许最大迭代次数、L = 允许最小迭代次数，**本文取 H=3、L=1**（印149）。
- 即：**步长由迭代次数驱动，而非由截断误差估计驱动**。
- 原文**未给出**步长增减的比例因子（如 ×2 或 ÷2）、也**未给出**拒绝步时的状态回滚方式。

### 算例与精度数据（印149）

**算例 1**：`ẍ − ẋ + e^{2t}·x = 0`，x(0)=cos1，ẋ(0)=−sin1（式 13），仿真 4 s，初始步长 0.01 s，γ=0.5、β=0.25。

### 摩擦系数函数（原文式 8，PDF5 / 印刷页 4）

```
μ = h1 + h2·exp(−h3·|v|)
```

原文释义（PDF5/印4）：
- h1 决定**动摩擦系数**；
- h1 + h2 决定**静摩擦系数**；
- h3 决定**由静摩擦向动摩擦的转换过程**。

### 关键判定：Lei2019 **没有** v_ε 正则化

- 全文检索 `regular`（regularization / regularize）：**0 处命中**。
- 全文检索 `transition`：命中处均指**特性曲线的过渡段**（phase II / transition curve，图 3），非速度正则化。
- 结论：**Lei2019 的速度相关项是"摩擦系数 μ(v)"这一物理量，由冲击试验数据标定；不是数值正则化速度 v_ε。**

### 标定依据（原文明确，PDF5/印4）

- 冲击试验：**93 t 车以 8 km/h 初速撞击另一辆静止的 93 t 同型车**，两车均装 **MT-2 摩擦缓冲器**。
- 由冲击试验数据建立查表模型，并对楔块-弹簧模型的主弹簧力进行修正（Figure 5 对比仿真与试验）。
- 两种模型（查表模型 vs 楔块-弹簧模型）计算速度差异"not significant"。
- 结论倾向：楔块-弹簧模型能反映缓冲器行程变化率的影响，与试验更一致。
