# 积分误差与效率补证（2026-10-23）— 本专项说明

**问题**：1 机车 + 108 辆 C80、1+0、约 10988 t、朔黄 49.6 km；车钩为 MT-2 加载/卸载包络 + 相对速度 tanh 切换，`friction_v_eps = 0.002 m/s`；零 RL 调制，当前只做底层控制诊断。原生 Newmark 迭代大量触上限，已换解析雅可比 Newton，每步力平衡残差 < 0.01 N。

**本专项要回答**：残差达标 ≠ 时间积分精度合格；在**不改力定律**的前提下，如何核验并改进积分精度与效率。

## 结论摘要（可直接引用）

### 1. 文献能给什么、不能给什么

| 问题 | 结论 |
|---|---|
| A 不改力定律的积分改进 | 只有 **郭炎冰 2023**（迭代次数驱动变步长，页 148–149）与 **翟婉明 1990**（预测-校正，印 52–54）。两者**都不提供截断误差判据**：郭的式(12) 是**迭代残差**，翟是**事后三档步长对比** |
| B 三量误差 | Newton 残差（< 0.01 N）与截断误差是两类量，**不可互替**；位移收敛不蕴含车钩力收敛（过渡带内 `∂F/∂v ≈ ½(f_l−f_u)/v_ε`，`v_ε = 0.002 m/s` 时对速度误差极敏感） |
| C 事件定位 | 文献主流是**改力定律消除间断**（Zhou 三种过渡），**不是**事件定位；"局部加密"**无文献支持**，只能标为本项目判断。另发现本项目步长阶梯与 1 ms 控制周期**不整除**，见下 |
| D 高阶/隐式方法 | **原始文献均未取得**，不给公式页码。机制上会引入高频数值阻尼、压低冲击峰值；翟婉明原文明确"隐式对非线性往往不再保持无条件稳定性"（印 54）。**不能**以曲线更平滑声称更准确 |
| E 时程对比方法 | **没有**任何已取得文献做过完整有符号车钩力时程的多步长对比；Zhou 只比峰值，正是本项目要避免的 |
| F 改过渡模型 | 必须单列为**物理模型变更**。Zhou 全文**未给** v_ε / k / α 的数值与标定方法；Lei2019 给的是**摩擦系数函数** μ=h1+h2·exp(−h3\|v\|)（PDF p.5），**不是** v_ε |

### 2. 三个必须写进报告的更正

1. **`friction_v_eps = 0.002 m/s` 没有实测定标依据**，属数值正则化参数；**不得**说成"文献实测值"或"Lei2019 标定"。
2. **Zhou 2022 本地 PDF 是作者自存档稿**（无出版社页眉页脚、无印刷页码），**不能**用 WoS 的 2436–2450 推算公式印刷页；本专项一律用 PDF 页号。
3. **93.2 / 34.5 / 14.2 kN 三个数字口径不同**（93.2 来自 25 s 窗口，后两者来自 7 s 窗口），**不得**并成一个"全程误差"序列。

### 3. 从本项目数据算出的三个事实

| 事实 | 数值 |
|---|---|
| 峰值差 vs 时程差 | 峰值 719.799 → 719.592834 kN，差 **0.206 kN（0.029%）**；完整时程差 **6.5639 kN（0.912%）**，**相差约 32 倍**。→ 只比峰值会提前宣布收敛 |
| 观测收敛阶 | 34.5 → 14.2 → 6.5639 kN，相邻比 2.43、2.16，**观测阶 p ≈ 1.28 → 1.11，趋于 1**，不是二阶。→ 不能靠 Richardson 一次跳到高精度 |
| 步长与控制周期不对齐 | 0.625 / 0.3125 / 0.15625 / 0.078125 / 0.0390625 ms **均不能整除 1 ms**（1.6 / 3.2 / 6.4 / 12.8 / 25.6 步）。→ 相邻档差异**混入了控制阶跃在步内位置变化**，不是纯截断误差 |

### 4. 建议的下一步（不改物理）

1. **换成可通约阶梯**：0.5 / 0.25 / 0.125 / 0.0625 / 0.03125 ms（均为 1 ms 的整数分之一），控制/气动事件时刻**强制断步**。
2. **按窗口分阶段跑**（见 `最小数值对照方案.md`）：先 7 s 敏感窗口，再 25 s 桥接，最后全程粗网格。**不要**尝试全程细网格（约 2–3 亿步）。
3. **三量分别核验**：`e_F`、`e_x`、`e_v` 各自给 max 与相对 L2，同时记录内层 Newton 迭代数与残差。
4. **补测墙钟时间**：当前只有子步数 537600（= 3 列 × 179200，与 `7 s / 0.0390625 ms` 自洽），**没有任何时间数据**，效率结论为空。
5. **暂不改过渡模型**；若要改，先取得 Wu 2014/2015 全文，再按 `六问答复_A-F.md` F.3 模板单独立项，并用冲击试验标定参数。
