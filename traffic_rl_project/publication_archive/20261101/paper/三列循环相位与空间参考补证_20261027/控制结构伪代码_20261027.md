## 1. 分层结构

```
上层：领航节奏层（周期 = 决策步长，非物理周期）
  输入：v_ref(t)、线路坡度/限速、各列 (s_i, v_i, σ_i, τ_i)
  输出：v_lead_target、pace_flag ∈ {正常, 压速, 退出压速}
  是否用未来信息：只用线路前方坡度/限速（地图先验），
                 不用任何未来真实仿真轨迹

中层：单列相位层（每列独立）
  状态：σ_i ∈ {充风, 施加, 持压, 缓解, 再充风}
        τ_i = 进入当前相位的累计时间
        p_bc,i = 制动缸压力, p_aux,i = 副风缸压力（若有）
  输入：本列目标速度、前车状态（V2V，允许延时）
  输出：ED 指令 u_ed,i、AB 请求 a_ab,i ∈ {无, 减压Δp, 保压, 缓解}
  是否用未来信息：否

下层：可行性过滤（硬门，动作生效前执行）
  输入：候选 (u_ed, a_ab) + σ/τ + 坡度 + v
  输出：允许的 (u_ed', a_ab') 或 REJECT + 降级请求
```

## 2. 可行性过滤（核心，逐条对应原文依据）

```
function filter(i, u_ed, a_ab, σ, τ, v, s, line):
    # R1 充风未完成禁止再减压（依据：林轩2017 式(9) t_z ≥ T_c 的形式）
    if σ == 再充风 and τ < T_c[i]:
        a_ab = 无                       # 只允许 ED 变化
    # R2 持压/等待期内不得越上限（依据：TubeMPC 式(24) 速度约束 + 本项目 v_max）
    if σ in {持压, 再充风, 缓解}:
        for t in horizon:
            v_pred = integrate(v, u_ed, slope(s(t)), resist(v))   # 仅 ED
            if v_pred > v_max: 
                return REJECT(超速风险)  → 触发上层降级
    # R3 ATP 安全带（依据：本项目 _atp_safe_gap，ETCS 曲线）
    if s_lead_tail - s_i - L_lead < d_safe(v_i, v_lead):
        return REJECT(ATP)
    # R4 车钩力（依据：本项目 1000 kN 验收；非文献值）
    if predicted_peak_coupler(u_ed, a_ab, line) > 1000 kN:
        return REJECT(钩力)
    # R5 输入物理上限（依据：TubeMPC 式(25) 形式；数值用本项目 HXD1 特性）
    u_ed = clip(u_ed, U_min(v), U_max(v))
    return (u_ed, a_ab)
```
