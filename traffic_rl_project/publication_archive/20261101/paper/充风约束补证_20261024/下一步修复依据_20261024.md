## 1. 结论先行

1. **"缩短 222 s"这个方向本身缺乏依据**——222 s 在原文里不是"要求的充风时间"，而是"观测到的最短充风间隔"。原文的**要求值**是 165 s（初减压）与 256 s（70 kPa）。把观测值当门禁要求，是把两类量混为一谈。
2. **"继续加大跟随速度偏置"与充风判据方向相反**——缓解速度越高，缓解后到下一次制动可用的增速时间 t_z 越短，t_z ≥ T_c 越难满足。它可以缓解列距/ATP 冲突，但会加重充风约束。
3. **正确着手点是缓解前的可行性判断**：在缓解时刻就沿线路积分算出"以最大电制动能撑多久"，与 T_c 比较；撑不住就说明该缓解事件在当前状态下不可行，应改缓解时机/缓解速度/跟随目标，而不是改门禁。
4. **222 s 现有门禁保留不动，但必须标注为"未完成本编组定标的模型假设"**。在定标完成前，它是唯一可用的保守占位值，不能删、不能缩、也不能被 196 s / 149.7 s / 216 s 替换。

## 2. 证据链：为什么必须回到缓解前判断

### 2.1 222 s 的定性（张二田 2021，印刷页 76，3.2 节）

原文：

> "……共进行了 19 次循环制动，减压量最大为 80 kPa，期间**最短充风时间为 222 s**，能够满足**初减压 165 s** 再充风时间的要求，困难区段减压 70 kPa 无法满足 **256 s** 再充风时间的要求。"

读法：

| 量 | 数值 | 性质 |
|---|---|---|
| 观测到的最短充风间隔 | 222 s | **观测值**（19 次循环中的最小值） |
| 初减压所需再充风时间 | 165 s | **要求值** |
| 70 kPa 所需再充风时间 | 256 s | **要求值** |

- 222 s > 165 s → 初减压"够用"；222 s < 256 s → 70 kPa"不够用"。这正是原文的论证结构。
- 因此 **222 s 不是任何减压量下的要求值**，把它当固定门禁，等于要求"每次缓解都必须达到该试验观测到的最短间隔"。
- 原文未写"初减压"对应的 kPa，**不得补成 50 kPa**。

### 2.2 编组不可迁移（同一篇，印刷页 75，2.2 节）

> "编组方式为'1 台交流机车+108 辆 C80 货车+1 台交流机车+108 辆 C80 货车+可控列尾'，重车牵引总重 21600 t，计长 237.6。"

- 有"108 辆"，但是**两组各 108 辆、中部有从控机车**的 2 万 t 组合列车。
- 本项目是**单机车 + 108 辆**，108 辆即整列。二者缓解同步性、充风能力都不同（原文另述尾部 55 辆与前部 55 辆存在约 3 s 制动时差、10 s 缓解时差）。
- **结论：222 s 既不是要求值，也不属于本编组。**

### 2.3 同编组同判据下数值仍不唯一（高胜利 2016 vs 胡杨 2017）

| 来源 | 编组 | 减压量 | 判据 | 数值 | 性质 |
|---|---|---|---|---|---|
| 高胜利 2016（印刷页 77 表 4 / 页 78 判据） | 1 机车 + 116 辆 C80 | 50 kPa | 尾部副风缸达 580 kPa | 196 s | 现场充排风时间表 |
| 胡杨 2017（印刷页 119 式(5)、表 1） | 1 HXD + 116 辆 C80 | 50 kPa | 尾车副风缸达 580 kPa | 149.7 s | 仿真+二次拟合，无滞后 |

- 编组、减压量、判据三者相同，数值差 46 s。
- 差异来源可追溯到胡杨"为消除滞后时间的影响，设定所有从控机车与主控机车同时动作即无滞后"——即**仿真理想化**。
- **结论：不得取平均、不得取较小者。** 这条同时说明：即使将来本项目做出仿真定标，也必须与实车/试验口径区分。

### 2.4 可行性判据的正确形式（林轩 2019，印刷页 51–52）

原文式(8)：

> "则列车在长大下坡道上的增速时间应不小于副风缸充风时间，约束条件为 t_z ≥ T_c"

原文式(14)：

> "t_z = ∫_{x_A}^{v'} (1/v(x)) dx ≥ ∫_{x_A}^{v'_lim} (1/v(x)) dx = T_c"

原文命题：

> "列车在长大下坡区间进行空气制动，当且仅当实际缓解速度不大于列车缓解速度 v'_lim(x) 时，即 v_s ≤ v'_lim(x)，周期性制动有最优解"

结论(1)（印刷页 57）：

> "周期性制动的最优缓解速度是副风缸缓解再充风时间约束边界值对应的速度 v'_lim(x)。"

- 这条把"充风约束"转化为**对缓解速度的约束**，而且**在缓解时刻即可判定**：给定 T_c 与线路坡度，可反算出 v'_lim。
- 因此正确的动作顺序是：**先判该次缓解是否可行 → 再决定缓解速度/时机**；而不是先定缓解速度、再靠门禁兜底。
- 加大跟随速度偏置 = 提高 v_s = 逼近甚至超过 v'_lim = **判据更难过**。

### 2.5 处置逻辑的先例（专利 CN119682711A）

> "一旦模型预测结果超出约束条件范围，进入安全模式运行，即主、从控机车采用同步控制指令输出，不采用异步协同控制参数寻优结果。"

> "约束条件 13 包括……**由重载组合列车的编组属性决定的充风时间 15**……缓解时间超过整列车充风的时间要求……"

- 该专利把充风时间作为**编组属性决定的约束**进入预测，越界即退回安全模式——与本项目"预测不可行就报不可行"一致。
- 但该专利对象是**一列车内主控+中部从控机车**，不是三列独立编队；且**未给出任何充风时间数值与判据**。只能借结构，不能借数值，更不能作为三列协同有效的证据。

### 2.6 工程上被验证过的方向（肖致明 2023，印刷页 27、30）

- 216 s 是 7129 次列车"缓解→再制动"的**实际间隔**，且该次在 81.161 km **停缓**——是被作者当作待优化反例的案例，不是合格阈值。
- 作者给出的可行方案是：**缓解速度降到 ≤50 / ≤60 km/h + 在缓坡（73.3–74.0 km）缓解 + 电制动力恒定 400 kN**。
- 方向与林轩判据一致：**降 v_s 以换取 t_z**。这与"加大跟随速度偏置"正好相反。
- 该文编组未公开，数值不可搬用。

## 3. 缓解前可行性判据（可执行形式）

### 3.1 符号与口径

| 符号 | 含义 | 本项目取值来源 |
|---|---|---|
| x | 沿线路里程 | 线路纵断面数据 |
| v | 速度 | 检查点状态 |
| i(x) | 坡度千分数，下坡为正（顺运行方向） | 线路数据，逐点更新 |
| M | 列车总质量 | 本编组 |
| γ | 回转质量系数 | 本模型 |
| F_eb(v) | 可用电制动力（含恒功率段限幅） | 本模型特性曲线 |
| W_0(v) | 基本阻力 | 本模型 |
| F_g(x) = M·g·i(x)·10⁻³ | 坡道下滑分力 | 由 i(x) 算 |
| Δp | 该次减压量 | 该次缓解事件 |
| T_c(Δp) | 该减压量所需再充风时间 | **当前仅有 222 s 这一未定标假设**（见 §5） |
| t_z | 缓解后到下一次制动的增速时间 | 由积分算 |
| v_s | 缓解速度 | 决策量 |
| v_next | 下一次制动开始速度（或限速） | 参考轨迹/限速 |

### 3.2 动力学积分（沿线路逐点，不用单点力差外推）

```
a_k   = [ F_eb(v_k) + F_g(x_k) − W_0(v_k) ] / (γ·M)
v_{k+1}² = v_k² + 2·a_k·Δx            （Δx 建议 10 m；v² 取非负）
t_{k+1}  = t_k + 2Δx / (v_k + v_{k+1})
```

- **F_eb 必须按 v 取当前可用值**（进入恒功率区后随速度下降），不得用额定值一算到底。
- **F_g 必须按 x 逐点取坡度**，不得用 668.2 s 那一点的下坡力代替整段。
- 积分终止条件：v 达到 v_next，或 x 到达下一次制动点，或 v 跌到 v_min_oper（停缓风险）。

### 3.3 三条同时成立的可行性条件

| # | 条件 | 判据 | 不满足时的含义 |
|---|---|---|---|
| C1 | 充风 | t_z ≥ T_c(Δp) | 充风窗口不足，该缓解事件不可行 |
| C2 | 限速 | v(x) ≤ v_limit(x)，∀x∈窗口 | 缓解后增速会碰线路限速 |
| C3 | 列距 | gap(t) ≥ g_min，∀t∈窗口 | 会碰前车安全边界 |

补充条件 C4（防停缓）：v ≥ v_min_oper，避免"为等充风而压得过低导致停缓"——高胜利 2016 与肖致明 2023 都把停缓列为失败。

### 3.4 用"最有利上界"做判定，避免过度乐观

- 令 F_eb 取**当前速度下的最大值**，得到 t_z 的**上界** t_z^max（电制动越强，增速越慢，t_z 越长）。
- **若 t_z^max < T_c → 该缓解事件在该状态下必然不可行**（任何更弱的电制动只会更差）。此结论不依赖参数细调，可直接用于否决。
- **若 t_z^max ≥ T_c → 只说明充风可行域非空**，仍需在域内选 v_s，并**另做完整动力学回放**检查车钩力（最大电制动本身可能加重缓解冲击，见张二田"缓解时承受较大车钩力"、高胜利"动力制动减小拉钩/压钩力"）。
- 该上界法**不能**用来证明"可行"；只能用来证明"不可行"。这一非对称性必须在报告里写明。

### 3.5 前车状态的处理

- 三列各自独立，C3 需要前车未来位置 x_lead(t)。
- 若前车未来状态来自同一预测器 → 属**同模型自洽预测**，不是真值；若来自假设（如"前车保持当前策略"）→ 必须在结果中标注假设。
- **没有前车未来状态时，只能给出"在假设 H 下列 i 可行/不可行"，不得宣称保证安全。**

## 4. 只读预测流程（不改代码、不跑闭环，仅记录）

### Step 0 选检查点

- 从**问题缓解动作之前**的可信完整检查点开始，**不是**从 668.2 s 停止点开始。
- 668.2 s 是"跑到停"的位置，其状态已被此前的 ATP 接管与多次决策污染，不适合作为因果分析的起点。

### Step 1 记录状态量（每列一行）

| 字段 | 说明 |
|---|---|
| 列号 / 缓解时刻 t_r / 缓解位置 x_r | 该次缓解事件 |
| 缓解速度 v_s | 决策量 |
| 该次减压量 Δp | 与 T_c 对应 |
| 当前车钩力 / 加速度 | 缓解前瞬时值 |
| 电制动力实际输出 | 不是指令值，是实际值 |
| 净坡道力 F_g − W_0 | 缓解位置处的逐点值 |
| 前车位置与速度 | 及该值的来源（预测/假设） |
| 动态安全速度边界 | 由限速与制动距离反算 |

### Step 2 沿线路积分

- 按 §3.2 从 (x_r, v_s) 积分到 v_next 或限速点。
- 逐点更新 i(x)、F_eb(v)、W_0(v)。

### Step 3 判定与输出

输出一张表，每行一个缓解事件：

| 列 | 缓解时刻 | 缓解位置 | v_s | Δp | T_c(Δp) | t_z^max | 余量 t_z^max−T_c | 是否碰限速(C2) | 是否碰前车(C3) | 是否停缓(C4) | 结论 |
|---|---|---|---|---|---|---|---|---|---|---|---|

结论只允许三种取值：**可行（在假设 H 下） / 不可行 / 无法判定（缺前车状态）**。

### Step 4 只读预测的定位

- 预测器**不是物理验收**：车钩力与空气传播仍由完整动力学回放验证。
- 预测器的作用是**筛掉明显不可行的缓解事件**，把实验预算集中到可行域内。

## 5. 222 s 的当前处置（明确、可审计）

| 项 | 处置 |
|---|---|
| 门禁数值 | **保留 222 s 不变** |
| 门禁语义 | 标注为"**未经本编组定标的模型假设**"，不是文献要求值，也不是本编组实测值 |
| ATP | 保留，不放宽 |
| 减压量分档 | 当前**没有**本编组的 T_c(Δp) 曲线；不得用张二田的 165 s / 256 s 代替（那是 2 万 t 组合列车） |

> 说明：把 222 s 用于所有减压量档位，在物理上偏保守（小减压量实际所需更短），但这是**在缺定标数据时唯一不引入乐观偏差**的选择。若因此导致可行域过窄，正确动作是**报告"当前证据不足以支持该区段通过"**，而不是下调 222 s。

### 6.2 局部覆盖窗口的检查项（每次实验必填）

| 指标 | 口径 |
|---|---|
| 速度范围 | 40–80 km/h（超出即记录越界点） |
| 内部子步车钩力峰值 | ≤ 1000 kN（不得放宽） |
| ATP 接管次数 | 与基线同窗口对比 |
| 列间距最小值 | 与基线同窗口对比 |

### 6.3 单一候选的选取顺序（一次只动一个）

1. **只提前缓解时刻**（v_s 不变）→ 看 t_z 是否变长。
2. **只降 v_s**（时刻不变）→ 看 t_z 与车钩力。
3. **只改跟随目标**（前两项不变）→ 看列距/ATP。
4. 三者组合仅在单变量均改善后考虑。

> 依据：§2.4 的判据方向是"降 v_s 换 t_z"，§2.6 的工程方案也是"降缓解速度 + 缓坡缓解"。加大跟随偏置属反方向，不应作为首选候选。
