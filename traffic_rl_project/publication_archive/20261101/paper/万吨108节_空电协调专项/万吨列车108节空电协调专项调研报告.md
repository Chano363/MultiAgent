## 二、已有核心论文精读摘要

### 2.1 马志强等《重载列车平稳运行的空电联合制动匹配控制》（机车电传动, 2023(4):71-76）

**原文状态**：✅ 已有 PDF + 提取文本

**编组与参数**：
- 2 万吨重载组合列车（朔黄铁路，1+1+可控列尾编组）
- 采用模式化操纵（空气制动按规则施加，电制动优化调节）
- 长大下坡道循环制动工况

**核心方法**：
1. **空电解耦思路**：空气制动按模式化操纵规则施加，转化为已知阻力分布；电制动作为优化控制量，用二次规划求解
2. **迭代匹配算法**：空气制动力 ↔ 速度曲线迭代收敛
   - Step 1：设目标速度 v_r，按恒速计算空气制动力初始序列 B_c0
   - Step 2：B_c0 作为附加阻力代入二次规划求解电制动操纵序列
   - Step 3：用优化速度曲线重算空气制动力，迭代至偏差收敛
3. **敛散性判据**（式7）：
   - B_c(v_r) + F_eb_max + W_0(v_r) - W_j(s) ≥ 0 （下坡合力为负，电制动有调节余量）
   - B_c(v_r) + F_eb_min + W_0(v_r) - W_j(s) ≤ 0
   - 含义：列车在大下坡使用空电联合制动时，速度可仅由电制动调控，且有唯一电制动序列使速度恒定于 v_r

**操纵规则约束**（关键！可直接借鉴）：
- ① 空电联合制动时，若速度与目标速度偏差过大，**仅调整电制动力**保证速度跟踪
- ② 循环制动时，**列车开始缓解后维持恒定电制动力 50 s**
- ③ 缓解施加前**逐步增大电制动力并保持不变**，缓解施加后电制动还要继续保持至少 50 s（赵紫宁2022第5.3节操纵准则）
- ④ 尽量在缓坡段进行缓解（避免变坡+缓解叠加产生更大纵向冲动）

**仿真结果**（2 万吨，朔黄线长大下坡）：
- 压钩力最多同比下降 33.74%，拉钩力最多同比下降 15.38%
- 电制动序列更平滑，关键节点操纵复杂度下降
- 最大车钩力：实车约 1028-1195 kN（各变坡点），优化后降低

**对本项目的适用性**：
- ✅ 可以直接借鉴：缓解后 50 s 恒定电制动力的规则、仅用电制动调速的思路、空电解耦框架
- ⚠️ 需要重标定：2 万吨双机车 → 1 万吨单机车，制动力分配完全不同
- ❌ 不适用：迭代匹配算法依赖整车优化（二次规划），不适合底层实时控制；2 万吨数据不可直接套用

## 四、关键公式与参数记录

### 4.1 空气制动三段式模型（王青元/赵紫宁2022，式2-3，PDF第2-3页）

**牵规两段式模型**（式3）：
```
B_c(t) = 0,                          t < t_kz   （空走时间）
B_c(t) = β_c × φ_h × [P_N × K_h + Σ(G_i × K_h)],  t ≥ t_kz  （有效制动）
```

**精细化三段式模型**（马志强2023式2、王青元2022式同）：
```
B_c(t) = 0,                                                          t ≤ t_d,i
B_c(t) = C_β × β_c × φ_h × [P_N × K_h + Σ G_N × K_z,i(t) × P_s(t)],  t_d,i < t ≤ t_m,i
B_c(t) = C_β × β_c × φ_h × [P_N × K_h + Σ G_N × K_h × P_s(t)],        t > t_m,i
```

**制动性能修正函数 P_s(t)**：反映历史制动/缓解对当前制动性能的影响（连续制动导致制动力下降）

### 4.2 空电联合控制约束（马志强2023，式4，PDF第3页）

```
0 ≤ F_t,i ≤ F_t,max(v)          牵引力上限
0 ≤ F_eb,i ≤ F_eb,max(v)        电制动力上限
0 ≤ B_c,i ≤ B_c,max(v)          空气制动力上限
|F_t,i - F_t,i-1| ≤ ΔF_t        牵引力变化率约束
|F_eb,i - F_eb,i-1| ≤ ΔF_eb     电制动力变化率约束
F_t,i × F_eb,i = 0              牵引和电制动不同时施加
```

### 4.3 敛散性判据（马志强2023，式7，PDF第4页）

```
B_c(v_r) + F_eb,max + W_0(v_r) - W_j(s) ≥ 0
B_c(v_r) + F_eb,min + W_0(v_r) - W_j(s) ≤ 0
```
含义：空电联合制动下，电制动有上下调节余量，可单独由电制动维持恒速。

### 4.4 操纵规则量化（马志强2023，第3.3节，PDF第4-5页）

- **规则①**：空电联合时速度偏差大 → 仅调电制动
- **规则②**：缓解后 → 维持恒定电制动力 50 s

### 4.5 车钩力纵向动力学模型（马志强2023，式8，PDF第4页）

```
m_2 × v̇_2 = F_co,2 - F_co,1 - F_eb,2 - B_c,2 - W_0,2 - W_j,2
...
m_n × v̇_n = F_co,n - F_co,n-1 - F_eb,n - B_c,n - W_0,n - W_j,n
```

## 六、修复建议分类

### 6.1 可以直接借鉴的控制逻辑

**1. 缓解前后电制动衔接规则（马志强2023 + 赵紫宁2022）**
- **内容**：
  - 缓解施加前：逐步增大电制动力并保持恒定
  - 缓解施加中：电制动保持不变
  - 缓解施加后：电制动继续保持至少 50 s，之后再缓慢调整至目标值
  - 尽量在缓坡段进行缓解（避免变坡+缓解叠加）
- **原理**：缓解过程中前后部车辆缓解不同步（2万吨约有10s缓解时差），若此时电制动也变化，会叠加产生更大纵向冲动。缓解前预加电制动可以"压住"列车，防止缓解时前部车辆突然前冲。
- **借鉴方式**：
  - 缓解触发前 t_advance 秒，开始线性增大电制动力至目标值并冻结
  - 缓解期间保持电制动恒定
  - 缓解完成后继续保持 t_hold 秒，再线性恢复调节
- **依据**：马志强2023 第3.3节、赵紫宁2022 第5.3节操纵准则第2条
- **仿真效果**：赵紫宁2022报告压钩力最多同比下降 29.49%

**2. 速度偏差大时仅调电制动（马志强2023规则①）**
- **内容**：空电联合制动时，若速度偏差过大，仅调整电制动力保证速度跟踪
- **原理**：空气制动延迟大、影响车钩力剧烈，电制动响应快、对车钩力影响相对平滑
- **借鉴方式**：速度偏差超过阈值时，优先增减电制动，不轻易新增空气制动
- **依据**：马志强2023 第3.3节

**3. 空气制动力历史修正思路（王青元2022 P_s(t)）**
- **内容**：连续制动导致充风不足，后续制动的制动力会下降（修正系数 C_β 从 1.379 降至 0.932）
- **借鉴方式**：在制动模型中引入"制动性能衰减系数"，根据连续制动次数和充风时间动态修正制动力预估
- **依据**：王青元2022 表5-5

**4. 缓解后车钩力最大的规律（张二田2021）**
- **内容**：最大拉钩力、最大纵向加速度主要在缓解后出现
- **借鉴方式**：保护逻辑应重点关注缓解阶段，缓解前后的电制动衔接需要特别平滑
- **依据**：张二田2021 第3.1节

### 6.2 需要按本项目重新标定的参数

**1. 空气制动时间参数**
- 头车充气时长 T_1、尾车充气时长 T_N、制动波传播时间 t_N
- 现有数据：2万吨 216 辆（T_1=12s, T_N=44s, t_N=14s）
- 本项目：1万吨 108 辆，需要按比例缩放或实测
- **估算参考**：如果近似线性，108辆约为 216辆的一半，但制动波速非线性，需谨慎

**2. 缓解后电制动保持时间**
- 马志强给出 50 s（2万吨双机车）
- 本项目单机车 108 辆，缓解波传播距离短，可能需要缩短
- 建议：先按 30-40 s 试探，根据仿真结果调整

**3. 再充风时间要求**

- 胡杨2017论文预期包含此数据，需获取全文确认

**4. 制动力变化率约束 ΔF_eb**

## 八、对照实验方案建议

### 推荐实验：缓解前后电制动衔接策略标定实验

**解决的瓶颈**：缓解后车钩力超限（当前试验中350-469s车钩力693-938kN，峰值1047kN超限）

**核心思路**：
借鉴马志强2023和赵紫宁2022的"缓解前后电制动衔接"规则——**缓解前逐步增大电制动力并保持、缓解中保持恒定、缓解后继续保持至少50s**——测试不同的电制动预加量和保持时间对缓解后车钩力峰值的影响，找到既能满足车钩力约束又不影响充风效率的参数组合。

**实验设计**：

| 项目 | 设定 | 说明 |
|------|------|------|
| 列车编组 | 1机车+108货车，总重10988吨 | 与当前600s试验完全一致 |
| 线路 | 朔黄铁路宁武西—北大牛49.6km纵断面 | 与当前试验一致 |
| 初速 | 80 km/h | 与当前试验一致 |
| 制动方式 | 电制动+空气制动（传统空气制动模型） | 与当前试验一致 |
| 车钩力指标 | ≤1000 kN | 验收标准 |
| 速度指标 | ≤80 km/h | 线路限速 |

**对比工况**：

| 工况编号 | 缓解前电制动 | 缓解中电制动 | 缓解后保持 | 预期效果 |
|----------|-------------|-------------|-----------|----------|
| 0（基准） | 当前策略 | 当前策略 | 当前策略 | 1047.7 kN超限 |
| 1 | 不变 | 冻结当前值 | 20 s | 轻微改善 |
| 2 | 不变 | 冻结当前值 | 30 s | 中等改善 |
| 3 | 不变 | 冻结当前值 | 40 s | 显著改善 |
| 4 | 不变 | 冻结当前值 | 50 s | 按马志强原文 |
| 5 | 预加20%，5s线性增长 | 冻结预加后值 | 30 s | 更强抑制（赵紫宁策略） |
| 6 | 预加30%，5s线性增长 | 冻结预加后值 | 40 s | 最强抑制 |

**检查指标**：
1. ✅ 车钩力峰值（所有车钩断面最大绝对值）
2. ✅ 最高速度（是否超速）
3. ✅ 缓解后车钩力收敛时间
4. ⚠️ 再充风完成时间（电制动是否影响充风效率？）
5. ⚠️ 总制动距离
6. ⚠️ 电制动容量是否足够（是否触发电制动上限）

**为什么选这个实验**：
1. **针对性强**：直接针对缓解后车钩力超限这个最大瓶颈
2. **有文献依据**：马志强2023+赵紫宁2022明确给出了规则和效果数据（压钩力下降29.49%~33.74%）
3. **改动最小**：只修改缓解阶段前后的电制动逻辑，不涉及空气制动控制逻辑
4. **风险可控**：如果效果不好，可以快速回退
5. **对标明确**：可以与马志强/赵紫宁的2万吨数据定性对比，验证规律是否一致
6. **物理直觉清晰**：缓解前"压"住列车、缓解中保持稳定、缓解后让列车平稳过渡，符合纵向动力学基本规律

**需要的参数依据**：
- 缓解触发信号（从空气制动模型的缓解指令获取）
- 当前电制动力值和电制动容量（预加量的基准）
- 预加时间（建议5-10s线性增长）
- 保持时间初值：建议从30s开始试，根据效果调整
- 车钩力监测：所有车钩断面的实时车钩力
