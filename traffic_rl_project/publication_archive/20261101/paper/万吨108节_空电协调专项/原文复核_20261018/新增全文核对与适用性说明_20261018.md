# 新增四篇全文核对与适用性说明（2026-10-18）

结论：此前缺失的四篇全文已存在并已按关键章节核对。原调研报告中“胡杨期刊/博士、高胜利、雷美琳全文未取得”状态已过时；本文为补充复核，不追改其检索历史。本轮不改代码或充风参数，不宣称1000kN瓶颈已经解决。

## 1. 胡杨2017期刊：取得1+0再充气拟合公式

《机车编组方式对列车再充气特性的影响》，PDF第3页（印刷113页）明确1辆HXD1+116辆C80，而不是108辆。PDF第4—5页（印刷114—115页）将尾车副风缸升至580kPa所耗时间定义为充风时间；110kPa减压实测1+0与2+1+0分别387s、162s。

PDF第9页（印刷119页），式(5)：T=A+BΔp+CΔp²+DR；表1的1+0行为A=-99.794、B=5.740、C=-0.015、D=0。Δp按kPa代入，T为s；R为从控滞后s，1+0无从控项。50kPa代入得到149.706s。这是该文拟合值，不是108辆运行规章或本项目已验证值。公式和表已视觉核对，见机车编组方式_PDF9.png。

不同机车位置充风差异明显，不能把双机车两万吨充风时间直接折半；也不能按108/116简单缩放。

## 2. 胡杨博士论文：提供不同的单编再充气模型及试验值

《神华铁路万吨重载列车纵向动力学试验与仿真研究》，博士论文。

PDF第107页（印刷95页）明确定义：从开始缓解至充风最慢车辆副风缸压力达到580kPa所用时间。PDF第111页（印刷99页）：50kPa减压的1+0试验150s、气流仿真145s；不是指制动缸排气完成。

PDF第112—114页（印刷100—102页），§6.3给出116辆单编模型。PDF114页（印刷102页），原印刷式号(6.9)：

t = -16.58 + 3.83Δp - 8.16×10⁻³Δp²，50≤Δp≤170kPa。

50kPa计算154.52s，表6.1取整为155s，试验/仿真对照150s；70kPa表中216s（试验/仿真）、212s（模型）。已视觉核对胡杨博士_PDF114.png。期刊与博士论文公式不同，不能混成一套“胡杨公式”。

## 3. 高胜利2016：单牵万吨50kPa减压充风196s

《单牵万吨列车充风不足的原因分析及措施》，中国铁路2016年第11期，起页76，DOI10.19549/j.issn.1001-683x.2016.11.019。

PDF第2页（印刷77页）：交流机车+116辆C80+列尾装置；车辆总质量11600t，机车质量另列200t。车型描述“神华号”交流机车，表1最大电制动力461kN。与当前188t机车+108辆、总10988t模型并不一致，不能直接套用电制动特性。

同页表4：减压50/100/170kPa/紧急对应充风时间196/368/476/656s；排风时间是另一行60/82/110/2s，二者不可混用。50kPa下196s并不等同于胡杨150s，本文核对部分尚不足以确认两者设备、初始压力、计时与完成判据完全一致，不能简单平均，更不能择小值当安全依据。表页已视觉核对单牵万吨_PDF2.png。

## 4. 雷美琳2026：幅值与施加时机应分阶段考虑

《典型线路重载列车电制动力异步控制与优化》，大连交通大学硕士学位论文，答辩2026-05-30，90个PDF页。

已读摘要、§1.3与§2.3附近：论文将主从控机车电制动力幅值与施加时机同时作为调控维度，讨论不同阶段拉压峰值、变坡激扰与空气制动传播；不是只把电制动整体增大或减小。

可借鉴“识别关键相位—适配力值—时变调控”的思路。其主从控分配、异步时差需要多台机车，不能直接用于本项目单机车列内控制。不能据此把主从控时间参数移植成单机车ED保持时间，也不宣称已通读90页并复现方法。

## 5. 对当前修复的影响

1. 现在已有单机车万吨再充气的原文证据，先前“完全缺依据”的状态已经改善；但未取得与108辆、当前机车型号、供气系统、EOT及压力判据全部匹配的单一时间值。
2. 149.706s为期刊拟合值、150s为博士试验值、154.52s为博士拟合值、196s为高胜利表4记录，各有自己的适用条件，不能当作可互换的108辆参数或通用安全区间。
3. 当前仿真记录的制动缸压力系数/排气比例不等于尾车副风缸580kPa；在代码不具备对应状态时，不能声称实现了论文的再充气完成判据。
4. 先保持222s原对照，明确充风起算事件和模型状态，再设计有明确假设的充风敏感性试验；不得把缩短充风当成1000kN问题已解决。
5. 当前最早峰值在首次缓解之前，充风修正并不能直接消除该首峰。需要继续基于完整气动/积分历史，分开预测拉伸、压缩，选择ED变化时机；再评估600kN新增AB门与速度约束的冲突。
6. 下一轮优先在125s与170s附近的完整运行状态比较同一组ED变化，验证拉压峰值与速度的短时预测；通过后才推广闭环。单机车ED过渡仍是待验证方案，不直接复制多机车异步控制。
