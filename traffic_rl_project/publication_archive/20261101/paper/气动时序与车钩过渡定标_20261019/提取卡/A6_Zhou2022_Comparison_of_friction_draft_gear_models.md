## 3. 公式准确形式（经页面文本逐行核对）

**Model 1（速度相关，式1）**：
```
F = F_spring ± F_f,            |v| ≥ vε
F = F_spring + (v/vε)·F_f,     |v| < vε
```
**Model 1（详细式2）**：
```
|v_t| ≥ vε:  F = ½(f_l(x_t)+f_u(x_t)) + ½(f_l(x_t)−f_u(x_t))·sign(v_t·x_t)
|v_t| < vε:  F = ½(f_l(x_t)+f_u(x_t)) + ½(f_l(x_t)−f_u(x_t))·sign(v_t·x_t)·(|v_t|/vε)
```
其中 `x_t`、`v_t` 为**相邻车辆**在当前时间步的相对位移与相对速度；`f_l`、`f_u` 为加载/卸载包络线；`vε` 为正则化速度。

**Model 2（中间斜率，式3-5）**：
```
F(x_t) = f_l(x_t),  x_t ≥ x_{t−Δt}
F(x_t) = f_u(x_t),  x_t < x_{t−Δt}          …(3)
F(x_t) = F(x_{t−Δt}) + k·(x_t − x_{t−Δt})    …(4)
|f_u(x_t)| ≤ F(x_t) ≤ |f_l(x_t)|             …(5)
```
`x_{t−Δt}`、`F(x_{t−Δt})` 为**上一时间步相邻车辆相对位移与缓冲器力**；`k` 为**中间斜率（intermediate slope）**。

**Model 3（平滑近似，式6）**：
```
x_t ≥ x_{t−Δt}:  F = f_l(x_t) + (F(x_{t−Δt}) − f_l(x_t))·exp(−|x_t − x_{t−Δt}|/α)
x_t < x_{t−Δt}:  F = f_u(x_t) + (F(x_{t−Δt}) − f_u(x_t))·exp(−|x_t − x_{t−Δt}|/α)
```
`α` 为**描述滞回环趋近外包络速率的临界参数**。

## 5. 步长与时间收敛结论（本文最有价值部分）

- **Model 1（速度相关）需要最小积分步长 0.1 ms 或 0.2 ms** 才能得到稳定响应；
- **Model 2（中间斜率）与 Model 3（平滑近似）步长仅需 1 ms**；
- 平均计算耗时：Model 1 约 **1514 ms/s**，Model 2 约 **183 ms/s**，Model 3 约 **189 ms/s**（表2）；即 Model 1 耗时约为另两者的 **8 倍**；
- 三种方法都能与 **"翟"积分方法（Zhai 两步显式法，ref [22] Zhai1996）** 配合；
- 结论(3)：速度相关法**对相邻车辆速度差敏感**，速度剧烈变化会引起数值不稳定；另两者由**相邻车辆相对位移**控制，推荐中间斜率或平滑近似处理摩擦缓冲器的不连续问题。
- 结论(4)：速度相关法的最大缓冲器行程明显大于另两者，最高车钩力出现在**过渡区**。

## 7. 可迁移的方法

1. **三种过渡方法的公式结构**（式1-6）可直接作为本项目"查表速度过渡/中间斜率/平滑逼近"三种策略的**规范形式**。
2. **过渡策略选择依据**：速度相关法对相邻车速度差敏感、需 0.1–0.2 ms 小步长；中间斜率/平滑近似由相对位移控制、1 ms 即稳定 → 若本项目用相对位移驱动查表，**中间斜率或平滑近似更稳健**。
