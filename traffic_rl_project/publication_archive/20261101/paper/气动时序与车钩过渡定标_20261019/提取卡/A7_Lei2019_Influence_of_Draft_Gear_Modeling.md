## 3. 公式准确形式（经页面文本逐行核对）

**查表模型（式3-5）**：
```
F(x_t, v_t) = f_l(x_t),  x_t·v_t ≥ 0        …(3)
F(x_t, v_t) = f_u(x_t),  x_t·v_t ≤ 0
F(x_t, v_t) = F(x_{t−Δt}, v_{t−Δt}) + k·(x_t − x_{t−Δt})    …(4)
|f_u(x_t)| ≤ |F(x_t, v_t)| ≤ |f_l(x_t)|                        …(5)
```
其中 `θ`、`θ₀` 为当前步与上一步行程；`f_l`、`f_u` 为加载/卸载特性函数；**`k` 为过渡特性刚度（transitional characteristic stiffness）**。式(4) 算过渡曲线恢复力，式(5) 用加载/卸载曲线作边界条件修正。

**楔块-弹簧模型（式7）**：
```
F(x_t, v_t) = F_s(Δx)·tanθ/(tanθ − μ·v_t),  Δx ≥ 0
F(x_t, v_t) = F_s(Δx)·tanθ/(tanθ + μ·v_t),  Δx < 0
```
其中 `F_s(Δx)` 为非线性弹簧力；`θ` 为楔块角；`μ` 为摩擦系数；`Δx` 为缓冲器行程变化；`v_t` 为变形速度。

## 4. 对应优先问题 3（过渡刚度 k 与建模方法对比）

- **过渡刚度 k**：查表模型用**固定刚度 k** 处理加载/卸载之间的间隙（式4-5）。原文称查表模型的特性曲线"**沿固定轨迹移动，与缓冲器行程变化率无关**"（摘要行 38-39）。
- **楔块-弹簧模型**：阻抗力**取决于行程变化率**（变形速度 v_t），摘要称其"更符合试验结果、体现动态特性"（行 39-41）。
- 结论：**楔块-弹簧模型**在制动时间/最大车钩力上更接近试验；**查表模型**在制动距离上更接近试验（差异均不大）。
- **k 的具体定标数值：本文未给出**（仅给符号定义与作用）。

## 7. 可迁移的方法

1. **两种缓冲器建模方法的对比范式**：查表法（固定 k、与行程变化率无关）vs 楔块-弹簧法（依赖变形速度）。可用于判断本项目 MT-2 建模属于哪一类、以及过渡刚度是否应随速度变化。
2. **两车缓冲器串联为一个单元**（PDF p4）——与王学龙式(5.10) 一致的建模约定。
3. **车钩力分布规律**：两模型最大车钩力均出现在**列车中后部**（可作为本项目车钩力断面分布的定性参照）。
4. **下坡循环制动车钩力时程**分析窗口：空气制动前后 **250 s**。

## 8. 不可迁移的参数 / 结论

- 本文整列为 **"1+1" 2 万吨（主控+105 C80+从控+105 C80+可控列尾）**，与本项目 **1 机车 + 108 货车、约 10988 t 的 1+0 编组**不同；其 **170 kPa 全制动**参数**不可**直接移入本项目（本项目关注 50 kPa 常用减压）。
