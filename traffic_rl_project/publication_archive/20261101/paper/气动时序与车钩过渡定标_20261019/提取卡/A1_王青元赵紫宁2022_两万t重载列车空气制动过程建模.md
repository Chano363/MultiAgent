## 3. 公式的准确形式（经 300 dpi 页面图目视核对，图见 `_txt_paged/核对图/WangQingyuan-4.png`）

- **式(13)**：`K_{z,i}(t) = [ (t − t_{d,i}) / (T_1 + t_{Δ,i}) ]^{λ_z} · K_h`
- **式(14)**：`t_{m,i} = t_{d,i} + t_{Δ,i} + T_1`
- **式(15)**（分段，N 为车辆数，γ_z 为制动波波速特性参数）：
  - i ≤ N/2：`t_{d,i} = t_1 + [(t_N − t_1)/((N/2 − 1)^{γ_z})]·(i − 1)^{γ_z}`
  - N/4 < i ≤ N/2：`t_{d,i} = t_1 + [(t_N − t_1)/((N/2 − 1)^{γ_z})]·(N/2 − i)^{γ_z}`
  - N/2 < i ≤ N：`t_{d,i} = t_1 + [(t_N − t_1)/((N/2 − 1)^{γ_z})]·(i − N/2)^{γ_z}`
- **式(16)**（K_z 为制动缸充气特性参数，T_N 为第 N 辆车充气时长）：
  - i ≤ N/4：`t_{Δ,i} = [(T_N − T_1)/((N/2 − 1)^{K_z})]·(i − 1)^{K_z}`
  - N/4 < i ≤ N/2：`t_{Δ,i} = [(T_N − T_1)/((N/2 − 1)^{K_z})]·(N/2 − i)^{K_z}`
  - N/2 < i ≤ N：`t_{Δ,i} = [(T_N − T_1)/((N/2 − 1)^{K_z})]·(i − N/2)^{K_z}`

> 说明：式(13)~(16) 的分段区间在原文印刷中为 N/4、N/2 的嵌套判断；上式按原文页图逐项抄录。式(15)(16) 中的指数（γ_z / K_z）与分母 (N/2−1) 的幂次为原文形式。

## 4. 三段划分与计时起点的原文定义（对应优先问题 1）

原文（期刊页72~73）明确：

- **t0**：制动手柄动作时间。
- **t_{d,i}**：**第 i 辆车辆制动缸开始充气时间**。
- **t_{m,i}**：第 i 辆车辆制动缸充气结束时间。

三段边界：

1. **空走阶段**：`t ∈ [t0, t_{d,1})` —— "制动手柄动作 → **头部车辆制动缸开始充气**"，原文称"认定为常数不进行深入研究，取值参考文献[14]"。
2. **暂态阶段**：`t ∈ [t_{d,1}, t_{m,N}]` —— "**头部车辆制动缸开始充气 → 尾部车辆制动缸充气结束**"。
3. **稳态阶段**：`t > t_{m,N}` —— 列车管保压的有效制动发挥至缓解。

**关键结论（有原文依据）**：各车辆闸瓦压力的计时起点是**该车制动波到达时刻 t_{d,i}**，不是整步起点。式(13) 中时间量为 `(t − t_{d,i})`，且归一化分母为 `(T_1 + t_{Δ,i})`，即第 i 车的**有效充气时长 = T_1 + t_{Δ,i}**（首车充气时长 T_1 加上该车与首车的充气时间差）。式(14) 保证 t = t_{m,i} 时归一化量为 1、K_{z,i} = K_h，与式(7) 的连续性约束自洽。

## 7. 可迁移的方法（有原文依据，可用于本项目核对）

1. **充气计时起点**：以"制动波到达该车的时刻 t_{d,i}"为计时零点，而非积分整步起点。
2. **暂态段归一化**：闸瓦压力按 `(t − t_{d,i})/(T_1 + t_{Δ,i})` 归一化，幂次 λ_z 控制升压曲率；跨越波到达时刻时，分子应按剩余时间重算。
3. **分段节点**：空走段末端取**首车**开始充气时刻 t_{d,1}；暂态段末端取**尾车**充气结束时刻 t_{m,N}（即 t_{d,N} + t_{Δ,N} + T_1）。跨越到达、升压结束、排气结束应按这三类节点切分。
4. **连续性校验**：任何分段实现都应满足式(7)，即在 t = t_{m,i} 处 K_{z,i} 恰好等于稳态值 K_h，否则会出现原文所指"两段式模型在模式切换时制动力突变"的问题（期刊页72 结论①）。

## 8. 不可迁移的参数 / 结论

- 本文为 **2 万 t、1+1 双机车、108+108 辆 C80** 编组；本项目为 **1 机车 + 108 货车、约 10988 t** 的 1+0 编组，**不可**直接套用其 t_{d,i}、t_{Δ,i} 分段系数、γ_z、K_z 标定值。
- 式(4)(5) 的牵规闸瓦换算参数（K=20 kN 等）是牵规体系参数，不等同于本项目模型内部的闸瓦压力参数。
- 表1 的实车"缓解再充风时间"（175~512 s）属 2 万 t 1+1 编组、未给减压量，**不可**作为本项目 222 s 再充风时长的直接依据。
