## 3. 公式准确形式（经 300 dpi 页面图目视核对，图见 `_txt_paged/核对图/ZhouZhansonghi-05.png`）

- **式(5)**：`∂p_c/∂t = (nRT / (A_p · Z)) · Σ ṁ_i`
  - p_c 制动缸压力；n 理想气体多变指数（等温假设下 n=1）；R 气体常数；T 温度；A_p 制动缸截面面积；Z 制动缸活塞杆行程（容积可变）；ṁ_i 流入/流出制动缸的流量。
- **式(6)**：`P_c = (1 / Z_{t+dt}) · ( Z_t · P_{c0} + (dt · nRT · Σ ṁ_i) / A_p )`
  - P_c 为 t+dt 时刻制动缸压力；P_{c0} 为 t 时刻制动缸压力；Z_{t+dt}、Z_t 分别为 t+dt、t 时刻行程。
  - 原文：**"将式(5)以时间步长 dt 的间隔离散，可得到制动缸压力的迭代计算公式如式(6)"**；制动缸活塞杆运动"基于运动学方程**采用一阶欧拉积分**"。

## 4. 与优先问题 1 相关的原文结论

- 制动缸压力采用**一阶欧拉显式离散**（式6），离散步长为 **dt**。
- 原文验证精度：**压力响应时间误差小于 0.5 s，峰值压力误差小于 10 kPa**（PDF p5）。
- 制动波/充气时序相关数值：常用制动减压 50 kPa 时，三种编组的**制动波传递至尾车处波速**分别为 250.3 / 241.8 / 236.7 m/s（C64 / C70E / C80，PDF p8）；制动缸出闸延时随车辆位近似线性增长（三种编组制动延时 6.96 / 6.86 / 5.52 s，PDF p8）；缓解时间在前 50 辆线性增长、50 辆后呈非线性，最大缓解时间 11.50 / 10.48 / 7.92 s（PDF p8）。
- **原文未给出 dt 的具体数值**，也**未给出**步长敏感性/时间收敛检验。

## 6. 参数值与单位、坐标定义

- 单位：压力 kPa；时间 s；波速 m/s；流量系数无量纲。
- 式(3) 流量系数 C_q 为 p_out/p_in 的五次多项式（系数 0.814、−0.1002、0.8415、−3.9、4.6001、−1）。
- 式(4) 修正系数 C_m 的分界压力比 **p_out/p_in = 0.528**。
- **坐标定义**：图2/图3 为**压力—时间**曲线（纵轴压力/kPa，横轴时间/s），标注"列车管"与"制动缸"两条曲线，含"试验"与"仿真"两组数据。本卡涉及的是**制动缸压力—时间**关系，**不是**缓冲器力—位移曲线。

## 7. 可迁移的方法

1. **制动缸压力一阶欧拉离散**（式6）：容积可变 Z 的处理方式（`Z_{t+dt}` 在分母、`Z_t·P_{c0}` 在分子）可作为本项目压力更新的离散参照。
2. **节流孔流量—压力比修正**（式2~式4）：多腔室（副风缸/加速缓解风缸/紧急风缸/制动缸）结构的分腔建模思路。
3. **验收量级参照**：压力响应时间误差 < 0.5 s、峰值压力误差 < 10 kPa。
4. **头车/尾车对比范式**：图2 同时给出 1 位与 116 位货车曲线，可作为"头/中/尾车"核对的组织方式。

## 8. 不可迁移的参数 / 结论

- 本文为**万吨编组（C64/C70E/C80，116 辆货车级）**，与本项目 **1 机车 + 108 货车、约 10988 t** 编组不同；其制动波速（236.7~250.3 m/s）、出闸延时（5.52~6.96 s）、缓解时间（7.92~11.50 s）**不可**直接移入本项目。
- 制动缸稳态压力 140 / 471 / 470 kPa 属该文设定（定压 600 kPa、管径 32 mm），本项目列车管定压与减压量须自行核对。
- 图2/图3 的曲线为**图中读数**，本卡**未**做数字化取点；如需取点须声明标尺与读数误差并保留核对图。
