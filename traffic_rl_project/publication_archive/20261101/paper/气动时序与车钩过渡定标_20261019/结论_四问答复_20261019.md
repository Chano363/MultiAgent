# 结论 — 气动时序与 MT-2 过渡定标（2026-10-19）

> 本文件只回答任务要求的四个问题。**未取得原文依据的内容一律标注"仍缺/未知"，不把"搜到论文"等同于"修复已成功"。**
> 证据来源为 D 盘既有原文（见 `检索记录/检索记录_20261019.md` 与 `提取卡/A1–A8`）；本批文献均**未**通过 MIS 机构通道在线检索取得（如实声明见检索记录）。

## 一、现有代码的跨步计时 / 压力更新应如何核对

现有实现为"**按区间递减波传播延迟 → 判定到达后累计升压 → 持区间制动力推进机械**"。核对建议（每条均可落到具体检验）：

1. **计时零点核对（最优先）**
   - 逐车核对：该车闸瓦压力/制动缸压力的**计时零点是否为该车的制动波到达时刻 td,i**，而**不是积分整步起点**。
   - 依据：王青元/赵紫宁三段式模型（`提取卡 A1` 式(13)；`提取卡 A8` 式(3-11)）明确压力按 `(t − td,i)/(T1 + tΔ,i)` 归一化，分子时间量从 td,i 起算。
   - 检验方法：对同一算例，人为把计时零点从"整步起点"改为"波到达时刻 td,i"，观察首车/尾车压力曲线相位是否前移；若相位无变化，说明代码未真正用 td,i 计时。

2. **跨步到达的亚步核对**
   - 核对当**波到达时刻 td,i 落在某个积分步内部**时，该步内的**有效充气时长**是否按 `(t − td,i)` 重算（即只计入该步中波到达之后的那段时间），而非按整步计时。
   - 依据：A1 式(13) 的分子为 `t − td,i`；跨步到达时分子应按剩余时间重算（`提取卡 A1` 第7节）。
   - 检验方法：把波到达时刻人为设在步内不同相位（如步长的 0%、25%、50%、75%），看该步升压增量是否随相位线性变化；若不变，说明存在"整步计时"离散误差。

3. **三类分段节点的连续性核对**
   - 空走段末端节点：**首车开始充气时刻 td,1**；暂态段末端节点：**尾车充气结束时刻 tm,N = td,N + tΔ,N + T1**；稳态段起点：`t > tm,N`。
   - 依据：A1/A8 明确三段边界为 `[t0, td,1)`、`[td,1, tm,N]`、`t > tm,N`（`提取卡 A1` 第4节；`提取卡 A8` 第2节行 988-994）。
   - 连续性条件：任意车在 `t = tm,i` 处闸瓦压力应恰好等于稳态值 `Kh`（A1 式(7)），否则会出现"模式切换时制动力突变"（A1 结论①、A8 局限①②）。
   - 检验方法：在 td,1、tm,i、tm,N 三类节点前后各取半步，检查压力/制动力是否出现非物理跳变。

4. **压力更新的离散方式核对**
   - 现有"到达后累计升压"是否为**一阶欧拉显式离散**；若是，核对容积可变项的处理（`Z_{t+dt}` 在分母、`Z_t·P_c0` 在分子）。
   - 依据：周占松（`提取卡 A2` 式(5)(6)）给出一阶欧拉离散形式；但其**未给出 dt 数值**。

5. **步长收敛检验（本项目须自行完成）**
   - 现有文献**均未给出**气动压力更新的步长敏感性/时间收敛检验（A1/A2/A3/A8 的"缺失数据"节均记"未给出"）。因此**本项目必须自建**收敛检验：
     - 在**压力更新时间步长**上细化（如 0.01 → 0.005 → 0.0025 s），观察力差是否随步长减半而按阶收敛；
     - 在**机械积分步长**上细化（0.0003125 → 0.00015625 s）作对照（已做，力差约 3.13 kN）；
     - 同时分离坡度/速度相关制动力，**不要把细化引起的全部差异简单归因于某一个气动参数**（与任务给定判断一致）。
   - 判据：若细化后力差**单调减小并趋于稳定**，则当前时间离散可接受；若**不收敛**，再定位是波到达的亚步处理还是升压函数本身的问题。

> **注意**：现有已测的"气动/控制力更新时间 0.01 vs 0.005 s → 力差 90.28 kN、0.005 vs 0.0025 s → 仍差 45.79 kN"表明**差异随步长减小并未快速收敛**，提示问题更可能在**跨步到达的亚步计时**（第2条），而非单纯步长不足。

## 二、哪种处理有原文依据

以下处理**有明确原文依据**（附出处），可直接作为核对基准：

| 处理 | 原文依据 | 出处 |
|---|---|---|
| 压力/闸瓦压力**从波到达时刻 td,i 计时** | 式(13) `Kz,i(t)=[(t−td,i)/(T1+tΔ,i)]^λz·Kh` | A1 第3、4节 |
| **三段划分**：空走 `[t0,td,1)`、暂态 `[td,1,tm,N]`、稳态 `t>tm,N` | 三段式模型定义 | A1 第4节；A8 第2节（行 988-994） |
| **连续性约束** `Kz,i(tm,i)=Kh` | 式(7) | A1 第3节 |
| **制动缸压力一阶欧拉离散**（容积可变） | 式(5)(6) | A2 第3节 |
| **历史缓解时间影响本次制动力**（缓解不充分 → 制动力变弱） | 修正函数 Ps(t)、影响因子 Ls | A8 第7节；A1 式(8)~(12) |
| **两缓冲器串联换算**：单只压缩量 = 相对位移/2、单只压缩速度 = 相对速度/2 | 式(5.10)(5.11) | A5 第3、4.1节 |
| **相邻两车缓冲器串联为一个单元**建模 | "draft gears of two adjacent vehicles are modeled in series as one unit" | A7 第5节（PDF p4） |
| **中间斜率过渡**：`F(t)=F(t−Δt)+k·(x_t−x_{t−Δt})`，边界 `|f_u|≤F≤|f_l|` | 式(3)(4)(5) | A6 第3节；A7 第3节 |
| **平滑近似过渡**：`F=f_l+(F(t−Δt)−f_l)·exp(−|x_t−x_{t−Δt}|/α)` | 式(6) | A6 第3节 |
| **速度相关过渡需更小步长（0.1/0.2 ms），中间斜率/平滑近似 1 ms 即可** | 结论(2) | A6 第5节 |

**没有原文依据、或依据不足的处理**：

- **用更多规则阈值掩盖时间离散问题**——本批文献**无**此做法，原文均以分段节点 + 连续性约束处理，不用阈值堆叠。
- **把 222 s 再充风当作与编组/减压量无关的常数**——文献表明再充气时间随**编组方式**和**减压量**显著变化（A4：50 kPa 时 3+0/2+1+0/1+1+1 = 114/72/28 s；110 kPa 时 = 245/162/70 s；1+0 与 2+1+0 在 110 kPa = 387/162 s）。**222 s 的来源在本批文献中未取得直接依据**。
- **把本模型缓冲器刚度改一半**——**无依据**。正确做法是位移/速度**口径 ÷2**（A5 式5.10/5.11），且前提是两车缓冲器特性近似相同（A5 第7节）。

## 四、是否确有必要更换物理规律

**结论：目前没有依据要求更换物理规律。**

理由（仅限有依据部分）：

1. **现有离散化方向与文献一致**：现有"波传播延迟 + 到达后计时 + 分段"的思路，与文献的"td,i 计时 + 三段划分 + 连续性约束"（A1/A8）**同向**，并非被文献否定的做法。
2. **文献本身也没给出可直接套用的收敛判据**：A1/A2/A3/A8 均**未做**步长敏感性/时间收敛检验；A3 的 0.05 s、A2 的 dt 都是工程设置而非收敛结论。因此**不能**用文献来判定本项目"步长已足够"或"必须换物理规律"。
3. **当前差异的指向**：0.01→0.005→0.0025 s 的力差（90.28 → 45.79 kN）**收敛缓慢**，且任务已明确"坡度隔离后主要差异仍存在、不能简单归因于某一个气动参数"。这更像**跨步到达的亚步计时/分段实现**问题，而非"物理规律错误"。
4. **建议的处置顺序**：
   - 第一步：按本文件第一部分做**跨步计时与三类分段节点的实现核对**（不改物理规律）；
   - 第二步：自建**步长收敛检验**（压力更新时间步长与机械积分步长分别细化），得到收敛证据；
   - 第三步：**只有在收敛证据显示实现无误、且差异仍大**时，才评估是否引入更细的气动模型（如 A2/A3 的多腔室节流孔模型、A4 的气体流动模型）。
5. **明确保留未知项**：vε、k、α、dt、222 s 来源、1+0/108/50 kPa 专门曲线均**仍缺**；在这些数据补齐前，**不得**宣称"更换物理规律即可修复"，也不得把"搜到论文"当作"问题已解决"。
