## 三、模型与约束（原页）

### 3.1 目标函数（印刷页 72—73）

J = w_f（平稳性）+ w_e（能耗）+ w_v（速度追踪）

- 能耗项含 η_t（牵引传动机电效率）、η_eb（**再生制动系统机电效率**）与 E_i、E_r,i（当前/目标速度对应动能）
- 平稳性以纵向动力学模型解算的车钩力分布表征

### 3.2 能力边界约束（式(4)，印刷页 73）

```
0 ≤ F_t,i ≤ F_t,max(v)
0 ≤ F_eb,i ≤ F_eb,max(v)
0 ≤ B_c,i ≤ B_c,max(v)
|F_t,i − F_t,i−1| ≤ ΔF_t
|F_eb,i − F_eb,i−1| ≤ ΔF_eb
F_t,i · F_eb,i = 0
```

其中：ΔF_t 为机车牵引力变化率，ΔF_eb 为**机车电制动力变化率**。

> **ΔF_eb 的数值原文未给出。** 全文只出现符号与不等式形式，未列 kN/s 或 kN/步的具体限值。这是本轮回答“ED 变化率是否有依据”时最直接的缺口。

### 3.3 运行边界约束（式(5)，印刷页 73）

```
0 ≤ v_i ≤ v_lim,i
F_t,ne = F_eb,ne = 0   （分相区）
```

### 3.4 空电解耦方法（印刷页 73）

> 「由于空气制动力难以精确施加控制……将空气制动力按照模式化操纵规则，**转化为随空间分布的已知控制力**，则长大下坡的列车运行优化问题转化为基于模式化空气制动的电制动操纵优化问题。」

即：**先把空气制动力当作已知量（按模式化规则给定），再优化电制动**。这与本项目“空气源保持、调整 ED 跟随”的做法在结构上同源。

算法：空气制动力初值 B_c0（按目标速度 v_r 计算）→ 代入二次规划求解 → 用优化速度曲线重算 B_c → 迭代至收敛；以式(7) 判敛散性（印刷页 73—74）。

### 3.5 量化后的操纵规则（印刷页 74，**本卡最关键的一段**）

原文：

> 「根据朔黄铁路重载列车长大下坡区段安全操纵准则，在操纵优化模型中电制动增加以下约束条件：
> ① 空电联合制动时，若列车实际速度与目标速度偏差过大，仅调整列车电制动力保证列车速度跟踪性；
> ② 列车循环制动时，**若列车开始缓解，则维持恒定电制动力 50 s**。」

| 规则 | 内容 | 是否给出数值 |
|---|---|---|
| ① | 速度偏差大时只调电制动、不动空气制动 | 定性 |
| ② | **缓解开始后维持恒定电制动力 50 s** | **给出：50 s** |

> 这是本轮唯一找到的、**明确写出“缓解后 ED 保持时长”数值**的文献。其依据被表述为「朔黄铁路重载列车长大下坡区段安全操纵准则」，但**原文未给出该准则的文件名、编号或条款**，也未说明 50 s 的推导过程。

> 2. 区段 73.1—77.7 km 与本项目关注的北大牛—原平南（约 73—77.5 km）高度重合，说明案例线路很可能就是朔黄线同一区段。但原文未明写线路名，**不据此断言**。

## 五、对本项目的可用性判定

### 可直接采用的同工况参数

**无。** 编组、辆数、质量、坡度、阀型、减压量全部未给出，无法判定同工况。

### 仅可迁移的方法

1. **「空气制动力作为已知控制力 → 只优化电制动」的解耦框架**。与本项目“保持空气源、调整 ED”的做法同构，可作为方法出处引用。
2. **缓解后维持恒定 ED 一段时间**这一规则形式（数值 50 s 不可直接搬，但“缓解瞬间不让 ED 立刻退出”的机制可借鉴）。
3. **ΔF_eb 以不等式约束进入优化**的写法——即使无数值，也说明“电制动变化率应作为显式约束”这一建模习惯在朔黄体系内成立。
4. **以车钩力分布作为平稳性指标**的评价方式。

### 不可迁移或证据不足

1. **50 s 不能直接写成本项目参数**：对象是 2 万吨（辆数未给出），本项目为 1+0、108 辆、10 988 t；且原文未给准则出处。
2. **ΔF_eb 无数值**，不能声称“已有变化率依据”。
3. **无任何热负荷内容**，不能用来回答 404 s 持压是否过热。
4. **优化后压钩力仍 1020.3 kN**，不能作为“本项目可做到 ≤1000 kN”的证据。
5. **未给编组**，不能按吨位比例折算到 108 辆。
