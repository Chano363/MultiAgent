## 三、热相关模型：S_tmp 与 P(t)

### 3.1 结构（论文第 20 页，式(3-6)~(3-10)）

```
P_s(t) = L_s + (1 − L_s) / (1 + exp(−λ_s (T_BRA − Q_off)))        (3-6)

L_s = (T_REL_Last / T_REL_Set)^K_s                                 (3-7)

Q_off = k_s (S_tmp + b_s)                                          (3-8)

b_s = a_0 L_s² + b_0 L_s + c_0                                     (3-9)

S_tmp = a_1 · e^(c_1 t) − b_1 · e^(d_1 t)                           (3-10)
```

变量（原文第 20—21 页）：

| 符号 | 含义 | 单位 |
|---|---|---|
| λ_s | 修正函数单调特性参数 | 无量纲 |
| T_REL_Set | 常用制动减压量下**缓解充风至标定管压所需的时间** | s |
| T_REL_Last | **上一个制动段的缓解时间** | s |
| T_BRA | **本制动段的制动时间** | s |
| L_s | 历史缓解时间对空气制动的影响因子 | 无量纲 |
| K_s | L_s 的特性参数 | 无量纲 |
| **S_tmp** | **闸瓦的温度曲线**（文献[50] 中**调速制动工况**闸瓦温度与制动时间关系的拟合曲线） | ℃ |
| a₁、b₁、c₁、d₁ | 常数 | — |
| Q_off | 闸瓦温度对空气制动的影响因子，与 S_tmp 成线性关系 | 无量纲 |
| k_s | Q_off 特性参数 | — |
| b_s | 历史缓解时间与闸瓦状态的关联因子 | — |
| a₀、b₀、c₀ | 常数 | — |

> 用户提示「不把段间 C_β 表当完整热模型」——**完全正确**。表 5-5 是按**制动段序号**（1/2/3）查表的离散修正，其 k_s 甚至出现负值（第 2、3 段），说明它是**拟合出的等效修正量**，不是物理温度。它没有温度状态、没有冷却过程、没有跨周期记忆，只有「上一段缓解时间 / 本段制动时间」两个比值型输入。

### 3.4 连续性约束（论文第 20 页，式(3-5)）

```
K_z,i(t)|t=t_m,i = K_h,i
```

即闸瓦压力在充气结束时刻与稳态值衔接。这说明模型在**单段内**保证连续，但**段与段之间只通过 P_s(t) 的标量修正传递**，不传递温度状态。

## 五、对本项目的可用性判定

### 可直接采用的同工况参数

**无。**

### 仅可迁移的方法

1. **「把热历史压缩成一个标量修正因子」的建模思路**：P_s(t) 只依赖 (T_REL_Last / T_REL_Set) 与 (T_BRA − Q_off) 两个组合量，计算量 O(1)。这正是本项目“低成本热负荷代理指标”的现成范式。
2. **充风时间与晾闸时间在同一函数里耦合**：T_REL_Set（充风所需）与 T_REL_Last（实际缓解时长）做比值，比值越大制动性能越接近满值。这直接回答了“充风与晾闸是否不同”——**在该模型里二者是同一个时间段的两种解释，用比值区分**。
3. **修正函数单调性方向**：缓解时间越长 → 闸瓦温度越低 → 制动性能越强（论文第 21 页明确论述）。
4. **参数辨识流程**（遗传算法 + 实车速度曲线拟合），可用于本项目若要标定自己的 k_s。

### 不可迁移或证据不足

1. **a₁、b₁、c₁、d₁ 无数值**，无法复现 S_tmp，也无法据此计算任何温度。
2. **表 5-5 的 k_s 出现负值**，说明其为等效拟合量，**不能解释为温度系数**，更不能反推 ℃。
3. **2 万吨参数不可迁移**到 1+0、108 辆、10 988 t。
4. **本模型无冷却项**：缓解期只通过 T_REL_Last 影响下一段的初始修正，**没有显式的散热/降温动力学**。因此它**不能**用来判断“404 s 持压后闸瓦温度是多少”。
