## 四、核心公式（PDF页2—3 = 印刷页51—52）

**式(1)(2) 运动学方程**：dv/dx = [μ_t·f_t(v) − μ_d·f_d(v) − μ_m·f_m(v) − w_0(v) − g(x)] / v；dt/dx = 1/v
式中：f_t 牵引力；f_d 电阻制动力；f_m 减压量50kPa时制动力；w_0 基本阻力；g(x) 附加阻力（坡道+曲线）；μ_t、μ_d 为[0,1]连续控制量，μ_m∈{0,1}（空气制动二元）。

**式(6)(7) 约束**：v(x) ≤ V(x)（限速）；μ_m·f_m(v) + w_0(v) + g(x) > 0（施加空气制动都能停车）。

**式(8) 充风约束（核心）**：**t_z ≥ T_c**
- t_z = 相邻两次空气制动的间隔时间（增速时间），s
- T_c = 施加空气制动后列车缓解再充风时间，s
- 文字表述："若列车运行于长大下坡区间，需要连续施加空气制动，为保证相邻两次空气制动的制动力不发生衰减，则列车在长大下坡道上的增速时间应不小于副风缸充风时间"。出处标注[1]（孙中央）。

**命题（2.1节，PDF页3=印52）**：列车在长大下坡区间进行空气制动，**当且仅当实际缓解速度不大于列车缓解速度 v'lim(x) 时，即 v(x) ≤ v'lim(x)，周期性制动有最优解**；且 v'lim(x) 满足"T_c 时间内列车由 A 点全力电制动到限速"。

**式(14) 时间—速度转化**：t_z = ∫_{xA}^{x'} 1/v(x) dx ≥ ∫_{xA}^{xB} 1/v'(x) dx = T_c
（证明：反证 v_lim(x) > v'_lim(x) 则全电制到限速时间 < T_c，副风缸充风不足——即缓解速度偏高直接违反充风约束。）

**表1 伴随变量—工况（PDF页4=印53）**：θ>1 全力牵引 FP；θ=1 部分牵引 PP；0<θ<1 惰行 C；θ=0 部分制动 PB（长大下坡区间特判为全力电制动）；θ<0 全力制动 FB（μ_t=0, μ_d=1, μ_m=1）。

## 五、关键结论（原文明写）

1. 长大下坡区间应采用周期性循环制动策略；**最优缓解速度是副风缸缓解再充风时间约束边界值对应的速度 v'lim(x)**（结论(1)）。
2. 长大下坡增速阶段应采用**全力电制动**；下坡末端车速为限速、工况为全电制（结论(2)）；出坡后转全力牵引（情况二/三）。
3. 区间运行时间充足时，接近长大下坡应提前惰行；**第一次制动位置由长大下坡末端工况反算决定，其余制动位置均在限速处**（结论(3)）。
4. 升速阶段"全力电制"比"全力牵引+部分电制"更优（平均速度更高→T_c 窗口更长；且避免低速缓解和全制转全牵的纵向冲动），（2.2节(4)）。
5. 工况切换注意（5.2节）：过大的牵引/制动力及变化率会造成纵向冲动甚至断钩；需对手柄建立时机、级位切换时机进行工程修正（起车 ≤3 km/h 缓慢行驶至车钩拉伸）。

## 七、对项目问题的直接回答（标注证据性质）

1. **问题 A（缓解速度—充风时间—坡道增速—再制动压力建立的联合条件）**：原文给出解析判据 v(x) ≤ v'lim(x)（v'lim 定义为 T_c 时间内全电制到限速对应的缓解速度）与式(8) t_z ≥ T_c、式(14) 积分形式。证据性质：**原文明写**。这直接对应本项目"缓解后 209.5 s 超速 vs 222 s 充风"矛盾——按该判据，缓解速度必须低到使"全电制到限速时间 ≥ 充风时间"才能保证下次制动压力充足。注意其 T_c=46 s、编组 50 辆，数值不可直接套用，但判据形式可迁移。
2. **问题 B（缓解后 ED 如何变化）**：该文策略是缓解后施加**全力电制动（FEB）**直到限速再转全制，即"全电制→全制"周期切换，没有"先减后增"的 ED 时序公式；并明确"全力牵引+部分电制动"组合会导致低速缓解与纵向冲动。证据性质：**原文明写**（非逐车纵向模型，无 kN 级 ED 幅值时序）。
3. **问题 C（50 kPa 沿列建立）**：该文以 f_m(v) 为减压量 50 kPa 的整列制动力建模，二元开关量，**不逐车建模压力传播**（多质点模型但刚性连接、无车钩力、无逐车充风延迟）。证据性质：**原文明写**（未覆盖部分）。
4. **问题 D（50/222 组合依据）**：本文未研究 108 辆、222 s；其 46 s 充风、50 辆编组不能支持本项目 222 s 设定。**无直接依据**（研究者推断）。应验证变量：缓解速度、坡道增速（坡度分布）、充风时间三者是否满足式(8)/命题。
5. **问题 E（列尾充风）**：未涉及可控列尾或尾部主动充风；充风约束针对全列副风缸压力恢复，无 EOT 建模。证据性质：**原文明写未涉及**。

## 八、局限性（研究者说明）

- 5000 t 级仿真（SS6B+50），结论"可用于万吨"为作者推断
- 无车钩力约束（刚性连接假设），无逐车充风传播/压力建立模型，无 EOT 区分
- T_c=46 s 为给定常数，无减压量分段公式
- 提供的是存在性/最优性条件与数值算法，未给出缓解速度—坡道增速的显式解析式（坡道增速隐含在 v'lim 的积分定义中）
