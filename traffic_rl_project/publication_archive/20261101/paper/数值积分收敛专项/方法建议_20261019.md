# 方法建议（数值积分收敛专项，2026-10-19）

> 目的：给出**可在本项目验证**的非线性求解与步长误差处理方法，用于判断"关键窗口 1599 步中 1475 步未满足位移准则仍推进"是否影响力峰结论。**这些建议不保证任何步长必定通过 1000 kN**；验收仍以 1000 kN 绝对断面力、80 km/h 上限、约 40 km/h 下界、222 s 再制动等待为准，本专项不改这些指标。
>
> 所有建议均为**方法层面**，不修改生产代码、不改物理参数、不推送仓库；先以"同工况冻结候选 + 独立细步参考"做验证。

## 一、先分清两类误差，分别度量

1. **非线性迭代误差**：每步内松弛固定点迭代未收敛（当前位移准则 1e-5 m、最多 30 次）。度量：每步残差范数、未收敛步计数与占比。
2. **时间离散误差**：步长本身带来的误差。度量：与更小步长的**细步参考解**对比。
3. 二者**不可互相替代**；线性无条件稳定结论**不能**当作非线性收敛证明。

## 二、可复现的细步参考网格（同一力/坡度序列）

- 固定**相同的力和坡度序列**（不回放历史状态、不拼 NPZ 复原），逐级细化内部步长，例如 0.01 → 0.005 → 0.002 → 0.001 → 0.0005 s。
- 每级记录并对比：**力峰（峰值与出现时刻）**、**力时程误差**（L∞ 与 L2 范数）、速度包络、车钩位移幅值。
- 判据：当细化到某步长时，力峰与峰值时刻的相对变化进入稳定带（如 ≤ 设定百分比），方可称"该窗口力峰已收敛"。**未收敛前不得据单一步长下结论。**

## 三、容差与迭代上限的敏感性

- 在细步参考基础上，扫描位移准则（如 1e-5 → 1e-6 → 1e-7）与迭代上限（如 30 → 60 → 100），记录：
  - 未收敛步数与占比如何变化；
  - 力峰、峰值时刻是否随之变化。
- 目的：判断"1475/1599 步未达准则"是**迭代不足**还是**准则过严/物理本身抖动**，而非直接推进。

## 四、不收敛后的动作（而非继续推进）

- 对未收敛步采用**子步细分 / 步长回退并重算该步**，记录回退次数与回退后是否收敛。
- 明确并**核对**回退/迭代时是否**重算有记忆的力学/气动状态**（摩擦迟滞的加载-卸载分支、制动缸/副风缸压力等），避免回退后状态不一致——这是本项目尤其要检查的点（当前模型未显式模拟完整副风缸再充风动态）。

## 五、迟滞过渡与力峰/相位的敏感性

- 参照 Zhou2022 的三类过渡策略（速度相关 / 中间斜率 / 平滑近似），在本项目 MT-2 模型上做**过渡参数敏感性**，观察力峰与相位变化。
- **不照搬**其 0.1/0.2 ms 或 1 ms 步长，也不照搬其过渡参数；先判断模型与积分器是否可比，再决定是否借鉴。

## 六、积分器实现的基准对照

- 用 Wu2018 / Spiryagin2017 / Zhou2022 的**国际基准算例**（共同输入、初始状态、车钩位移/速度/力、力峰位置与时刻、误差指标）验证本项目积分器实现是否正确。
- 基准通过 ≠ 本项目物理正确；基准用于排除**实现错误**，本项目力峰仍需实测/细步参考校核。

## 七、缓解预测的速度/力裕量（与本专项衔接）

- 本专项**不改变**缓解可行性判据：仍按"当前线路、受保护 ED 能力下的最大允许缓解速度 ∩ 最低允许缓解速度"，若无交集，**如实报告该位置不具备缓解条件**，而不是无限降低速度或用放宽准则掩盖。
- 数值收敛结论只用于**提高力峰可信度**，不用于替代车钩力验收。

## 八、验证顺序（可跨模型迁移 / 不可迁移）

1. 先修**实现错误**（若基准对照暴露）——可跨模型迁移。
2. 再做**本模型**细步参考与容差敏感性——结论只对本模型/本项目成立。
3. 迟滞过渡策略与步长的**具体数值**——**不可**跨编组、跨车型迁移。
4. 只有在本项目细步参考下力峰稳定，才可据此判断候选是否满足 1000 kN；否则应报告"该窗口力峰未收敛、结论待定"。
