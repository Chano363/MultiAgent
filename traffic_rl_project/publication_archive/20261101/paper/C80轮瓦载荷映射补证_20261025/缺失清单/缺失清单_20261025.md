## P0：直接决定「405.7 s 持压是否合理」能否判定的四项

### P0-1 单块闸瓦接触斑面积 S_patch 与闸瓦包角

| 项 | 内容 |
|---|---|
| 缺什么 | C80 单元制动装置单块闸瓦与踏面的**实际接触斑面积**（m²）与**包角**（°） |
| 为什么需要 | 闸瓦热流 q_s = a·P_i/S_patch，S 取错 9 倍，q 就差 9 倍，温度结论随之全错 |
| 现状 | 6 篇原文均未给出；李广 2026 只给按 TB/T 3104.1—2020 的示意图；周高伟 2026 给的 224 196 mm² 是**轮周接触环面积**，不是接触斑 |
| 获取途径 | ① TB/T 3104.1—2020《机车车辆闸瓦 第 1 部分：合成闸瓦》原文（标准全文库，**需用户手动**）；② C80 制动装置图纸或厂家资料；③ 项目方台架/实车印痕测量 |
| 缺失时影响 | 无法给出闸瓦热流的绝对值；只能用「相对升温趋势」比较，不能给峰值温度 |
| 临时处理 | 参数证据表按包角 40° 假设给出 S_patch ≈ 0.0249 m² 的**示例值**，已明确标注为假设，不得作为证据引用 |

### P0-2 120 阀 50 kPa 减压对应的制动缸压力与单块闸瓦力

| 项 | 内容 |
|---|---|
| 缺什么 | C80 装 120 型分配阀、列车管定压（500/600 kPa）、**50 kPa 减压**下的：制动缸压力时程、制动缸升压/缓解时间常数、单块闸瓦法向力 |
| 为什么需要 | ① 校核模型有效制动力是否物理可实现（力上限）；② 若要用非均匀接触压力模型，必须输入真实接触压力 |
| 现状 | 徐超 2020 只有静态点：142 kPa→19.3 kN（空车）、396 kPa→80.0 kN（重车），且**未写对应减压量**；周高伟 2026 的「600/70/130 kPa→3/7 kN」是 70 t 级货车，不可用 |
| 获取途径 | ① 120 阀特性试验报告/《铁路货车制动装置》类专著；② 知网检索「120 型分配阀 制动缸压力 减压量」；③ 项目方静态试验 |
| 缺失时影响 | 无法判断 50 kPa 档在模型中对应的力是否偏高；也无法把热流结果换算回缸压口径 |
| 临时处理 | 用徐超 396 kPa→80 kN 作为**重车上界锚点**；50 kPa 档的力不填，不插值、不外推 |

### P0-3 闸瓦热量分配系数在本项目工况下的确认

| 项 | 内容 |
|---|---|
| 缺什么 | C80 实际闸瓦牌号在 40—80 km/h、20 kN 级载荷、长持压条件下的热量分配系数 a |
| 为什么需要 | a 直接线性缩放闸瓦热流；2% 与 10% 相差 5 倍，结论可能反转 |
| 现状 | 两派冲突：李广 2026 实测反标定 **2%—6%**（LH2 2.2%—6.2%，LH1 2.1%—3.4%）；肖绯雄/陈旭 2014 转引 **10%**（文献[9]，2010 年，无实测）；范文明 2025 计算值 **9%**（材料物性，非实测） |
| 获取途径 | ① 台架实测闸瓦温度反标定（李广方法可复现）；② 查李广 2026 引用的 TB/T 3104.1 与本项目闸瓦牌号对应关系 |
| 缺失时影响 | 闸瓦温度可能被高估或低估数倍；车轮温度影响相对小（94%—98% 对 90% 差 4—8 个百分点） |
| 临时处理 | 以 2%—6% 为主区间、10% 作敏感性上界，**不取平均**；报告中必须写明该选择 |

### P0-4 闸瓦与车轮的「允许温度 / 允许持续时间」标准原文

| 项 | 内容 |
|---|---|
| 缺什么 | 是否存在标准规定的闸瓦/车轮运用温度限值或最长持续制动时间 |
| 为什么需要 | 没有限值就没有「合理/不合理」的判据；现在所有阈值都是转引或代理 |
| 现状 | 900 ℃（TB/T 2403—2010 热失重考核温度，被「暂以」作上限）；300 ℃（转引 Handa，Wear 2020）；400 ℃（转引 Walia，2018）；36 MPa（闸瓦压缩强度）；1 cm³/MJ（磨耗率）——**均非运用限值** |
| 获取途径 | ① TB/T 2403—2010 全文（标准全文库，**需用户手动**）；② TB/T 1407.1—2018《列车牵引计算规程》；③ 铁路货车运用维修规程 |
| 缺失时影响 | 只能做「相对比较」，不能给「是否超限」的验收结论 |
| 临时处理 | 报告中只写「参照 300 ℃ 软化阈值与 900 ℃ 热失重考核温度作量级比较」，不写「超限/合格」 |

## P1：影响定量精度，但不改变定性方向

### P1-1 闸瓦牌号与摩擦系数 μ(v, T, P)

| 项 | 内容 |
|---|---|
| 缺什么 | C80 装车闸瓦的具体牌号；μ 随速度、温度、法向压力的变化曲线 |
| 现状 | 仅知「LH1 / LH2 高摩合成」；唯一实测点是陈建平 2025 的 **μ = 0.298**（LH2/CL60，1.5 kN，95 r/min），载荷低一个量级 |
| 获取途径 | 闸瓦厂家型式试验报告；知网「高摩合成闸瓦 摩擦系数 速度」；TB/T 3104.1 附录 |
| 影响 | 影响力上限校核与「制动力是否可实现」的判断；若走功率路径（§1），不影响热流主链 |
| 临时处理 | μ 取 0.298（注明条件）与 0.35—0.45 做区间，仅用于量级校核 |

### P1-2 车轮/闸瓦换热边界实测

| 项 | 内容 |
|---|---|
| 缺什么 | 环境风速（列车风）、低速段（<20 km/h）对流系数、闸瓦背面与侧面的分区换热系数 |
| 现状 | 车轮有经验式 h = 0.3828 + 14.39v（范文明）；闸瓦有自然对流 22.713（李广台架）与 1.32(ΔT/L)^0.25（陈建平室内）；肖绯雄给 74.2/54.3/34.2 但未说明口径；**均无现场实测** |
| 获取途径 | 实车/台架热电偶+风速同步测量；知网「车轮 对流换热系数 试验」 |
| 影响 | 长时程（400 s 级）散热占比大，对流系数误差 30% 可造成峰值温度误差 10%—20%（量级估计，非文献值） |
| 临时处理 | 用范文明式(12) 作基准，肖绯雄 34.2—74.2 做区间 |

### P1-3 制动力沿 108 辆车的分布与偏载范围

| 项 | 内容 |
|---|---|
| 缺什么 | 列车管压力波沿 108 辆的传播导致的**前后车制动缸压力差**、闸瓦力不均系数 |
| 现状 | 本轮 6 篇均未涉及；徐超 2020 仅指出速度 >30 km/h 时轮瓦出现异常间歇接触（p27 第 3 章） |
| 获取途径 | 项目自身的空气传播模型（已有）；实车制动缸压力测试 |
| 影响 | 「均分假设」若偏差 20%，单车热流偏差 20% |
| 临时处理 | 保留均分假设，但在报告中声明；建议用项目模型自身的逐车压力输出替代均分 |

### P1-4 闸瓦磨耗状态（剩余厚度）

| 项 | 内容 |
|---|---|
| 缺什么 | 本项目运行里程对应的闸瓦剩余厚度/磨耗量 |
| 现状 | 肖绯雄 2014 表 2 表明磨耗 0→28 mm 使同工况峰值从 651.1 ℃ 升到 1 538 ℃（−10‰/80 km/h），影响极大 |
| 获取途径 | 运用维修记录；肖绯雄式(7) 的磨耗量估算 |
| 影响 | 新瓦与到限瓦的热质量差近 1 倍，峰值温度差可达 2 倍以上 |
| 临时处理 | 按新瓦（0 mm 磨耗）计算，报告注明「未计磨耗」 |
