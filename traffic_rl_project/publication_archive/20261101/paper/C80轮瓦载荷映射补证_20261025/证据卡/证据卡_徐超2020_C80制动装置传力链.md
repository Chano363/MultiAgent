## 2. 研究对象

C80 型铝合金敞车单元制动装置，理论解析 + 现场静态闸瓦压力试验 + RecurDyn 仿真。与卢碧红 2021 同一课题组、同一批试验。

## 3. 关键公式（原文编号）

式(2.1)（PDF 35 / 印刷 p26）：

```
F_z = P_z · π d² / 4
```

F_z 制动缸推杆推力(N)，P_z 制动缸压强(Pa)，d 制动缸直径(m)。

式(2.2)(2.3)（PDF 36 / p27）：闸瓦压力按杠杆比传递，前制动梁两块为 K₁,₂，后制动梁两块为 K₃,₄：

```
K₁,₂ = F_z · (a+b)/a · e/f · j/i
K₃,₄ = F_z · (a+b)/a · e/g · f/h
```

式(2.4)：ΣK_理 = K₁+K₂+K₃+K₄（即每车 4 块闸瓦，1 个制动缸驱动前后两根制动梁）。

式(2.5)：制动倍率 n = ΣK_理 / F_z。

式(2.6)：制动效率 η = ΣK_实 / ΣK_理。

式(3.1)（PDF 50 / p41，引自 TB/T 1407-1998 推导）：η 由 ΣK、制动缸数 n_z、缸径 d、缸压 P_z、倍率 γ 计算。

## 5. 必须标注的内部不一致

原文称制动缸为 356×254 旋压密封式，但按式(2.1) 用 d = 254 mm 计算，140 kPa 应得约 7094 N、390 kPa 应得约 19782 N，与文中给出的 4529 N / 12616 N 不符。反推 4529/(140×10³) = 0.03235 m²，对应 d ≈ 203 mm。

处理方式：本卡如实并列「原文文字（356×254）」与「原文数字反推（d≈203 mm）」两种口径，不擅自修正，也不据此断言哪种正确。凡引用推力、倍率 8.5、效率 0.578/0.853，均须注明它们是在原文数字口径下自洽的；用于本项目时必须另取缸径实测值复核。

## 6. 能回答什么

- 给出 C80「1 制动缸 + 4 块闸瓦 + 制动倍率 8.5」的完整传力链，以及理论/实测两级闸瓦力。
- 给出本项目最关键的一条：**换算制动法与真实法向力的量级差**。重车实测四块合计 79.4 kN（约 19.8 kN/块），而项目模型里的 K_h = 161.5 kN 是换算值，约为实测法向力总和的 2 倍，更不能当作单块闸瓦真实压力。
- 给出 500 kPa 定压这一试验条件，说明本项目的 50 kPa 减压与 396 kPa 缸压不是同一口径。

## 8. 适用边界

- 全部闸瓦力均为静态测定；列车运行中因制动梁窜动、偏载、间隙变化，实际法向力会波动（本文第 3 章仿真亦指出速度 >30 km/h 时轮瓦出现异常间歇接触）。
- 不可把 19.8 kN/块直接当本项目 50 kPa 减压下的法向力；只能作为「缸压—法向力」标定曲线上的一个点。
