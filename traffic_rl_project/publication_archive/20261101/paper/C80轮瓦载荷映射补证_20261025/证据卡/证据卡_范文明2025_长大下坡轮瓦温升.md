## 3. 关键公式（原文编号 + PDF 页；式(4) 已用高清裁剪逐字符核对）

式(1)（PDF 4）：制动空走时间

```
t_k = (1.6 + 0.065n)(1 − 0.028i)
```

n 为牵引辆数，i 为坡度千分数。

式(2)(3)（PDF 4）：有效制动距离 S_e = L − v·t_k；减速度 a = (v² − v₀²)/(2S_e)。

式(4)（PDF 4）——**原文照录**：

```
q^b = [ dQ(t)/dt ] / S = m·a·(v − a·t)·(a + g·θ) / S
```

符号：q^b 制动产生的总热流密度；Q(t) 制动过程总能量；v 制动初速度；m 单个车轮承受的载荷（轴重 25 t，单轮约 12.5 t）；θ 坡度值（下坡取负）；S **闸瓦与踏面接触环面的面积**。

> **必须标注的原文问题**：按原文所给符号量纲，分子 m·a·(v−a t)·(a+gθ) 为 kg·m²·s⁻⁶，除以 S 后不是 W·m⁻²，与 q^b 的定义不符；若按「制动功率 ÷ 面积」，应为 m(a+gθ)(v−a t)/S。原文式(4) **多出一个因子 a**（或把 a 与 (a+gθ) 重复计入）。本卡如实照录，**不代为修正**；本项目若复算，须按量纲自洽形式使用，不得直接照抄该乘子。

式(5)(6)（PDF 4）：轮瓦热流分配

```
q_w = η · q^b
q_s = (1 − η) · q^b
```

原文：η「根据车轮及闸瓦的材料属性[26]**计算**，取为 **0.91**」——即车轮 0.91、闸瓦 0.09。**该值由材料物性计算得出，不是实测**。

式(7)（PDF 4）：下滑力 F_g = [P(i − w′₀) + G(i − w″₀)]·g×10⁻³。

式(8)(9)（PDF 5）：机车/车辆单位基本阻力 w′₀ = 1.44 + 0.0099v + 0.000298v²；w″₀ = 0.92 + 0.0048v + 0.000125v²。

式(10)（PDF 5）：F_b = F_g − (P + G)·a。

式(11)（PDF 5）：q_b = F_b·v / (2nS)，n 为机车与牵引车辆**总轴数**，2n 即全部车轮数，S 为单轮接触环面积。

> 口径要点：式(11) 的分母是**全部车轮的接触环面积之和**，得到的是「按全列车轮周环面积平均」的热流密度；它不是单块闸瓦接触斑上的热流密度。两种 S 的取法相差近一个数量级（见参数证据表第 4 节）。

式(12)（PDF 5）：车轮表面对流

```
h(t) = 0.3828 + 14.39·v(t)
```

式(13)—(16)（PDF 5）：闸瓦对流按强制对流，Nu = 0.664Re^(1/2)Pr^(1/3)（层流）或 Nu = (0.037Re^(4/5) − 871)Pr^(1/3)（混合边界）；特征尺寸取闸瓦长度。

式(17)（PDF 5）：辐射，**发射率取 0.66**。

## 5. 允许限值的来源

原文（PDF 3）：

> 「针对踏面损伤阈值温度的研究，Handa K 等[19] 指出踏面钢材温升软化，当温度超过 **300 ℃** 时，踏面塑性变形加剧导致磨损率显著上升，**本文以此为轮瓦阈值温度**。」

- 300 ℃ 是**转引 Handa 等（Wear, 2020）的定性结论**，被本文借用为「轮瓦阈值」；它不是标准规定的允许温度，也不是本项目可用的验收限值。
- 原文没有给出「允许持续时间」，也没有给出闸瓦材料的允许温度。

> **必须标注的原文内部矛盾**：PDF 10 称 −24‰ 下「车轮与闸瓦峰值温度分别为 325.06 ℃、243.53 ℃，**均超过阈值温度**」。但按本文自设的 300 ℃ 阈值，闸瓦 243.53 ℃ **并未超过**。该句与阈值定义不自洽，**本卡不采信「均超过」这一表述**，只采信数值本身。

## 6. 对本项目的可用性判定

### 可直接采用的同工况参数

本文是**唯一明确以 C80 型敞车为对象**的长大下坡轮瓦温升文献，以下参数与 C80 同车型、同材质层级，可直接采用：

- 车轮 **840 mm / CL60 / LM 踏面**；闸瓦 **树脂基合成、宽 85 mm**
- 轴重 **25 t**，单轮载荷 12.5 t
- 车轮/闸瓦材料物性（表 1，与陈建平 2025 一致）
- 车轮对流经验式 h(t) = 0.3828 + 14.39 v(t)
- 辐射率 0.66
- 循环制动缓解速度不低于 30 km/h、本文取 35 km/h（依据《铁路机车操作规则》）

### 仅可迁移的方法

1. **「总制动力 → 全轮周环面积平均热流」的式(11)**：可直接把本项目的列车级空气制动力时程转成轮周热流时程（注意量纲修正后的式(4)）。
2. **轮瓦 0.91 / 0.09 的分配结构**：与李广 2026 的 2%—6% 闸瓦占比同向（0.09 略高于 6%，属同一量级），可作分配系数的上界参照。
3. **循环制动「制动—缓解—制动」三周期建模框架**（10 km 制动 + 120 s 缓解）：与本项目 405.7 s 持压后缓解再抱闸的场景结构一致，可作时序模板；但具体数值不可照搬。
4. **「循环制动下环境温度影响不足 2%」**：说明对本项目长时程工况，环境温度不是主控因素，可降低该参数的取证优先级。

### 不可迁移或证据不足

1. **不能把 410.66 ℃ / 325.06 ℃ / 306.26 ℃ 当作本项目 405.7 s 持压的预期温度**：本文是 3 个 10 km 制动周期、总时长 2 118 s 的仿真，坡度、编组、缓解时间均不同。
2. **不能把 300 ℃ 当验收限值**：转引定性结论，非标准。
3. **不能把 0.91 当作实测分配系数**：由材料物性计算，非实测。
4. **不能把式(4) 原样代入**：量纲不自洽（见第 3 节）。
5. **全文无实测**，不能作为「实测验证过」引用。
6. **未给出**：闸瓦摩擦系数、单块闸瓦法向力、接触斑面积、闸瓦初温、列车总质量、辆数（仅提「2 万吨」）。
