## 3. 关键公式（原文编号 + 页）

式(1)（p21）：热应力 σ = α_a·E·(T − T₀)。

式(2)（p21）：辐射折算为对流的因子

```
k = 0.337·Pr^0.35·λ·υ^0.8 / [ ε·σ·(t_w² + t_∞²)·L^0.2·v^0.8 ]
```

式(3)（p21）——**摩擦热流密度的核心式**：

```
q(t) = η · Φ(t) / (n · S_f)
```

- Φ(t)：热流率，W
- n：**每轴所对应的闸瓦数，取 n = 2**
- S_f：闸瓦摩擦面积，m²
- η：摩擦热分配到闸瓦上的比例，**依据文献[9]取 η = 10%**

紧急制动代入后：**q(t) = 153.728 − 2.795 t，kW/m²**（p21）。

> 口径要点：
> 1. **η = 10% 是转引值**（文献[9] = 应之丁等，《中国铁道科学》2010, 31(3): 70-75），不是本文实测。
> 2. **S_f 的数值原文未给出**，因此本表的 kW/m² 绝对值无法与李广 2026（接触斑尺度）或范文明 2025（轮周环面积尺度）直接比较。**不同文献的热流密度数值不可跨文对比**。

## 6. 允许限值的来源（本卡关键判据出处）

| 判据 | 原文表述 | 出处 |
|---|---|---|
| **900 ℃** | TB/T 2403—2010 规定闸瓦在温度 900 ℃ 时热失重不超过标称值 ±10%，原文「**暂以该值作为闸瓦承受的最高温度**」 | p24 |
| 36 MPa | 闸瓦压缩强度极限，用于判断最大应力是否超限 | p24 |
| 1 cm³/MJ | 标准规定的闸瓦磨耗量上限 | p24 |
| 剩余厚度 ≥18 mm | 提速货车高摩合成闸瓦磨耗剩余厚度要求（按闸瓦厚 45 mm 计） | p25 |
| 剩余厚度 ≥25 mm | 大秦线、侯月线、高原铁路及 C100 型敞车二、三位转向架要求 | p25 |

> **900 ℃ 是材料热失重试验的考核温度，被作者「暂以」用作承受上限——是代理判据，不是标准规定的运用温度限值。不得写成本项目的允许上限。**

## 7. 对本项目的可用性判定

### 可直接采用的同工况参数

**无。** 本文未给车型、编组、辆数、总质量、阀型、定压、减压量，且为纯仿真；不能提供任何 C80 同工况参数。

### 仅可迁移的方法

1. **热流反算链条**：总空气制动力（kN）→ 每轴摩擦热 → 每块闸瓦热流密度 → 温度。链条完整，但 S_f 需自定。
2. **按坡度/速度分档给定 q(t) 与 h_f 的表格式建模**：可作本项目「速度—坡度—热流」查表的参考结构。
3. **判据框架**：以材料考核温度（900 ℃）作代理上限，叠加磨耗状态修正，再叠加压缩强度校核——是目前唯一有标准出处的闸瓦判据组合。
4. **循环调速制动的升温机理**：制动缓解后闸瓦得不到充分散热，温度逐周期抬升（p24）。与本项目 405.7 s 持压后缓解再抱闸的担忧同向。

### 不可迁移或证据不足

1. **不能把 η = 10% 直接采用**。它与李广 2026 实测反标定的 2%—6% 相差 2—5 倍。两者不得取平均，也不得「取中间值」；只能二选一并说明依据，或作为上下界做敏感性分析。
2. **不能把 651.1 ℃、909 ℃、1 538 ℃ 当作本项目预期温度**：工况（−10‰ 匀速 80 km/h、40 min、120 km/h 紧急制动）与判据口径均不同。
3. **不能把 900 ℃ 当允许上限**（代理判据）。
4. **不能把 62.4 MPa 超限结论迁移**：应力取决于闸瓦压力与结构，本文未给闸瓦压力。
5. **不能把表 1 的 kW/m² 与李广/范文明的数值跨文比较**：S_f 定义与数值未统一。
6. **全文无实测**，不能作为「实测验证」引用。
