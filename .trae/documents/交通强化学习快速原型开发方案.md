# 基于TorchRL和SUMO-RL的交通强化学习项目快速原型开发方案

## 项目概述

本项目旨在利用TorchRL（PyTorch官方强化学习框架）和SUMO-RL（交通仿真环境）快速构建交通信号控制强化学习原型系统，实现从数据获取、环境搭建、模型训练到评估验证的完整开发流程。

### 3.3 数据格式要求

#### SUMO文件格式标准

**路网文件 (*.net.xml)**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<net version="1.9">
    <!-- 节点定义 -->
    <junction id="J0" type="traffic_light" x="0.0" y="0.0">
        <request index="0" response="00" foes="00"/>
    </junction>
    
    <!-- 边定义 -->
    <edge id="E0" from="J0" to="J1" priority="1" numLanes="2" speed="13.89">
        <lane index="0" id="E0_0" length="100.0"/>
    </edge>
    
    <!-- 连接关系 -->
    <connection from="E0" to="E1" fromLane="0" toLane="0" via=":J1_0"/>
    
    <!-- 交通信号逻辑 -->
    <tlLogic id="J0" type="static" programID="0" offset="0">
        <phase duration="31" state="GrGr"/>
        <phase duration="6"  state="yryr"/>
        <phase duration="31" state="rGrG"/>
        <phase duration="6"  state="ryry"/>
    </tlLogic>
</net>
```

**路由文件 (*.rou.xml)**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<routes>
    <!-- 车辆类型 -->
    <vType id="car" vClass="passenger" maxSpeed="13.89"/>
    
    <!-- 路由定义 -->
    <route id="route0" edges="E0 E1 E2"/>
    
    <!-- 流量定义 -->
    <flow id="flow0" route="route0" begin="0" end="3600" 
          vehsPerHour="600" type="car"/>
</routes>
```

**配置文件 (*.sumocfg)**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <input>
        <net-file value="grid3x3.net.xml"/>
        <route-files value="grid3x3.rou.xml"/>
    </input>
    <time>
        <begin value="0"/>
        <end value="3600"/>
    </time>
    <report>
        <duration-log.statistics value="true"/>
    </report>
</configuration>
```

#### 集成代码示例
```python
import sumo_rl
import torchrl
from torchrl.envs import EnvBase, TransformedEnv, Compose
from tensordict import TensorDict

# 1. 创建SUMO-RL环境
env = sumo_rl.parallel_env(
    net_file='data/grid3x3.net.xml',
    route_file='data/grid3x3.rou.xml',
    use_gui=False,
    num_seconds=3600,
    delta_time=5,  # 每5秒决策一次
    yellow_time=3,
    min_green=10,
    max_green=60,
    reward_fn='queue',  # 使用队列长度作为奖励
)

# 2. 转换为TorchRL兼容环境
from torchrl.envs.libs.pettingzoo import PettingZooWrapper

torchrl_env = PettingZooWrapper(env)

# 3. 添加数据变换
from torchrl.envs.transforms import (
    ObservationNorm, 
    RewardScaling,
    StepCounter
)

transformed_env = TransformedEnv(
    torchrl_env,
    Compose(
        ObservationNorm(in_keys=["observation"]),
        RewardScaling(loc=0, scale=1),
        StepCounter(),
    )
)

# 4. 初始化归一化参数
transformed_env.transform[0].init_stats(
    num_iter=1000, 
    reduce_dim=0
)

# 5. 环境验证
td = transformed_env.reset()
print(f"观察空间: {transformed_env.observation_spec}")
print(f"动作空间: {transformed_env.action_spec}")
```

#### 训练脚本 (src/scripts/train.py)
```python
import torch
from torchrl.collectors import SyncDataCollector
from torchrl.data import LazyMemmapStorage, ReplayBuffer
from torchrl.envs import TransformedEnv
from torchrl.modules import ActorCritic
from torchrl.objectives import ClipPPOLoss
from tensordict import TensorDict
from tqdm import tqdm

from src.environments.sumo_env import make_env
from src.utils.config import load_config

def train(config_path):
    # 加载配置
    config = load_config(config_path)
    
    # 创建环境
    env = make_env(config['environment'])
    
    # 添加变换
    env = TransformedEnv(env)
    
    # 创建模型
    actor_critic = ActorCritic(
        observation_spec=env.observation_spec,
        action_spec=env.action_spec,
        **config['network']
    )
    
    # 创建收集器
    collector = SyncDataCollector(
        env,
        actor_critic,
        frames_per_batch=config['training']['n_steps'],
        total_frames=config['training']['total_frames'],
        device=config['device']
    )
    
    # 创建损失函数
    loss_fn = ClipPPOLoss(
        actor_network=actor_critic.actor,
        critic_network=actor_critic.critic,
        **config['ppo']
    )
    
    # 创建优化器
    optimizer = torch.optim.Adam(
        actor_critic.parameters(),
        lr=config['optimizer']['actor_lr']
    )
    
    # 训练循环
    for i, tensordict in enumerate(collector):
        # 计算优势
        loss_fn.advantage(tensordict)
        
        # 计算损失
        loss = loss_fn(tensordict)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 日志记录
        if i % config['logging']['log_interval'] == 0:
            print(f"Step {i}, Loss: {loss.item():.4f}")
    
    # 保存模型
    torch.save(
        actor_critic.state_dict(),
        f"outputs/checkpoints/model_final.pt"
    )

if __name__ == "__main__":
    train("configs/train_config.yaml")
```

## 第六部分：风险管理

### 6.1 技术风险

| 风险项 | 影响 | 缓解措施 |
|-------|------|---------|
| SUMO仿真速度慢 | 训练时间长 | 启用Libsumo加速、并行环境 |
| 环境不稳定 | 训练困难 | 奖励归一化、观察归一化 |
| 超参数敏感 | 性能波动 | 系统性超参数搜索 |
| 内存溢出 | 程序崩溃 | LazyMemmapStorage、梯度累积 |

### 6.2 进度风险

| 风险项 | 概率 | 应对策略 |
|-------|------|---------|
| 数据获取延迟 | 中 | 优先使用RESCO内置数据 |
| 环境调试困难 | 高 | 充分利用SUMO-GUI调试 |
| 算法收敛慢 | 中 | 从简单场景开始验证 |
